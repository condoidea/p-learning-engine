# LEARNING ENGINE

「わかるまで教えて、忘れる前に思い出させる」学習アプリのエンジン。
ブラウザだけで動き（Node・サーバー不要）、科目ごとに**コース**を差し替えて使う。

最初のコースは **基本情報技術者試験（BIT RUSH）**。

## 使い方
- `index.html` をダブルクリック → コースを選ぶ
- コースを直接開くなら `fe.html`（基本情報技術者試験）

## 学習の流れ（全コース共通）
1. **ロードマップ**のレッスンで理解する（たとえ話・図 → 用語 → 体験 → 確認 → 例題 → 自力 → まとめ）
2. クリアすると、その範囲の**本番形式の問題**と**復習カード**が解放される
3. 解放された問題を**間隔反復**（忘却曲線）で復習する
4. ユニットを終えたら**ユニットボス**（範囲を混ぜた総合問題）に挑む

学習理論との対応は [docs/学習設計.md](docs/学習設計.md) を参照。

## フォルダ構成
```
index.html              コース選択（タイトル画面）
fe.html                 基本情報コースの入口（中身は数行。engine/js/boot.js が組み立てる）
habsburg.html           ハプスブルク年代記コースの入口
trig.html               三角比・平面図形コースの入口
engine/
  js/boot.js            起動処理（スタイル・画面・スクリプトを順に読み込む）
  js/fxmap.js, fxgeo.js 背景（古地図／方眼ノートと単位円）。scene.preset で切りかえ
  js/terms.js           画面の呼び名（コースごとに差し替え可能）
  js/template.js        画面の骨組み（全コース共通）
  js/api.js             教材を書くための関数（LE.add / LE.defLesson など）
  js/core.js            学習ロジック（間隔反復・習熟ゲート・XP・実績・保存）
  js/lesson.js          ロードマップとレッスン画面
  js/ui.js              ホーム・問題・結果・カード・設定などの画面
  js/fx2d.js, fx3d.js   演出（パーティクル・3D背景）
  js/audio.js           効果音・振動
  css/                  見た目（共通）
courses/
  registry.js           コース一覧（index.html が読む）
  fe/                   基本情報技術者試験コース
    course.js           コース設定（名前・試験形式・特別ルール・読み込むファイル）
    theme.css           コース専用の見た目
    data/               教材（分野・ロードマップ・レッスン・問題・復習カード）
  habsburg/             ハプスブルク年代記（マンガ『ハプスブルク家の華麗なる受難』1〜3巻の範囲・高校世界史レベル）
  trig/                 三角比・平面図形 公式マインドマップ（プリント1枚分・数式は KaTeX、動かせる図形つき）
tests/
  check-course.js       教材の整合性チェック（Node）
  e2e.js                ブラウザでの通しテスト（<コース>.html?e2e で起動）
docs/                   設計・コースの作り方
```

## テスト
エンジンを変更したら、全コースで両方を通すこと。
```bash
node tests/check-course.js fe
```
- ブラウザで `fe.html?e2e` を開く（全レッスン・全ボス・全モードを自動で解く。約10分）
- `fe.html?e2e&fast` なら最初の2ユニットだけ（約2〜3分）
- テストは専用の保存先（`.e2e`）を使うので、本物の学習データには触れない

`file://` で開いた場合にブラウザが自動テストを制限することがある。その場合はフォルダで `python -m http.server 8766` を実行し、`http://localhost:8766/fe.html?e2e` を開く。

## 学習データ
- ブラウザの localStorage に保存（コースごとに別保存。レベル・ストリークは全コース共通）
- 設定画面から書き出し／読み込みでバックアップできる
- 旧版（`基本情報技術者試験/`）のデータが同じブラウザにあれば、初回起動時に自動で引き継ぐ
