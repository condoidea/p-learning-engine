# 学習設計ノウハウ（ユーザーと検討・獲得したもの）

コースを作る・直すときに、まずここを読む。
基本情報（BIT RUSH）→ ハプスブルク年代記 → 三角比（サンカク・ラッシュ）の制作で、ユーザーとのやり取りから得た原則・部品・試したアイデアをまとめたもの。

---

## 1. 原則（ユーザーの指摘から）

| # | 原則 | きっかけ |
|---|---|---|
| 1 | **知識を入れる前に問題を出さない。** 「まず覚える（短く・楽しく）→ すぐ思い出す → 定着」 | 基本情報「問題だけじゃ学習できない」、三角比「三角定規の比を説明せずに問題」 |
| 2 | **「タップするだけで解ける」問題は NG。** その知識を使わないと解けない操作にする | 三角比「tan30°の角はどこ？」で 30 の円を押すだけ |
| 3 | **受け身の「次へ」「次へ」にしない。** 自分で押す → 結果が出る。説明は「小さな問い（予想）→ 答えると説明」 | 三角比「次へ次へでは脳が記憶を拒否する」 |
| 4 | **図形のアニメーションは説明に沿って、適度に。** 文章と図のイメージを連動させる（例：「裏返る」なら本当に裏返す） | 三角比「定規が裏返って」 |
| 5 | **前に教えたことがまた出たら、同じ説明を復習として繰り返す。** 1〜2回で十分 | 三角比「筆記体を三角定規でもう一度」 |
| 6 | **教材の範囲・分量は元の資料に合わせる。** 盛りすぎると、やる気がなくなる | 三角比「プリントはもっとシンプル」→ 20レッスン135ステップ → 15レッスン62ステップ |
| 7 | **図がないと解けない画面を作らない。** 記号（a, b, PA…）を使う問題には必ず図 | 三角比「この画面だけでは解けない」 |
| 8 | **何をすれば合格か、いつも見えるように。** ミッションは条件を具体的に、進み具合（●●○）も出す | 三角比「何がパスの条件か分からない」 |
| 9 | **飾りが学習の邪魔をしたら本末転倒。** 背景は文字の画面で十分に暗く。うすくしても色の太線や光は目立つので、文字の画面では描かない | 三角比「背景の線画が明るすぎる」 |
| 11 | **その画面のポイントが一目で分かるように。** 文字は一文字ずつ流し、キーワードは跳ねてマーカー（`typewriter`） | 三角比「説明が丁寧で長くなった分、ポイントを見失う」 |
| 12 | **迷いそうな言葉には、こまめにヘルプ。** 本文に出たら自動で「？」（`autoGloss`）。迷ったときだけ見ればいい | 三角比「逆数などにヘルプがあるとストレスが減る」 |
| 13 | **覚えること／覚え方のヒント／この教材での呼び方・約束を見た目で分ける。** `**…**`＝覚えること（マーカー）、`__…__`＝覚え方（💡波線）、`((…))`＝便宜上の呼び方（📎グレー）。最初のレッスンで見分け方を教える。数式は `**` などで囲まない | 三角比「斜辺を c と呼ぶ、が覚える知識に見える。学習者は何を覚えるべきか判断できないから学習者」 |
| 14 | **思い出させるときは「何を思い出すか」の手がかりを見せる。** まとめの答え合わせは「問い（見える）＋答え（ぼかす）」。全部ぼかすと、何を思い出せばいいか分からない（`points: [{ q, a }]`） | 三角比「ぼかしたところを頭の中で言って、はヒントが無さすぎ」 |
| 15 | **説明を一足飛びにしない。** 数学が苦手な子は「2乗＝正方形の面積」「sin²/cos² ＝ tan²」のような1段の省略で置いていかれる。書き方の約束（$\cos^2	heta=(\cos	heta)^2$）も最初に教える。本文が長くなるところは「🤔 なぜ？」（`more`）で、見たいときだけ開けるようにする。前提になる関係（tan ＝ sin ÷ cos）は、使う前のレッスンではっきり教える | 三角比「面積だと説明不足」「なぜ tan² になるのか」 |
| 10 | 操作の「ここちよさ」：指に遅れない・吸いつきは少し弾む・数字は足し算が合うように表示 | 三角比 |

**点検のしかた**：完成前に全レッスンを通して、①説明より先に問題が出ていないか ②受け身の「次へ」が続いていないか ③図がないと解けない画面がないか ④資料より盛りすぎていないか ⑤太字が「覚えること」だけになっているか（話の強調・計算問題の数値・エピソードの細部は太字にしない）、を見る。指摘された箇所だけでなく全体を直す。

**太字の点検のしかた**：レッスンの「まとめ」と用語カードに出てこない太字を機械的に洗い出し（その太字は覚えることではない可能性が高い）、1つずつ「覚える／ヒント／呼び方／ただの強調」に振り分ける。計算問題の問題文の太字は「問題のデータ」なので外す。

## 2. エンジンの部品（どのコースでも使える）

| ステップ | 何に向いているか |
|---|---|
| `say` ＋ `ask` / `reveal` | 説明の前に小さな問い（予想）。答えると説明と図が出る（予測・生成効果）。採点しない |
| `show` | コマ送りの解説。コマに `ask` を入れると、答えるまで次へ進めない |
| `widget` | 動かせる図形（コースの `LE.widgets`）。ミッション＋進み具合 |
| `build` | 公式を札で組み立てる（1手ごとに判定） |
| `fill` | 家系図・表・式の穴埋め |
| `decide` / `advise` | RPG の決断・臣下として提言（歴史向け） |
| `route` | 地図の上で駒を進める（`LE.mapData` が必要） |
| `like` | 「いまでいうと」のたとえ |
| `recap`（`COURSE.recapTap`） | キーワード（太字・数式）をぼかし、思い出してからタップ |
| `step.art` / `step.place` | 線画の挿絵（ペンで描く）／古地図の舞台へ移動 |

背景：`scene.preset` = `'neon'`（3D）・`'royal'`・`'map'`（古地図）・`'geo'`（方眼ノートと単位円）。数式は `COURSE.math`（KaTeX）。

## 4. 試して、いまは外したアイデア（理由つき）

- **三角比 v1-full（20レッスン・135ステップ・111問）**：`courses/trig/archive/v1-full/` に保存。プリントより盛りすぎ（原則6）として 15 レッスンへ。
  - 外したレッスン：「鈍角の値を出す（120°・135°・150°）」「どの公式を使う？（使い分け）」。プリントの枠にないため。
  - 外した活動：例題のコマ送り、計算入力（num）、表のフック（sin は √1,√2,√3 /2）、内心・重心のウィジェット、たとえ（いまでいうと）など。
- **三角定規の「角をタップ」問題**：知識なしで解けるので廃止（原則2）→ `ruler` を「分母→分子の辺タップ」に作り直したが、量の見直しで未使用。
- **証明の並べ替え（order）**：見たことのない証明を並べさせるのは原則1に反する → コマ送り＋問いに変更。
- **パーティクルの背景（ハプスブルク）**：サイバーで世界観に合わない → 古地図へ。

## 5. 内容づくりのコツ

- フック（覚え方）は資料の落書き・メモを最優先で拾う（例：プリントの筆記体 s c t、メネラウスきつね、「30°,45°,60° → 三角定規」）。
- 色は意味で固定する（三角比：sin＝ピンク、cos＝シアン、tan＝イエロー）。背景・図・式・問題で統一。
- 同じ公式を、図から／式から／逆向き／計算／まちがい探し、とちがう形で問う（復習の問題で）。
- 歴史で覚えることは「年・人物・出来事・その意味」。年齢・日付の細部・エピソードの小道具は話を楽しくする材料なので太字にしない。
- 歴史は「時系列」で進める。文化・社会の話は「文化の窓」として、その時代の位置に入れる。

## 6. 画面づくりの落とし穴（レイアウト）

- **吹き出しの中の部品は inline のまま**にする。`<button>`・`inline-block`・`scale` は行の中で1つの箱になり、長い太字が折り返せなかったり、直後の「。」が行頭に泣き別れしたりする（ハプスブルク「文字が大きくなって崩れる」）。用語ヘルプは `<span role="button">`、「？」も inline、キーワードの跳ねは `position:relative; top` で動かす。
- 数式（KaTeX）は箱になるので、直後の句読点は数式といっしょに `nobr` でまとめる（エンジンが自動でやる）。
- 大きな飾り文字（頭文字）は、2行以上ある文だけにつける。短い文だと行の高さが崩れる。
- 確認は**スマホ幅（375px）で、全レッスンの説明文を機械的に流し込んで**、はみ出し・行頭の句読点を数える（3コースまとめて）。
- **iPhone の Safari は、はみ出しのある画面で文字を勝手に拡大する**（テキスト自動拡大）。`html { -webkit-text-size-adjust: 100% }` で止める。Chrome のスマホ幅表示では再現しないので、実機で見た指摘は重要。
- 図の縦矢印 `.ar.v` は「→」を90°回して下向きにしている。文字入りの矢印（「↓ 封土 ／ ↑ 忠誠」など）は `.ar.vl`、最初から ↓ の記号は回さない。
- 地図のラベルは、エンジンが重なり・はみ出しの少ない位置（右・左・下・上・斜め）に自動で置く。旅（route）の指示は「地名をタップすると駒が進む」と、操作そのものを書く。
- 濃い背景の上に、羊皮紙用の朱色（テーマの太字色）が乗らないよう、場所ごとに色を固定する。
