| 10 | 操作の「ここちよさ」：指に遅れない・吸いつきは少し弾む・数字は足し算が合うように表示 | 三角比 |

**点検のしかた**：完成前に全レッスンを通して、①説明より先に問題が出ていないか ②受け身の「次へ」が続いていないか ③図がないと解けない画面がないか ④資料より盛りすぎていないか ⑤太字が「覚えること」だけになっているか（話の強調・計算問題の数値・エピソードの細部は太字にしない）、を見る。指摘された箇所だけでなく全体を直す。

**太字の点検のしかた**：レッスンの「まとめ」と用語カードに出てこない太字を機械的に洗い出し（その太字は覚えることではない可能性が高い）、1つずつ「覚える／ヒント／呼び方／ただの強調」に振り分ける。計算問題の問題文の太字は「問題のデータ」なので外す。

## 2. エンジンの部品（どのコースでも使える）

| ステップ | 何に向いているか |
|---|---|
| `say` ＋ `ask` / `reveal` | 説明の前に小さな問い（予想）。答えると説明と図が出る（予測・生成効果）。採点しない |
| `show` | コマ送りの解説。コマに `ask` を入れると、答えるまで次へ進めない |
| `widget` | 動かせる図形（コースの `LE.widgets`）。ミッション＋進み具合 |
| `build` | 公式を札で組み立てる（1手ごとに判定） |
| `fill` | 家系図・表・式の穴埋め |
| `decide` / `advise` | RPG の決断・臣下として提言（歴史向け） |
| `route` | 地図の上で駒を進める（`LE.mapData` が必要） |
| `like` | 「いまでいうと」のたとえ |
| `recap`（`COURSE.recapTap`） | キーワード（太字・数式）をぼかし、思い出してからタップ |
| `step.art` / `step.place` | 線画の挿絵（ペンで描く）／古地図の舞台へ移動 |

背景：`scene.preset` = `'neon'`（3D）・`'royal'`・`'map'`（古地図）・`'geo'`（方眼ノートと単位円）。数式は `COURSE.math`（KaTeX）。

## 4. 試して、いまは外したアイデア（理由つき）

- **三角比 v1-full（20レッスン・135ステップ・111問）**：`courses/trig/archive/v1-full/` に保存。プリントより盛りすぎ（原則6）として 15 レッスンへ。
  - 外したレッスン：「鈍角の値を出す（120°・135°・150°）」「どの公式を使う？（使い分け）」。プリントの枠にないため。
  - 外した活動：例題のコマ送り、計算入力（num）、表のフック（sin は √1,√2,√3 /2）、内心・重心のウィジェット、たとえ（いまでいうと）など。
- **三角定規の「角をタップ」問題**：知識なしで解けるので廃止（原則2）→ `ruler` を「分母→分子の辺タップ」に作り直したが、量の見直しで未使用。
- **証明の並べ替え（order）**：見たことのない証明を並べさせるのは原則1に反する → コマ送り＋問いに変更。
- **パーティクルの背景（ハプスブルク）**：サイバーで世界観に合わない → 古地図へ。

## 5. 内容づくりのコツ

- フック（覚え方）は資料の落書き・メモを最優先で拾う（例：プリントの筆記体 s c t、メネラウスきつね、「30°,45°,60° → 三角定規」）。
- 色は意味で固定する（三角比：sin＝ピンク、cos＝シアン、tan＝イエロー）。背景・図・式・問題で統一。
- 同じ公式を、図から／式から／逆向き／計算／まちがい探し、とちがう形で問う（復習の問題で）。
- 歴史で覚えることは「年・人物・出来事・その意味」。年齢・日付の細部・エピソードの小道具は話を楽しくする材料なので太字にしない。
- 歴史は「時系列」で進める。文化・社会の話は「文化の窓」として、その時代の位置に入れる。

## 6. 画面づくりの落とし穴（レイアウト）

- **吹き出しの中の部品は inline のまま**にする。`<button>`・`inline-block`・`scale` は行の中で1つの箱になり、長い太字が折り返せなかったり、直後の「。」が行頭に泣き別れしたりする（ハプスブルク「文字が大きくなって崩れる」）。用語ヘルプは `<span role="button">`、「？」も inline、キーワードの跳ねは `position:relative; top` で動かす。
- 数式（KaTeX）は箱になるので、直後の句読点は数式といっしょに `nobr` でまとめる（エンジンが自動でやる）。
- 大きな飾り文字（頭文字）は、2行以上ある文だけにつける。短い文だと行の高さが崩れる。
- 確認は**スマホ幅（375px）で、全レッスンの説明文を機械的に流し込んで**、はみ出し・行頭の句読点を数える（3コースまとめて）。
- **iPhone の Safari は、はみ出しのある画面で文字を勝手に拡大する**（テキスト自動拡大）。`html { -webkit-text-size-adjust: 100% }` で止める。Chrome のスマホ幅表示では再現しないので、実機で見た指摘は重要。
- 図の縦矢印 `.ar.v` は「→」を90°回して下向きにしている。文字入りの矢印（「↓ 封土 ／ ↑ 忠誠」など）は `.ar.vl`、最初から ↓ の記号は回さない。
- 地図のラベルは、エンジンが重なり・はみ出しの少ない位置（右・左・下・上・斜め）に自動で置く。旅（route）の指示は「地名をタップすると駒が進む」と、操作そのものを書く。
- 濃い背景の上に、羊皮紙用の朱色（テーマの太字色）が乗らないよう、場所ごとに色を固定する。

## 7. モル教室（mole.html）で試した、ちがう形（2026-10-20）

アプリが増えてきたので「上から説明を読む」以外の形を試した。エンジンとは別の独立アプリ（`mole/`）。CSS・JS は `mole.html` だけが読み込む。

| 変えたところ | 中身 |
|---|---|
| 演出 | **先生とのチャット**（モルモットのモルモ先生）。先生が吹き出しで話し、こちらは下のボタンで返事。「🤔 なんで？」と返すと話が分かれて、詳しい説明（一足飛びにしないための途中の説明）が見られる＝ `more` のチャット版 |
| クイズの形 | 予想（採点しない）／選ぶ／**テンキーで数を入れる**（×10ⁿ キーつき。1回目のまちがいでヒント、2回目で解き方）／**先生のまちがい探し**（計算の行をタップ）／実験の中で選ぶ（地図の道） |
| クイズの時機 | レッスンの**最初に抜き打ち**（前のレッスンから1問）、説明の途中で予想、**最後に早押しラッシュ**（タイマーつき・全問正解で PERFECT） |
| 報酬 | XP・バッジのかわりに**あつめた粒の数**（10 の何乗）。正解ごとに ×1.3 倍…とふえ、粒がカウンターへ飛ぶ。**1 mol（6.0×10²³個）がゴール**。途中で「世界の人口」「水1滴の分子」などを超えると**スケール図鑑**に登録（単位の大きさの実感にもなる） |
| カードのかわり | レッスンごとに**結晶**（岩塩・ミョウバン・ダイヤモンド…）が育つ。時間がたつと**くもる → みがく（復習5問）**で輝きが増す（間隔反復の見える化）。結晶をタップすると**研究ノート**（板書・ひっかけ注意と 🤔 なぜ？・こぼれ話＝カード裏の豆知識） |
| 分量 | 化学が苦手な子向けに**基本8レッスン（1回3〜4分）**。応用（溶液の濃度）は**基本をぜんぶクリアで追加レッスンとして解放**。用語が多い「原子量・分子量」は2レッスンに分けた |

- 前提知識をアプリの中だけで完結させる：化学式の読み方（右下の数字＝個数）、10 の何乗の計算（前が 10 をこえたら直す、10⁰＝1）、原子核・陽子・中性子・質量数を、使う前のレッスンで教える。用語は点線のバルーン（図の中の文字には入れない）
- 実験カードには「ねらい（何を確かめる実験か）」と「やること」を書き、終わっても残す（ユーザー「触って遊ぶのは分かるけど、目的が示されてないとわからない」）
- 早押しは、ルールをトークの中のカードで見せ、「⚡ スタート！」を押してから画面が開く（「案内の直後に勝手に開くと、その前の説明が読めない」）
- 高校受験を経た高校生向けなので、中学の内容（原子・分子・化学式、10の累乗の意味）は「おさらい」として短く。くわしい説明は「🤔 ちょっと自信ない…」の分岐へ
- 動作確認は `mole.html?sandbox`（別の保存先）で。本物の記録に触れない
- 台本の点検：`node tests/check-mole.js`（先生が4回つづけて話すと注意＝受け身の「読むだけ」を防ぐ、計算ドリルに半端な小数が出ないか）。通しテストは `mole.html?e2e`

### 説明の「まくしたて」を防ぐ（モル教室・2026-10-20 のユーザー指摘）
- **長い説明は、速さではなく返事で区切る**。先生が3回つづけて話す所を作らない（`tests/check-mole.js` が注意）。返事は内容に合ったもの（「電子は？」「じゃあ、何て呼ぶの？」）にして、ただの「次へ」にしない。吹き出しの待ちは短め（0.9〜3秒）、タップで先へ
- **1つの吹き出しに1つのこと**。式や手順は改行して1行ずつ（例：「¹²C 1個 → 12 ／ H 1個 → 1 ／ だから 1 mol でも 12分の1 → 1.0 g」）。`tests/check-mole.js` が改行なしの長い1行（40字超）を注意する
- **新しい言葉は1つずつ出し、確かめの問いをはさむ**。用語が多い所はレッスンを分ける（原子量と分子量を別レッスンに）
- **「A → B：×22.4」のような書き方をしない**（コロンは比に見える）。「【mol から体積を求める】22.4 をかける」「【体積から mol を求める】22.4 でわる」のように文で書く。手順も「前の数は 2.0×3.0＝6.0」「答えは …」と文にする
- **2段階の計算は、まちがえたら1段階ずつに分ける**（`parts`）。いきなり解き方を見せるより、「1段階め：○○は何 mol？」から自分で解かせる
- **独自の呼び方（「地図」「○歩」など）は、それを教えるレッスンより前に出さない**
- **補足は聞いたときだけ**：説明のあとに「わかった」「🤔 なんで○○？」の返事を置く。分からない子だけが補足を読む

## 9. ユーキ・クエスト（yuki.html・有機化学）で試したこと（2026-10-21）

ユーザー（私用）「有機化学って素材を組み合わせて魔法陣を作るみたい」→ 有機と勇気をかけた RPG。共通テストの基本（完璧は目指さない）。重視：①ゲームの面白さ ②盛り上がる演出（ドパガキ・厨要素）③学習の丁寧さ・役立つ Tips。まず序章（炭素の村）と 1章（炭化水素の草原）だけ。独立アプリ（`yuki/`）。

| 変えたところ | 中身 |
|---|---|
| たとえの芯 | **原子価＝魔法陣が光る条件**（手が1本でも余ると光らない）、官能基＝紋章、試薬と条件＝呪文カード、反応＝魔法の発動、系統図＝地図。たとえの言葉は ((呼び方)) にして、覚える言葉は本物（置換・付加・脱水） |
| 錬成 | くし形の台座（横5・上下3ずつ。環ができない）に C・O を置く。H は自動で数えて CH₃・CH₂・OH と略して表示（示性式に慣れる）。**曲げただけ・ひっくり返しただけは「同じ形だ！」**（つながり方で判定）＝異性体のわなを体で覚える |
| 詠唱の儀式 | 試薬と条件のカードを選んで発動。正しければ詠唱が1行ずつ流れ、**詠唱の言葉どおりに魔法陣の原子が動く**（「隣り合う H と OH を引き剥がし」で本当に抜ける）。説明は表に出さず、**魔法のスクロール**（反応式・ポイント・ひっかけ・🤔なぜ）にだけ書く（ユーザー「説明臭いとテンションが下がる」）。条件ちがいで別の反応になるもの（130℃ → エーテル）は「暴発！？」として発動させる |
| 音 | **属性＝反応の種類ごとの BGM**（⚡雷＝置換・🌪風＝付加・🏜砂＝脱水縮合）を Web Audio でその場で鳴らす（オリジナル曲・ファイルなし）。詠唱の行ごとに楽器が重なり、「顕現せよ」の直前に一瞬止めて爆発。**読み上げ**は Web Speech API で、画面の漢字とは別に**ひらがなの読み（y）**を読ませる（焔・器などの読みが機種でぶれるため）。読めない端末では文字だけで同じ時間待つ |
| 復習 | 呪文書：使うほど詠唱が短くなる（完全詠唱 → 詠唱短縮 → 詠唱破棄 → 無詠唱）、使わないと3日ごとに1段もどる＝間隔反復を世界観の中で見せる。復習詠唱でカードを選び直す |
| ボス | 序章：幻影ミラージュ（C₅H₁₂ の異性体3つを時間内に錬成。同じ形を作ると反撃）。1章：臭素の魔獣ブロモス（問題で攻撃・5秒以内でクリティカル・3連続で FEVER・詠唱封じ＝詠唱の穴埋め）。とどめは付加の詠唱で**ボスの赤褐色が消える**（臭素水の脱色そのもの） |

- **錬成の作り直し（ユーザー指摘 2026-10-21）**：最初は「台座をタップすると CH₃・CH₂ が勝手に出る」形だったが、①手のつながりは H−C−H の見た目で覚えたい ②勝手に正しいものが出ると判断がいらない ③タップより自分で組み立てる感がほしい、で作り直した。いまは**素材（C・O・H）を、原子の空いている「手」までドラッグ**（タップで選んで手をタップでも可）。H も自分でつなぎ、素材を使いきって手が全部うまったら光る。略した書き方（CH₃−CH₃）は、できたあとに示す
- **操作は練習させる**（ユーザー「タップを一回練習させないとわからない」）：最初の錬成（エタン）で、ドラッグ → タップ（H は数が多いのでタップが楽）を 🧭 練習として1手ずつ出す。水素の筆も、初めて出る錬成で練習させる。輪（環）にできない理由は、置こうとしたときと「🤔 四角い輪にしたら？」で説明する（C₄H₈ になる）
- **理由は数えて見せる**（ユーザー「輪にすると手が二本減る理由が分からない。片手落ちにならないように」）：C 4 つで手は16本 → つなぎ目1か所で2本使う → 鎖（3か所）なら残り10本＝C₄H₁₀、輪（4か所）なら残り8本＝C₄H₈、を問いにして本人に数えさせ、構造式の絵（ブタン・シクロブタン）も見せる。Tips「輪を1つ作ると H は2つへる（二重結合も同じ）」で 1章のアルケンにつなぐ
- **ごほうびは経験値とレベル**（ユーザー「HP のように見える MP が増えるのは変。RPG なら EXP」）：魔力 MP をやめて EXP と Lv（Lv n→n+1 に 60＋30n）。レベルで称号が変わり、上がったら LEVEL UP!
- **序章を通しての指摘（2026-10-22）**：①ボス戦で、もう作った形が分からない → 倒した分身の所とレッスンの「作った形」の棚に、その構造式を残す ②曲げただけの同じ形が NG になる理由が、その場で分かりにくい → C を全部置いた時点で「🔎 鑑定」：いちばん長い鎖に 1→n の番号をふり、枝の番号（と名前）を出す。作った形と同じなら H をつける前に ⚠ ③3 通り作る必然性がほしい → ミラージュを「3 体の分身・それぞれ別の形の魔法陣が弱点」に。完成すると魔法が飛んで分身を倒す ④名前は抜き出しの問題で正解しても全部覚えたとは限らない → **全部の組を合わせるマッチング**（1 回 5 組・タイム表示・まちがえた組はその回の最後に「おさらい」でもう一度）。名前↔C の数、名前↔分子式、枝の名前、異性体の名前↔構造式
- **BGM はキメの場面だけ**（ユーザー「学習シーンでは要らない。戦闘で魔法を詠唱するときとか、キメシーンに入るとわくわくする」）：地図・レッスン・錬成・カード選びは静か。詠唱が始まったら属性の曲が鳴って発動で最高潮、儀式が終わったら止める。ボス戦はボスの曲
- **大きな分子の工夫**：H を自分でつなぐのは最初の数問だけ。慣れたら「水素の筆」（残りの手をまとめて H に。魔法陣を描く操作なので「詠唱」とは呼ばない）と、パーツ（CH₃＝メチル基、OH）で骨組みに集中させる。芳香族の章では**ベンゼン環をパーツ**にする予定（六角形を1つで置き、どの手に何をつなぐかを選ぶ）
- **見た目は中世ヨーロッパの RPG**（ユーザー希望）：テトラの話・Tips・地図・スクロール・カードは「羊皮紙にインク」、魔法陣は「暗い石板に金の光」、ボタンは金箔、地図のレッスンは封蝋、背景は石の城（レッスン中はうすく）。文字は明朝（Shippori Mincho）と Cinzel。飾りは縁と角だけ
- Tips は理由つき（HONC 1234、テトラ＝4＝テトラポッド、めったに えらくない プロの ぶた、オクタ＝オクトパス、低温は「ふたりで」高温は「ひとりで」）
