# ¡PEGA!（pega/）— 語尾のジェムを武器にはめて戦う

私用。西検4級まで1か月の時点で作った。**負担を軽く**（物語なし・1章5分ほど）。
チェック：`node tests/check-pega.js`（`--words` で単語帳にない語）。動作確認：`pega.html?sandbox`（`__pega.reset()`・`__pega.clearTo(n)`＝n章までクリア済みに・`__pega.chapter(i)`・`__pega.loot(id)`）。

## 決めたこと（依頼者）
- 語尾はしぼる：**-mente・-dad・-ción・-dor・-oso・-ista・-ero・-ería**。-dor は依頼者が足した。-ísimo は入れない〔経験則〕
- ストーリーより、サクサク。語尾の種類が自然と見分けられるように〔経験則〕
- **ゲームの形は依頼者の案**（2026-11-14）：「tranquilo という剣を持っている。剣にはスロットがあり、ジェムが1つ入る。敵の属性に合うジェムを入れないと攻撃が通らない」。
- ドパガキ仕様も忘れずに。ジェムの紹介は「スマブラの参戦」のようなカットインで（見た目はオリジナル）。

## v1〜v4 で外れたこと（2026-11-14 の指摘）
- v1「ゲームとしても学習としても成立していない」。v2「紹介はボタンを押すだけで頭に入らない」「理由もわからず -ción を押していくだけ」。v3「『本当に』は、何を言う語？ が日本語として分からない」「問題が何を答えさせたいのか分からない」「きまりの説明が長い」。v4「el? la? が唐突」。
- 依頼者の言葉：「なぜそうなるのか、複数の選択肢の中から正しいものが選べるのか、正解をきちんと記憶できるのか、が絶対に必要」「付け焼刃の修正じゃなくて、どうやって学習させるかに立ち返って基本から」。
- 原因〔AI の整理〕：画面と問題の形を先に作り、学ばせ方を後から当てはめていた。そのため、問題が直前に教えたことから出ていなかった（唐突）。**ゴール（何ができるようになるか）→ 学ぶ順 → 1回の流れ → 問題、の順に決める**。どの問題にも「直前に教えたのはどれか」を対応させる。

## ゴール
- **使う**：文の空所に合う形を選ぶ（rápido か rápidamente か rapidez か）。試験の空所問題と同じ力。→ 戦い
- **読む**：知らない語から語尾を外して、元の語から意味を推す。→ 戦利品の鑑定
- **語尾についてくるきまり**：-dad・-ción・-ería は la、-mente は -o を -a にして、-ista は男女同じ形。→ ジェムの力（きまり）と、文の中の la ＋ 空所

## いまの作り（v5）
- **対応**：武器＝元の語（武器の種類＝品詞：🗡 剣＝形容詞／🪄 杖＝動詞／🪓 斧＝名詞）。ジェム＝語尾（はまる武器が決まっている）。敵＝空所のある文。**弱点＝空所に入る語の種類**（🎨 説明／🌀 ようす／📦 もの・こと／⚡ 動作／👤 人・道具／🏠 店）。
- **「武器 × 弱点 → ジェム」が1つに決まる**。ジェムなし（そのまま）も選択肢なので、ジェムが1つの1章から「選ぶ」が成り立つ（v1 の失敗への答え）。例外は -ista と -ero（どちらも斧の「人」）で、語ごとに覚える。教材チェックが「同じ武器で弱点が重なる形がない」ことを確かめる。
- **章（ジェム1つずつ）**：宝箱 → 参戦カットイン（名前だけ。力はまだ見せない）→ 知っている武器3本にはめて、意味を予想（採点しない。L26）→ **ジェムの力**（表：同じ武器にはまる持っているジェムを、なるべく同じ元の語でならべる「そのまま real＝説明／＋-mente realmente＝ようす／＋-dad realidad＝もの」。新しいジェムの行を金の枠に。その語にない形は、ほかの語の例で。きまりの文は最後に1行。見る順、原則21）＋ その章で初めて出る弱点の**見分け方**（きまりの文ではなく、その章の敵の文を1つ見せて手がかりを指す）→ 戦い（弱点が見える＝足場）→ **ボス**（弱点は隠れる。💡 で見られるが自力に数えない。前の章の形も混ぜる＝見分けの練習 L12 L14）→ **ボスの落とし物**（とどめの理由を読んだあと、自分で「つぎへ」→ 巻物が落ちる → 「拾って読む」。自動で進めない）→ 鑑定 → 結果。
- **見直し（2026-11-14 の指摘「ボスのあとのジェム回収が唐突」）**：ボスをたおすと3秒で鑑定の画面に切りかわっていた。何が起きたか（ボスが語を落とした）と、なぜ読むのか（習っていない語でも、ジェムを外すと知っている語が出てくる）を、ルスのせりふで先に言う。鑑定の選択肢は、考えずに消せる語を入れない（元の語の意味＝ジェムを足し忘れた答え・同じ元の語のほかの形・同じジェムのほかの語）。ジェムが1つの章では「どのジェム？」と聞かず「タップして外そう」。外したジェムには弱点と意味（〜に・〜く）を添える。
- **斬ったあと**：文が埋まり、訳も埋まる。「🔎 手がかり → 弱点 → 武器＋ジェム → できた語（意味）」の順（原則19）。はじかれたら「✕ あなたの形＝その弱点」を上に（L25）。その回の最後にもう一度。
- **はまらないジェム**（-ción を剣に）は「はまらない」と知らせる。品詞のきまりを覚える場面なので、その敵は自力に数えない。
- **記憶**：形ごとに 1・3・7・14・30日（L6 L8。日数は設計上の値〔推論〕）。見回り＝戻ってきた敵（弱点は隠れる）。はじかれた形はジェムごとに 🩹 おさらい（ジェムの力 → リベンジ。あとの回で自力で正解すると消える）。
- **導き役ルス**（依頼者の案 2026-11-14「導くキャラがいてもいい」）：フクロウの、ジェムの目きき（オリジナル）。画面上の案内はすべてルスのせりふ（ホームのひとこと・宝箱・はめてみる・ジェムの力・戦い・ボス・鑑定）。斬ったあとは「見事！理由も見ておこう」「はじかれた。どこがちがったか見てみよう」と、下の理由へ目を向けさせる。ルス自身は動かさない（目線は問題に。原則の目線の誘導）。何体目かはせりふに入れず、上のバーで見せる（せりふを2行までにして、問題の位置がずれないように）。
- **大きさ**（依頼者 2026-11-14）：学習の本体は「問題文の空所に合う形にする」なので、問題文がいちばん大きい（29px・空所は金の枠）。武器の札は小さめ（語 19px）。
- **見た目**（依頼者 2026-11-14「武器とジェムは SVG で、RPG 風のかっこいいやつ。スロットの画面は昔の RPG のメニューのように」）：pega/js/art.js に手描きの SVG。剣（鋼の刃・金の鍔・革の柄）／杖（木の柄・金の爪）／斧（三日月の刃）は横向きで、ソケットは鍔・杖の頭・斧の根元に1つ（id="sock"。ジェムはここへ飛ぶ）。ジェムは八角形のブリリアントカット（色1つ＋白黒の半透明で面の明暗）。武器の札・ジェムの棚・ホームのジェムの帯は、青のグラデーションに白いふちのウィンドウ（.win）。選んでいるジェムに ▶ のカーソル。文の中の武器のしるしも小さな SVG。斬ったら棚はたたむ（文と理由に場所をゆずる）。見た目はどれもオリジナル。

  - **武器の意匠＝そのまま使ったときの弱点**：剣（🎨 説明）＝絵筆と色（柄頭が筆の穂先・虹色の刃紋・鍔に絵の具の3色）。杖（⚡ 動作）＝稲妻（頭は2本の稲妻の爪・柄に稲妻の彫り・先に火花）。斧（📦 もの）＝石と箱（四角い石の刃・根元は立方体の金具）。
  - **ジェムのカット＝はめたときの弱点**：🌀 ようす＝しずく／📦 もの・こと＝四角／👤 人＝横顔を彫ったカボション／🏠 店＝家の形／🎨 説明＝絵の具をのせたカボション。色だけでなく形でも見分けられる。

## 分かっている弱み
- -ista と -ero は、きまりだけでは決めきれない（目安：スポーツ・芸術・楽器・専門の仕事は -ista、パン・手紙・料理・靴など身近な物をあつかう人は -ero）。
- 1章の鑑定は、持っているジェムが1つなので「外す」は押すだけ（意味の予想が本体）。
- 敵の文の手がかりは文ごとに手書き。「es ___」は説明（形容詞）にも人（名詞）にもなるので、手がかりは文の意味まで書く。
- 語の級は目安（西検は公式の単語リストを公開していない）。iPhone・Android の実機の手ざわり・音は未確認。
