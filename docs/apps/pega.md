# ¡PEGA!（pega/）— 語尾タイルを貼って単語をふやす

私用。西検4級まで1か月の時点で作った。**負担を軽く**（物語なし・1回2分ほど）。
チェック：`node tests/check-pega.js`（`--words` で単語帳にない語）。動作確認：`pega.html?sandbox`（`__pega.seeAll()`・`__pega.reset()`・`__pega.peel(id)`）。

## 決めたこと（依頼者）
- 語尾はしぼる：**-mente・-dad／-ción・-dor／-oso・-ista／-ero・-ería**。-dor は依頼者が足した。-ísimo は入れない〔経験則〕
- ストーリーより、サクサク。語尾の種類が自然と見分けられるように〔経験則〕

## v1・v2 で外れたこと（2026-11-14 の指摘）
- **v1**：「ゲームとしても学習としても成立していない」。語尾ボタンを押していくだけ。
- **v2**：「単語の紹介がただボタンを押すだけで何も頭に入らない」「問題は理由もわからず -ción を押していくだけ」。
- 原因〔AI の整理〕：①語尾を1つずつ入れたので、最初の段階では棚に押せるタイルが1枚しかなく、「選ぶ」が成り立たなかった（原則2）。②紹介は「光るタイルを押す」＝受け身（原則3）。③「なぜその語尾か」を問う場面がなかった（原則16・19）。
- 依頼者の言葉：「なぜそうなるのか、複数の選択肢の中から正しいものが選べるのか、正解をきちんと記憶できるのか、が絶対に必要」。

## いまの作り（v3）
- **語尾は2枚ずつ、くらべて入れる**。1段階＝同じ元の語の組（real → realmente／realidad、organizar → organización／organizador、pan → panadero／panadería）。最初から「選ぶ」が成り立つ。
- **入荷（紹介）**：2つの語を「元の語〔品詞〕＋タイル → できた語」で並べ、「『本当に』はどっち？」を選ぶ（初めての段階は予想・採点しない。L26）→ 2語それぞれの理由「real は形容詞。-mente は『どんなふうに』を言うタイル → realmente＝本当に」→ 初めての段階はきまり（英語の -ly・-ty などの対応も）。見る → 選ぶ → 理由 → きまり の順（原則21）。
- **注文（採点）**：「つくる」は2手。**手1「その意味は何を言う語？」**（どんなふうに／もの・こと／人／どんな〜／店）→ **手2「元の語〔品詞〕に貼るタイルは？」**（棚の役割の字は隠す。💡 で開くと自力に数えない）。まちがえたら「✕ あなたのタイル → できる語」と「○ 何を言う語 × 元の語の品詞 → タイル」をならべる（L25）。ほかに 意味の4択（同じ元の語の別の語尾をはずれに）・el／la・つづり（-a に変える・-tad など）・文に合う形。
- **記憶**：まちがえた注文はその回の最後にもう一度。語ごとに 1・3・7・14・30日で戻す（L6 L8。日数は設計上の値〔推論〕）。まちがえた語は語尾ごとに 🩹 おさらい（きまり → リベンジ）。
- **初見チャレンジ**（採点しない）：習っていない語から語尾タイルをはがして意味を読む（peligrosamente は2枚）。
- 演出：貼り合わせの音・パーティクル・コンボ（5で FEVER＝XP2倍）・XP とレベル。演出は待ちにしない（正解のあとは自動で次へ）。

## 分かっている弱み
- -ista と -ero（どちらも名詞＋人）は、きまりだけでは決めきれない。理由は「-ista＝それをする人（スポーツ・芸術・楽器）、-ero＝物を作る・売る人」で、語ごとに覚える部分が残る。
- -oso と -ista は、同じ名詞から両方できる4級の語がないので、ちがう名詞どうしでくらべる（`nopair`）。
- 語の級は目安（西検は公式の単語リストを公開していない）。iPhone・Android の実機の手ざわり・音は未確認。
