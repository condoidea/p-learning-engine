# ¡PEGA!（pega/）— 語尾（接尾辞）で単語をふやす

私用。西検4級まで1か月の時点で作ったので、**負担を軽く**が前提（物語なし・1回1〜2分・70語）。

## 決めたこと（依頼者）
- 語尾は数個にしぼる（覚えきれないので）。**-ción・-dad・-mente・-oso・-ista・-ero／-ería・-dor の7つ**。-dor は依頼者が足した。-ísimo は入れない（4級の範囲に明記されているか未確認。語彙をふやす効果も小さい）〔経験則〕
- ストーリーを追うより、サクサクこなす。語尾の種類が自然と見分けられるように〔経験則〕

## 作り
- **1回＝あたらしい5語**：カードをタップして語尾をくっつける（見る）→ はじめての語尾は「何になった？」の予想（採点しない）→ きまり → すぐ問題（原則1・21）
- **問題は4つ**：くっつける（元の語＋作りたい意味 → 7つの語尾ボタン）／意味の4択／el・la（-ción・-dad・-ista・-ería）／-mente の形（-a に変えてから）
- **語尾ボタンは場所と色がいつも同じ**。まだ習っていない語尾は「？」で押せない。あたらしい回にも、前の語尾の語を2つ混ぜる（見分けは混ぜて練習。原則27）
- まちがえたら、その回の最後にもう一度（原則25）。語ごとに 1・3・7・14・30日で復習〔日数は設計上の値・推論〕
- 正解のあとの待ちは、タップで飛ばせる。終わりは一覧を見せて止まる（自動で次へ流さない。原則35）
- 読み上げは単語だけ

## 分かっている弱み
- どの語にどの語尾がつくか（-ista か -ero か）は、きまりでは決まらない。見た語を思い出す問題になっている
- 語の級は目安（西検は公式の単語リストを公開していない）。語は `pega/js/data.js`、チェックは `node tests/check-pega.js`
- 語は `shared/es-words.js` に登録していない（文を出さないので、意味はデータに直接書いた）
- 動作確認は `pega.html?sandbox`（`__pega.seeAll()` で全部出会った状態、`__pega.reset()` で最初から）
