# ¿QUIÉN FUE? 下町新聞の事件記者（quien.html・スペイン語の受身と se の使い分け）で試したこと（2026-11-04）

> ¿QUIÉN FUE?（スペイン語の受身と se・西検4級）。独立アプリ。`quien.html` ＋ `quien/`
> チェック：`node tests/check-quien.js`（`--words`）。通しテスト：`tests/e2e-quien.js`。動作確認：`quien.html?sandbox`

ユーザー（私用）「受身表現と、似た形（再帰・一般に言われることを se ＋動詞で表すやつ）との区別が苦手」「探偵もの（A案）を中心に。図で見せる案はなし、理屈から理解したい派」「動物に寄りすぎず、新聞で単語を広く」「テスト対策（西検4級）が目的なので、見出しのような特殊な短縮文に寄りすぎない」「60秒ドリルは、時間切れでも最後の1問は解くまで終わらない」。¡PROTESTO! と同じ台本の形（取材＝インプット → 対決＝アウトプット）の独立アプリ（`quien/`）。

| 変えたところ | 中身 |
|---|---|
| 中心の問い | どの文にも「**やった人は？**」を問う。受身・se の文は「やった人を文から消す」言い方なので、事件記者の「犯人さがし」と文法の見分けが同じ操作になる。答えは8つの仮面（por のあとの人／だれか／問わない（様子）／人はだれでも／本人が自分に／おたがいに／ひとりでに・うっかり／se は「彼に」）＝ se の種類と1対1 |
| 理屈 | **見分けの手順**（`QF.flow`）を話ごとに1段ずつ足す（ser＋過去分詞 → estar＋過去分詞 → se＋物 → 主語なし → 主語が人 → ひとりでに → se lo）。新しい形の note には必ず `why`（受身の se は「物が自分を売る」から、無人称は主語がないから単数、se me の me は困った人、le lo → se lo は言いにくさから） |
| 新しい操作 | **現場ボード**（`who`：やった人の仮面を選ぶ。その話までに習った仮面だけ）、**決め手の語をタップ**（`tap`：venden の -n が合う語・a・por・me など「なぜそう言える？」の根拠を文の中から）、**赤ペン**（`redpen`：見習いの原稿のまちがった語をタップ → 直す語を選ぶ。試験に出るまちがい：Se vende pisos、Se buscan a…、Le lo di） |
| 練習 | ⏱ **即答ドリル**（60秒で何問。やった人を選ぶ問題と空所の問題。**時間切れのときに解いている1問は答えるまで終わらない**。まちがえたら「手順のどこで分かるか」と、その話のノートを開くボタン）、🎓 **西検模試**（全話クリアで。分野ごと7分野・20問・答え合わせは最後・70%で合格・弱い分野のノート）、🗂 単語の復習（¡PROTESTO! と同じ） |
| 選択肢 | ドリルの空所・模試の選択肢は**表示のたびに順をまぜる**（書いた順のままだと正解の位置で覚えてしまう） |
| 見た目 | 新聞の紙面：新聞用紙＋網点、墨、特色の赤だけ。見出しは Playfair Display、スペイン語の文は Source Serif 4、日本語は Zen Old Mincho。叩きつけ文字は赤い二重枠のゴム印、事件の終わりは「号外」の一面が刷り上がる |

- 台本は第1話を自分で書き、第2〜7話・ドリル・模試を Sonnet のサブエージェントに並行で書かせた（共通ルールのメモ＋第1話を見本に）。**同じ名前の別人（マルタ×4）**が出たので、名前の重なりは最後に洗う。サブエージェントのファイルに**文字列の中の生の改行**（構文エラー）が混ざったことがあった → `node tests/check-quien.js` は全ファイルを読むので、1つ壊れると全部止まる
- スペイン語の不自然な文（empezar un rumor、odiarse con、不特定の人に a）は最後に目で洗った
- **一足飛びの見直し（原則22）**：全7話を見る順に書き出して読み、次を直した。①まだ教えていない文法用語（他動詞・自動詞・能動）→「〜を…する」「〜が…する」「やった人を主語にして」と言いかえる ②「a が付く人／付かない人」の理由がなかった → 決まった人（この2人）には a、だれでもいい人には付かない、を足す ③まだ出ていない人の名前を問題に出した（パスさん）④問いの手がかりがまちがっていた（「主語＝se のあとの語」→「動詞が合わせている語」）⑤名前を変えたあとの古いヒント（a dos camareros）⑥ estaba ＋過去分詞を「いまの様子」と書いた ⑦根拠とつながらないセリフ ⑧画面の名前の不一致（西検チャレンジ／西検模試）。サブエージェントの台本は、読む順に書き出すスクリプトで1本の文にして読むと見つけやすい
- 教材チェック `node tests/check-quien.js`（単語帳・正解の番号・メモの get・仮面がその話までに習ったものか・tap/redpen の語が文にあるか・ドリルと模試の形）。`--words` で単語帳にない語。通しテスト `tests/e2e-quien.js`（`quien.html?sandbox` で `quienE2E(['c1',…])`）
