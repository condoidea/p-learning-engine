# ¡QUE FUSIÓN!（relativo.html・スペイン語の関係詞）で試したこと（2026-10-20）

> ¡QUE FUSIÓN!（スペイン語の関係詞・西検4級）。独立アプリ。`relativo.html` ＋ `relativo/`
> チェック：`node tests/check-relativo.js`（`--memo` で単語メモを書き出す）。ブラウザの通しテストはなし。動作確認：`relativo.html?sandbox`

ユーザー「化学はちょっと控えめだったから、もっと全力で（ドパガキ仕様）」。文法1つ（関係詞）を **1日30分×7日** で回る分量に。エンジンとは別の独立アプリ（`relativo/`）。

| 変えたところ | 中身 |
|---|---|
| 中心の操作 | **文の合体（FUSION）**：2つの文で「かぶっている名詞」をタップ → que に変身して文の頭へ → 1文に合体。前置詞つきは「前置詞ごとタップ」で、**名詞だけが que に変わり冠詞は残る**（en el restaurante → en el que）のを目で見せる＝冠詞の性・数を先行詞に合わせる理由になる |
| 色の約束 | 先行詞＝水色・関係詞＝ピンク・前置詞＝黄色。例文では関係詞から先行詞へ矢印（弧）が伸びる |
| 問題の形 | 空所を選ぶ／先行詞をタップ／まちがい探し（語をタップ）／que の正体（関係詞・接続詞・疑問詞）／意味を選ぶ／タイルを並べる／正しい合体を選ぶ。問題バンク 126問 |
| ごほうび | XP・レベル・称号、コンボ（3で NICE、5で **FEVER**＝XP2倍・虹色の画面）、ボス戦（HP・ライフ3・速く正解でクリティカル・S/A/B ランク）、60秒ラッシュ（ハイスコア）、**フレーズガチャ**（例文カード N〜SSR、ボスを倒すと UR）、今日のミッション、連続日数 |
| 復習 | 問題ごとに間隔反復（1・2・4・7・15・30日、まちがえたら10分後）。復習は期限切れ → 苦手 → 未出題の順 |
| 単語 | 例文の語はすべて共通の単語帳 `shared/es-words.js` に登録（ないとチェックでエラー）。4級以上の語は点線バルーン。**どの語を何回使ったかは docs/vocab/スペイン語単語メモ.md**（次のスペイン語アプリで、復習に使う語・被らない新しい語を選ぶため） |

- 英語経験者のワナを先に Tips に：que は省略できない／前置詞を文末に残せない／限定（コンマなし）で quien は使わない／donde は「〜で」のときだけ（「〜を」なら que）
- Tips には全部「🤔 なぜ？」をつけた（原則16）。Tips ノートでいつでも読み返せる
- ガチャのカードは集めるだけにしない（ユーザー「集めたカードは何か役に立つの？」）：図鑑のカードから **🎧聞き取り**（音声を聞いて3文から選ぶ。声のない端末は日本語訳から選ぶ）と **🧩並べ替え**で練習できる。まだ練習していないカードから出る。レッスンごとに5枚そろえると 🎟+3・+50 XP
- 「迷ったらこの形」だけでは試験に足りない（ユーザー「テストは『適切ではない形を選べ』が出る。話せる最低限ではなく4級を解ける知識に合わせる」）→ L5 に **OK・NG 表**（前置詞のあり・なし × コンマ × もの／人 で、que・冠詞＋que・quien の○✕△）を Tips として入れ、その前に NG の形（人＋前置詞＋冠詞なし que、名詞のすぐ後ろの el que）を予想の問いで見せる。問題の形に **ng（入らないものを選ぶ）** を足した。OK を選んだときは「それは入る。入らないのは○○」と出す
- **まちがえたら、自分の答えと正解をならべて見せる**（ユーザー「まちがった選択肢が消えると、何がまちがったのか分からない。全体的に。全講座に関係するかも」）：✕ あなた／○ 正解 の2行で、ちがう語だけに色（文どうしは語の最長共通部分列で差分、並べ替えは位置のずれ）。選んだ選択肢はトークの吹き出しにも残す。ラッシュのように途中で見られない形は、結果画面に「まちがえた問題を見直す」で全部ならべる
- **使い分けは「原因 → 結果」で教え、その場で見えないものを参照しない**（2026-11-01 作り直し。ユーザー「『表の○行目』と言われても、その表をそこで見られない」「この理由だからこの形が使える、という理由と結論・原因と結果の対比がはっきりしないとだめ」「donde も対象に」「このアプリ全体をやれば西検4級の関係詞の問題が解けるレベルまで育てる気合で」）
  - 新しいレッスン「L6+ 使い分けマスター」（id L11・`label: '6+'`）：**1か所だけちがう2文**（`pair`）で「どっちが ✕？」→ 両方の文の下に「原因」「結果」のラベルつきで出す。並べたまま残るので対比が見える
  - ○✕ジャッジ（`relativo/js/data/dojo.js`・37文、donde の「〜で／〜を」も）：先に**手がかり**を自分で選ぶ（①先行詞は人・もの・場所 ②前置詞は要る？ 動詞とのペア hablar con 〜 などで決まる）→ そのあと形ごとに ○✕。各行に「原因 なので → 結果」。きまりのまとめは問題の「📋 きまり」でその場で開ける（表の行番号は出さない）
  - 🩹 おさらい（原則23）：復習・道場・ボス・ラッシュ・西検チャレンジでまちがえた問題をレッスンごとに記録。まちがえたその場で「📖 L○ の要点」（そのレッスンの Tips・表・きまり）、結果画面とホームで「🩹 おさらい」（例文・合体・くらべる2文・予想の問い・Tips・** の説明だけを回り直し、最後にまちがえた問題へリベンジ。正解で記録から消える）。ホームでは次のレッスンより先に出し、「あとで」も選べる
  - 🎓 西検チャレンジ：試験と同じ形（空所・入らないもの・正体・まちがい探し・意味）の20問を分野ごとに出し、答え合わせは最後。分野ごとの正解数と、弱い分野の「L○ をもう一度／道場」ボタン。合格ライン 70%
- 「なぜ？」は開いたときに単独で読む文章。前の文を受ける「だから」「そう」で始めない
- quien のコンマの説明は「ちなみに情報」では伝わらなかった → 日本語の（かっこ）の説明として、例文 → 消しても通じる？ → 区別のため？ → 結論、の順に
- **説明の順の見直し（2026-11-10）**：L1「que が主語にもなる」は例の前に結論を言っていた → 合体を見せてから「本**を**」「電車**が**」をくらべる。L5 は、L2 で「人の a は消える」と教えたのに al que が説明なしで出ていた → 「a を残すなら冠詞つき」を先に。OK・NG 表の「前置詞なしの冠詞＋que は ✕」を、表の前に予想の問いで見せる。del que も本文で。L6 は「〜で なら donde」のあとに「ホテル**に**」が出てずれた → 「戻して en がつくなら donde」。L7 は lo que の結論から始まっていた → 例文 → 「que の前に名詞はある？」→ lo que。**前のレッスンで教えたきまりと食いちがって見える形が出たら、その場でつなぐ**
