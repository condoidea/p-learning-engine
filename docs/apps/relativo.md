- 英語経験者のワナを先に Tips に：que は省略できない／前置詞を文末に残せない／限定（コンマなし）で quien は使わない／donde は「〜で」のときだけ。Tips には全部「🤔 なぜ？」をつけた（原則16）
- ガチャのカードは集めるだけにしない（ユーザー「集めたカードは何か役に立つの？」）：図鑑から **🎧聞き取り**と **🧩並べ替え**で練習できる。レッスンごとに5枚そろえると 🎟+3・+50 XP
- 「迷ったらこの形」だけでは試験に足りない（ユーザー「テストは『適切ではない形を選べ』が出る。話せる最低限ではなく4級を解ける知識に合わせる」）→ L5 に **OK・NG 表** を Tips として入れ、その前に NG の形を予想の問いで見せる。問題の形に **ng（入らないものを選ぶ）** を足した
- **まちがえたら、自分の答えと正解をならべて見せる**（ユーザー「まちがった選択肢が消えると、何がまちがったのか分からない。全体的に。全講座に関係するかも」）：✕ あなた／○ 正解 の2行で、ちがう語だけに色。ラッシュのように途中で見られない形は、結果画面に「まちがえた問題を見直す」で全部ならべる（出典：誤答の訂正 L25）
- **使い分けは「原因 → 結果」で教え、その場で見えないものを参照しない**（2026-11-01 作り直し。ユーザー「『表の○行目』と言われても、その表をそこで見られない」「この理由だからこの形が使える、という理由と結論・原因と結果の対比がはっきりしないとだめ」「donde も対象に」「このアプリ全体をやれば西検4級の関係詞の問題が解けるレベルまで育てる気合で」）
  - 新しいレッスン「L6+ 使い分けマスター」（id L11）：**1か所だけちがう2文**（`pair`）で「どっちが ✕？」→ 原因・結果のラベルつきで並べて出す
  - ○✕ジャッジ（`relativo/js/data/dojo.js`・37文）：先に**手がかり**（①先行詞は人・もの・場所 ②前置詞は要る？）を自分で選ぶ → 形ごとに ○✕。きまりのまとめは問題の「📋 きまり」でその場で開ける
  - 🩹 おさらい（原則23）と 🎓 西検チャレンジ（合格ライン 70%）の作り方は型.md
- 「なぜ？」は開いたときに単独で読む文章。前の文を受ける「だから」「そう」で始めない。quien のコンマの説明は「ちなみに情報」では伝わらなかった → 日本語の（かっこ）の説明として、例文 → 消しても通じる？ → 区別のため？ → 結論、の順に
- **説明の順の見直し（2026-11-10）**：L1「que が主語にもなる」は例の前に結論を言っていた → 合体を見せてから「本**を**」「電車**が**」をくらべる。L5 は L2 で「人の a は消える」と教えたのに al que が説明なしで出ていた → 「a を残すなら冠詞つき」を先に。L6 は「〜で なら donde」のあとに「ホテル**に**」が出てずれた → 「戻して en がつくなら donde」。L7 は lo que の結論から始まっていた → 例文 → 「que の前に名詞はある？」→ lo que。**前のレッスンで教えたきまりと食いちがって見える形が出たら、その場でつなぐ**
