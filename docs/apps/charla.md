# CHARLA（charla.html・charla/）— 会話を 聞く・書く・まねる

TTS で作ったスペイン語の会話（音声＋台本）を、学習向けに聞く**道具**。ゲームの要素（XP・演出・ごほうび）は入れない（依頼者の指定）。私用。2026-11-18 に作った。

## できること
- **🎧 聞く**：台本を見ながら聞く。いま読んでいるセリフが明るくなり、見える位置へ送られる。
  - **セリフをタップ** → そのセリフの頭から再生し、そのセリフを **AB 区間**にしてくり返す。`＋次` で次のセリフまで広げる、`✕` で消す。
  - 🔁 なし／全体／AB、速さ（0.6・0.75・0.85・1.0・1.15。声の高さは変えない）、⟲ 2秒戻し、⏮⏭ セリフ単位。
  - 文字を**隠す**（語の長さの棒だけ。👁 でそのセリフだけ見る）、訳あり／なし。
- **✍️ 書き取り**：**書くのは紙。アプリは再生の操作だけ**（スマホで文字を打つ書き取りはしない＝依頼者の指定）。1セリフずつ「聞く → 書く時間（セリフの長さ×2〜4）」を回数（1〜3）ぶん → 答えを見る。
  - 答え：**書いたら**（回数ぶん聞き終えたセリフだけ文字が出る）／隠す（👁 で見る）／見せる。
  - 次へ：**止まる**（そのセリフで止まり「▶ もう一度・⏭ 次のセリフ」）／自動。
  - ⟲ 2秒：聞いている途中はセリフの中で2秒戻す。書く時間・止まっているときは、セリフの最後の2秒をもう一度（回数には数えない）。
- **🗣 シャドーイング**：1セリフずつ「聞く → あなたの番（セリフの長さ×間）」を回数ぶん → 次のセリフ。
  - 回数 1〜3、間 ×1／×1.5／×2（速さを落とすと間も長くなる）。
  - 役：A／B になる → そのセリフは先に「あなたの番」、そのあとお手本を1回。
  - 文字：見せる／**聞いたら**（1回聞いたセリフだけ見える）／隠す。
  - 🎙 録音：あなたの番のあいだ録音し、セリフの右の「▶自分」で聞き比べる（その場だけ。保存しない）。
- **語の意味（バルーン）**：金の点線の語（覚えたい語・言い回し）はいつでも、調べる価値のある語（このダイアログ用に意味を書いた語と、共通単語帳の4級・3級の語。5級・機能語は除く）と言い回しにも**どのセリフでも薄い点線**。**点線の語のタップは意味だけで、再生には触らない**（語を調べたいだけなのに AB が始まるのはストレス＝依頼者 2026-11-19。線が多いのは邪魔ではない）。点線のない語も、いま聞いている（AB の）セリフの中なら意味。セリフの再生は、話し手の名前・番号・点線のない所のタップ。それ以外の所のタップはセリフの頭出し。🔊 は語だけ読み上げ（文は読み上げない＝ダイアログの音声で聞く）。
- **📒 調べた単語**：バルーンを開いた語を記録（冠詞・前置詞は記録しない）。チェックして**単語アプリの参考書のデッキへ送る**（💬 の区間として。取り消せる）。

## 単語アプリへの送り方（参考書のデッキに混ぜて、区別できる形で）
- **送り先は、単語アプリに読み込んだ参考書のデッキ**（`vocab/js/decks.js`）。アプリを切りかえずに参考書の語と一緒に出題されるように（依頼者の指定。¡VAMOS! の組み込みデッキは使っていない）。📒 の下の「送り先」でえらび、覚えておく。参考書のデッキがなければ CHARLA だけのデッキ `charla`。
- **区別**：1ダイアログ＝デッキの1区間（区間 id＝`charla-<ダイアログの id>`、名前＝「💬 1 La paella desaparecida（消えたパエリア）」、`ref: "CHARLA"`）。語の id は `charla-…`、`ref`＝「セリフ12」。単語アプリの「範囲」で 💬 の区間だけ・参考書の課だけにも絞れる。カードの出どころは 📗 でなく「💬 …・セリフ12」。
- 1語の形：例文＝そのセリフ（語を `{ }` で囲む）、訳＝セリフの訳、手がかり＝notes の `clue`（なければ場面 `sceneJa` の `ctx`）、`memo`＝会話の中の形（「会話では compruebo（…）」）と notes の `note`。動詞のくせ `cj` も渡す。
- **送り先のデッキにもうある語**（参考書の語）は「📗 送り先のデッキにもうある」と出し、送れない（同じ語のカードが2枚にならないように）。
- **取り消す**：送った語には「取り消す」。デッキから外し（区間が空になれば区間も）、その語の育ち具合も消す（育っていたら確認を出す）。まちがえて送ったとき用（依頼者の指定）。
- 参考書のデッキを**全部入れかえ**で読み込み直しても、`charla-` の区間と語は残す（`vocab/js/ui.js` の `keepTalk`）。「足す」はもとから残る。
- 送る前に単語アプリのチェック（`deck-check.js`）を通す。エラーなら送らない。
- 同じサイトの中なので直接書きこむ（ファイルのやりとりなし）。クラウド保存にログインしていれば、ほかの端末にも届く。
- `?sandbox` では `charla-sandbox` にだけ書き、デッキの一覧には載せない（`vocab.html?deck=charla-sandbox` で開ける）。

## 解説（guide.md）をどこで・どれだけ見せるか
シリーズに学習用の解説（`guide.md`）がつく。全部を読ませると情報が多すぎるので、**聞く流れの中で要る所だけ**を出す。
- **聞く前**：台本の頭に「🎯 聞き取りポイント」（あらすじ＋問い2〜3個）。目的を持って聞くと理解が上がる（pre-listening task）。🎧 聞くのときだけ。**何度も聞く道具なので、一度見ればよい情報は押しつけない**（依頼者の指定）：開いて出すのはそのダイアログを初めて開いたときだけ。2回目からは細い点線の1行で、タップすると開く。
- **聞いているとき**：訳は出さない（「訳 あり」で各セリフの下）。語の意味は点線の語・いまのセリフの語のバルーン。慣用表現・境目の語彙は notes.json の `key` で点線にしてある。
- **★**：解説が「くり返し練習したい」としたセリフ。番号の横に ★。✍️ 書き取り・🗣 シャドーイングで「セリフ ★だけ」にすると、★ のセリフだけを回る（ほかは薄く）。
- **聞いたあと**：📘（ヘッダー）でその話の解説。あらすじ・聞き取りポイントは開いたまま。**文法ノートは項目（`**見出し**` の行）ごとにたたみ、見出しの並びが目次**になる。その下に「表現と語彙」（慣用表現・語彙）。各項目の下に「本文：セリフ8・10…」→ タップでそのセリフをくり返して聞く。
- **このセリフの文法**：文法ノートの例（表の「本文の例」などの列と、文中の **太字**）を含むセリフに、小さく「文法」。タップで下から、その項目を出し、当たった表の行に色（再生は止めない）。「📘 解説」で全体へ。結びつけは `text.js` の `grammarTopics`・`linkGrammar`（説明の列＝分解・ポイント・働き・意味… は手がかりにしない）。
- **一覧**：シリーズの「📘 教材について」で、シリーズの説明。付録（伏線と回収）はネタバレなので閉じておく。
- 訳は guide.md の本文の表から取る（notes.json の `lines` は guide がないときだけ）。

## ダイアログを足すとき
受け取り方の約束（フォルダ・dialog.json の title・guide.md の書き方）は [ダイアログ音声の書き出し仕様.md の「渡し方」](../ダイアログ音声の書き出し仕様.md)。
1. `charla/dialogs/<シリーズ>/<id>/` に `dialog.json`・`audio.mp3` を置く。解説は `charla/dialogs/<シリーズ>/guide.md`。
2. 同じフォルダに **`notes.json`** を作る（下）。台本と guide.md（慣用表現・境目の語彙）から作れる。話ごとにサブエージェント（Sonnet）に分けて並行で作ってよい。
3. `charla/dialogs/list.js` の `CHARLA_SERIES` に1行足す（`no`＝第N話、`title` は NN を除いたもの、`titleJa`）。人名・地名はシリーズの `names` に。`courses/registry.js` の charla の `lessons` をダイアログの数に（`index.html`・`cloud.html` の `registry.js?v=` を上げる）。
4. `node tests/check-charla.js` でエラー0に。guide.md の本文とセリフの照合、意味のない語、送れない語、言い回しの空白ちがいを教えてくれる。代名詞つきの形（contarte・Ponla）の「活用形として作れない」は気にしなくてよい。

### notes.json の形
```json
{
  "format": 1,
  "sceneJa": "🛎 マドリードの小さな宿のフロント。着いたばかりの客と、受付の人",
  "names": ["Torres"],
  "phrases": [ { "t": "a nombre de", "ja": "〜の名前で", "key": true, "note": "予約のときの言い方" } ],
  "words": {
    "compruebo": { "w": "comprobar", "pos": "v", "ja": "確かめる・確認する", "key": true,
                   "form": "comprobar の「私は」（現在）。o → ue に変わる", "cj": { "stem": "ue" },
                   "clue": { "t": "cog", "text": "英語の prove・probe と同じ祖先" } },
    "reserva": { "w": "reserva", "pos": "n", "g": "f", "ja": "予約", "key": true }
  }
}
```
- `lines`：セリフと同じ数・同じ順の訳。
- `words`：**台本に出てくる形（小文字）**がキー。`w`＝見出し語（動詞は原形・名詞は単数・形容詞は男性単数）、`pos`（n v adj adv phr のほか prep pron art conj num int det interj）、名詞は `g`。`form`＝その形の説明、`note`＝補足、`key: true`＝点線（覚えたい語）。単語アプリ用に `clue`（[単語データの作り方](../vocab/単語データの作り方.md) の4種類。意味を書かない）と、規則どおりでない動詞の `cj`。
- `words` にない語は共通単語帳（`shared/es-words.js`）で引く（機能語など）。どちらにもない語はチェックでエラー。
- `phrases`：言い回し。語の並び（間は空白）が台本と一致したら1つの塊になる。長いものが先。
- `names`：人名・地名（意味を出さない）。
- 点線（`key`）は**覚えたい語だけ**に。多すぎると目が散る（原則20）。
- `sceneJa` は単語アプリの手がかり（ctx）にも使うので、**語の意味を書かない**（「夕方」と書くと tarde の答えがばれる → チェックが警告）。

## 決めたこと・理由
- **道具なので演出なし。** 色は話し手の2色とアクセントの金だけ。動くのは「いまのセリフ」の明るさと、あなたの番の残りの棒だけ（原則20・9）。
- **セリフのタップ＝頭出し＋AB**（依頼者の希望）。語の意味は点線の語と「いま聞いているセリフ」の中だけにして、タップの意味がぶつからないようにした〔推論〕。→ 点線を「いま」のセリフだけに出すと調べたい語に気づけず、語を調べたいだけで AB が始まるのがストレスだった（依頼者）。点線をどのセリフにも出し、点線の語のタップは意味だけにした（2026-11-19）。
- **隠すときは語の長さの棒を残す**：何語あるか・長さが見えるだけで、聞き取りの手がかりになる〔推論〕。
- **練習はアプリの外で**：書き取りもシャドーイングも、書く・話すのは本人が紙と声でやる。アプリは「どこを・何回・どれだけ間をあけて流すか」だけを受け持つ（依頼者の指定）。はじめは書き取りを文字入力＋採点で作ったが、スマホでの文字入力は不要とのことで外した（2026-11-18）。
- **書き取りとシャドーイングは同じしくみ**（1セリフずつ：聞く → 間 → 回数 → 次）。ちがうのは間の長さ（書く時間は長め）・止まるか進むか・答えの見せ方。
- **シャドーイングの間はセリフの長さに比例**、役になってから**お手本**：言ったあとにすぐ正しい形を聞ける〔推論〕。
- **点線を薄く**：最初は濃い金で、ほぼ全文に線が引かれて目が散った。薄くして、いまのセリフでだけ少し濃く。
- 語学プレーヤーの一般的な機能（AB くり返し・速さ・数秒戻し・文単位の移動・文字を隠す・書き取り・シャドーイング・録音の聞き比べ）を参考にした。学習効果の出典はまだ調べていない〔未確認〕。

## 時刻と余白
- `dialog.json` の `startMs`／`endMs` は声の約30ms前〜約60ms後（2026-11-18 に無音検出で確認）。アプリは前に 120ms、後ろに 250ms（次のセリフの頭は越えない）を足して区間にする（`PRE`・`TAIL`）。

## iPhone の注意（実機で確かめること）
- 画面を消すと、毎フレームの更新は止まる。AB の折り返しは `timeupdate`（約0.25秒ごと）で続けるので、少し行きすぎてから戻ることがある。シャドーイング・書き取りの「間」はタイマーなので、画面を消すと止まる・ずれることがある〔未確認〕。
- ロック画面の操作（Media Session）：再生・停止・戻す（2秒）・前後のセリフ。iOS で出るボタンは端末しだい〔未確認〕。
- 録音中はマイクのため、iPhone の音の出口が変わる（小さくなる）ことがある。イヤホン推奨。録音しない設定に戻すとマイクを手放す〔未確認〕。
