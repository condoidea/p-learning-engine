# ユーキ・クエスト（yuki.html・有機化学）で試したこと（2026-10-21）

> ユーキ・クエスト（有機化学）。独立アプリ。`yuki.html` ＋ `yuki/`
> チェック：`node tests/check-yuki.js`。画面の重なり：`tests/overlap.js`。動作確認：`yuki.html?sandbox`

ユーザー（私用）「有機化学って素材を組み合わせて魔法陣を作るみたい」→ 有機と勇気をかけた RPG。共通テストの基本（完璧は目指さない）。重視：①ゲームの面白さ ②盛り上がる演出（ドパガキ・厨要素）③学習の丁寧さ・役立つ Tips。まず序章（炭素の村）と 1章（炭化水素の草原）だけ。独立アプリ（`yuki/`）。

| 変えたところ | 中身 |
|---|---|
| たとえの芯 | **原子価＝魔法陣が光る条件**（手が1本でも余ると光らない）、官能基＝紋章、試薬と条件＝呪文カード、反応＝魔法の発動、系統図＝地図。たとえの言葉は ((呼び方)) にして、覚える言葉は本物（置換・付加・脱水） |
| 錬成 | くし形の台座（横5・上下3ずつ。環ができない）に C・O を置く。H は自動で数えて CH₃・CH₂・OH と略して表示（示性式に慣れる）。**曲げただけ・ひっくり返しただけは「同じ形だ！」**（つながり方で判定）＝異性体のわなを体で覚える |
| 詠唱の儀式 | 試薬と条件のカードを選んで発動。正しければ詠唱が1行ずつ流れ、**詠唱の言葉どおりに魔法陣の原子が動く**（「隣り合う H と OH を引き剥がし」で本当に抜ける）。説明は表に出さず、**魔法のスクロール**（反応式・ポイント・ひっかけ・🤔なぜ）にだけ書く（ユーザー「説明臭いとテンションが下がる」）。条件ちがいで別の反応になるもの（130℃ → エーテル）は「暴発！？」として発動させる |
| 音 | **属性＝反応の種類ごとの BGM**（⚡雷＝置換・🌪風＝付加・🏜砂＝脱水縮合）を Web Audio でその場で鳴らす（オリジナル曲・ファイルなし）。詠唱の行ごとに楽器が重なり、「顕現せよ」の直前に一瞬止めて爆発。**読み上げ**は Web Speech API で、画面の漢字とは別に**ひらがなの読み（y）**を読ませる（焔・器などの読みが機種でぶれるため）。読めない端末では文字だけで同じ時間待つ |
| 復習 | 呪文書：使うほど詠唱が短くなる（完全詠唱 → 詠唱短縮 → 詠唱破棄 → 無詠唱）、使わないと3日ごとに1段もどる＝間隔反復を世界観の中で見せる。復習詠唱でカードを選び直す |
| ボス | 序章：幻影ミラージュ（C₅H₁₂ の異性体3つを時間内に錬成。同じ形を作ると反撃）。1章：臭素の魔獣ブロモス（問題で攻撃・5秒以内でクリティカル・3連続で FEVER・詠唱封じ＝詠唱の穴埋め）。とどめは付加の詠唱で**ボスの赤褐色が消える**（臭素水の脱色そのもの） |

- **錬成の作り直し（ユーザー指摘 2026-10-21）**：最初は「台座をタップすると CH₃・CH₂ が勝手に出る」形だったが、①手のつながりは H−C−H の見た目で覚えたい ②勝手に正しいものが出ると判断がいらない ③タップより自分で組み立てる感がほしい、で作り直した。いまは**素材（C・O・H）を、原子の空いている「手」までドラッグ**（タップで選んで手をタップでも可）。H も自分でつなぎ、素材を使いきって手が全部うまったら光る。略した書き方（CH₃−CH₃）は、できたあとに示す
- **操作は練習させる**（ユーザー「タップを一回練習させないとわからない」）：最初の錬成（エタン）で、ドラッグ → タップ（H は数が多いのでタップが楽）を 🧭 練習として1手ずつ出す。水素の筆も、初めて出る錬成で練習させる。輪（環）にできない理由は、置こうとしたときと「🤔 四角い輪にしたら？」で説明する（C₄H₈ になる）
- **理由は数えて見せる**（ユーザー「輪にすると手が二本減る理由が分からない。片手落ちにならないように」）：C 4 つで手は16本 → つなぎ目1か所で2本使う → 鎖（3か所）なら残り10本＝C₄H₁₀、輪（4か所）なら残り8本＝C₄H₈、を問いにして本人に数えさせ、構造式の絵（ブタン・シクロブタン）も見せる。Tips「輪を1つ作ると H は2つへる（二重結合も同じ）」で 1章のアルケンにつなぐ
- **ごほうびは経験値とレベル**（ユーザー「HP のように見える MP が増えるのは変。RPG なら EXP」）：魔力 MP をやめて EXP と Lv（Lv n→n+1 に 60＋30n）。レベルで称号が変わり、上がったら LEVEL UP!
- **序章を通しての指摘（2026-10-22）**：①ボス戦で、もう作った形が分からない → 倒した分身の所とレッスンの「作った形」の棚に、その構造式を残す ②曲げただけの同じ形が NG になる理由が、その場で分かりにくい → C を全部置いた時点で「🔎 鑑定」：いちばん長い鎖に 1→n の番号をふり、枝の番号（と名前）を出す。作った形と同じなら H をつける前に ⚠ ③3 通り作る必然性がほしい → ミラージュを「3 体の分身・それぞれ別の形の魔法陣が弱点」に。完成すると魔法が飛んで分身を倒す ④名前は抜き出しの問題で正解しても全部覚えたとは限らない → **全部の組を合わせるマッチング**（1 回 5 組・タイム表示・まちがえた組はその回の最後に「おさらい」でもう一度）。名前↔C の数、名前↔分子式、枝の名前、異性体の名前↔構造式
- **BGM はキメの場面だけ**（ユーザー「学習シーンでは要らない。戦闘で魔法を詠唱するときとか、キメシーンに入るとわくわくする」）：地図・レッスン・錬成・カード選びは静か。詠唱が始まったら属性の曲が鳴って発動で最高潮、儀式が終わったら止める。ボス戦はボスの曲
- **練習は「冒険者ギルドの依頼」で**（ユーザー「RPG だからクエストは困りごとを解決する依頼形式が良い。ギルドや酒場で依頼を受ける。魔物退治・素材集め・護衛任務・探索」）：メインの話は増やさず、地図の章の下の「🍺 冒険者ギルド」の掲示板に依頼書を貼る（依頼人・困りごと・報酬）。問題は毎回作り直す（`data/side.js`）。⚔ 魔物退治＝構造式を見て名前を答えて戦う（バトル）、🧪 素材集め＝名前から錬成、🗝 探索＝部屋ごとに同じ物質か見分ける（旅程カード）、🛡 護衛任務＝道中の待ちぶせで反応の問題（旅程カード）。名前の問題は C₄〜C₆ の異性体を全部列挙し、曲げた・裏返した描き方をランダムに出す
- **スマホの実際の高さで作る**（ユーザー「ブラウザの上下の UI で短い。文字や UI が重なっている」）：iPhone の Safari で使える高さは 550〜660px くらい。この高さで全画面を開き、`tests/overlap.js` の `overlaps()` で重なりを数える。詠唱の文字は魔法陣の下に重ねる（直近3行）、錬成は「指示 → 魔法陣 → 素材 → 操作ボタン → 鑑定」と操作する物を魔法陣のすぐ下にまとめる、高さは dvh で縮む、短い選択肢は2列、結果のボタンは横並び
- **大きな分子の工夫**：H を自分でつなぐのは最初の数問だけ。慣れたら「水素の筆」（残りの手をまとめて H に。魔法陣を描く操作なので「詠唱」とは呼ばない）と、パーツ（CH₃＝メチル基、OH）で骨組みに集中させる。芳香族の章では**ベンゼン環をパーツ**にする予定（六角形を1つで置き、どの手に何をつなぐかを選ぶ）
- **見た目は中世ヨーロッパの RPG**（ユーザー希望）：テトラの話・Tips・地図・スクロール・カードは「羊皮紙にインク」、魔法陣は「暗い石板に金の光」、ボタンは金箔、地図のレッスンは封蝋、背景は石の城（レッスン中はうすく）。文字は明朝（Shippori Mincho）と Cinzel。飾りは縁と角だけ
- Tips は理由つき（HONC 1234、テトラ＝4＝テトラポッド、めったに えらくない プロの ぶた、オクタ＝オクトパス、低温は「ふたりで」高温は「ひとりで」）
- 教材チェック `node tests/check-yuki.js`：**詠唱のあとの分子の手の数**（C4・H1・O2…）を機械で確かめる。読みに漢字がないか、錬成の答えが同じ形になっていないか、テトラが3回つづけて話さないか
- 動作確認は `yuki.html?sandbox`。最初に「TAP TO START」を置いて、そのタップで音と読み上げを使えるようにする（iPhone はタップの中でないと声も音も出せない）
