# ユーキ・クエスト（yuki.html・有機化学）で試したこと（2026-10-21）

> ユーキ・クエスト（有機化学）。独立アプリ。`yuki.html` ＋ `yuki/`
> チェック：`node tests/check-yuki.js`。画面の重なり：`tests/overlap.js`。動作確認：`yuki.html?sandbox`
> 根拠の印は [根拠/README.md](../根拠/README.md)。

ユーザー（私用）「有機化学って素材を組み合わせて魔法陣を作るみたい」→ 有機と勇気をかけた RPG。共通テストの基本（完璧は目指さない）。重視：ゲームの面白さ・盛り上がる演出・学習の丁寧さ。まず序章（炭素の村）と 1章（炭化水素の草原）だけ。

| 変えたところ | 中身 |
|---|---|
| たとえの芯 | **原子価＝魔法陣が光る条件**（手が1本でも余ると光らない）、官能基＝紋章、試薬と条件＝呪文カード、反応＝魔法の発動、系統図＝地図。たとえの言葉は ((呼び方)) にして、覚える言葉は本物 |
| 錬成 | くし形の台座（環ができない）に C・O を置く。H は自動で数えて CH₃・CH₂・OH と略して表示。**曲げただけ・ひっくり返しただけは「同じ形だ！」**（つながり方で判定）＝異性体のわなを体で覚える |
| 詠唱の儀式 | 試薬と条件のカードを選んで発動。正しければ詠唱が流れ、**言葉どおりに魔法陣の原子が動く**。説明は表に出さず、**魔法のスクロール**（反応式・ポイント・ひっかけ・🤔なぜ）にだけ書く（「説明臭いとテンションが下がる」） |
| 音 | **属性＝反応の種類ごとの BGM**（⚡置換・🌪付加・🏜脱水縮合）を Web Audio でその場で鳴らす（オリジナル曲）。読み上げは漢字とは別に**ひらがなの読み（y）**を読ませる（読みが機種でぶれるため）。読めない端末では文字だけで同じ時間待つ |
| 復習 | 呪文書：使うほど詠唱が短くなり、使わないと3日ごとに1段もどる＝間隔反復を世界観の中で見せる（L6 L8。日数は設計上の値〔推論〕） |
| ボス | 序章：幻影ミラージュ（異性体3つを時間内に錬成）。1章：臭素の魔獣ブロモス（問題で攻撃・詠唱封じ）。とどめは**ボスの赤褐色が消える**（臭素水の脱色そのもの） |

## ユーザーの指摘と対応
- **錬成の作り直し**（2026-10-21）：最初は「台座をタップすると CH₃ が勝手に出る」形だったが、①手のつながりは H−C−H の見た目で覚えたい ②勝手に出ると判断がいらない ③自分で組み立てる感がほしい、で作り直した。いまは**素材（C・O・H）を、原子の空いている「手」までドラッグ**（タップでも可）。素材を使いきって手が全部うまったら光る。略した書き方は、できたあとに示す
- **操作は練習させる**（「タップを一回練習させないとわからない」）：最初の錬成で、ドラッグ → タップを 🧭 練習として1手ずつ出す
- **理由は数えて見せる**（「輪にすると手が二本減る理由が分からない。片手落ちにならないように」）：C 4 つで手は16本 → 鎖なら残り10本＝C₄H₁₀、輪なら残り8本＝C₄H₈、を本人に数えさせ、構造式も見せる（原則19）
- **ごほうびは経験値とレベル**（「HP のように見える MP が増えるのは変。RPG なら EXP」）：MP をやめて EXP と Lv
- **序章を通しての指摘**（2026-10-22）：①ボス戦でもう作った形が分からない → 倒した分身の所に構造式を残す ②曲げただけの同じ形が NG になる理由 → 「🔎 鑑定」（いちばん長い鎖に番号をふり、枝の名前を出す）③3 通り作る必然性 → 3 体の分身・それぞれ別の形が弱点 ④抜き出しで正解しても全部覚えたとは限らない → **全部の組を合わせるマッチング**
- **BGM はキメの場面だけ**（「学習シーンでは要らない。戦闘で魔法を詠唱するときとか、キメシーンに入るとわくわくする」）：地図・レッスン・錬成は静か。詠唱が始まったら属性の曲、発動で最高潮、終わったら止める
- **練習は「冒険者ギルドの依頼」で**（「RPG だからクエストは困りごとを解決する依頼形式が良い。ギルドや酒場で依頼を受ける」）：地図の下の「🍺 冒険者ギルド」に依頼書を貼る。⚔ 魔物退治（構造式から名前）・🧪 素材集め（名前から錬成）・🗝 探索（同じ物質か見分ける）・🛡 護衛任務（反応の問題）。問題は毎回作り直す（`data/side.js`）。曲げた・裏返した描き方をランダムに出す
- **スマホの実際の高さで作る**（「ブラウザの上下の UI で短い。文字や UI が重なっている」）：iPhone の Safari で使える高さは 550〜660px。この高さで全画面を開き、`tests/overlap.js` の `overlaps()` で重なりを数える
- **大きな分子の工夫**：H を自分でつなぐのは最初の数問だけ。慣れたら「水素の筆」（残りの手をまとめて H に）とパーツ（CH₃＝メチル基、OH）で骨組みに集中させる（慣れた人には省ける 原則30）
- **見た目は中世ヨーロッパの RPG**（ユーザー希望）：話・Tips・地図は「羊皮紙にインク」、魔法陣は「暗い石板に金の光」、ボタンは金箔
- Tips は理由つき（HONC 1234、テトラ＝4＝テトラポッド など）
- 教材チェックは**詠唱のあとの分子の手の数**（C4・H1・O2…）を機械で確かめる。動作確認は最初に「TAP TO START」を置いて、そのタップで音と読み上げを使えるようにする（iPhone はタップの中でないと出せない）
