- **形の作り方のルールは、1つの形に1つだけ**（2026-11-04 ユーザー「tú は s を取る／3人称と同じ、usted は a と e を入れかえる／yo の形から、と複数のルールがある。単純に覚えるものなので、いちばんシンプルなものだけに」）。tú＝**tú の形から s を取る**、usted＝**yo の形の o を取って -ar は e、-er・-ir は a**（不規則な yo の形 tengo → tenga もこれ1つで作れるので、「a と e を入れかえる」は使わない）。あとはすべて usted の命令から足し算：ustedes ＋n、「〜するな」＋s、「〜しよう」＋mos。別の覚え方（「彼は〜する と同じ」など）は、正しくても書かない。ルールが2つあると、どちらを使うか迷う
- **🗺 命令の地図：出発点が変わる文法には、1枚の全体図を**（2026-11-10 ユーザー「動詞の変化の説明に迷走があって、頭に入りづらい」）。原因は、形を作る出発点がレッスンごとに変わる（tú の形 → 原形 → 暗記 → yo の形 → usted の命令に足し算 → 原形）のに、全体図がなかったこと。あとから足した神託で usted の仲間がジグザグになっていたこと（L5 → L6 → L7 → L11）
  - 地図（`MQ.map`）：出発点3つ（tú の形・yo の形・原形）→ 枝（だれに・操作・できる形）。usted の命令から足し算で伸びる枝（ustedes・〜するな・〜しよう）は字下げ。例外（8つ・-oy の4つ・つづりの書きかえ）は小さい札
  - **きまりを自分で見つけた直後に書きこむ**（台本の `map` ステップ。hi の枝だけ光る）。前の枝から続ける神託は、冒頭で「地図のここから」と1回。1つの神託に多くて2回。まだ習っていない枝は「？？？ 第○の神託で」で中身を見せない

  - 例外の4つ（ven・ten・pon・sal）の「原形の2文字を取る」は覚え方で、出発点ではない（「今日の出発は原形」と書くと、vosotros の出発点と混ざる）
