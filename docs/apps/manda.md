# ¡MANDA!（manda.html・スペイン語の命令表現）で試したこと（2026-10-23）

> ¡MANDA!（スペイン語の命令表現・西検4級）。独立アプリ。`manda.html` ＋ `manda/`
> チェック：`node tests/check-manda.js`（`--forge` で鍛冶場の一覧）。通しテスト：`tests/e2e-manda.js`。動作確認：`manda.html?sandbox`
> 共通の教訓は [語学アプリの型.md](../語学アプリの型.md)。根拠の印は [根拠/README.md](../根拠/README.md)（L＝学習理論、G＝ゲーム）。

ユーザー「関係詞アプリと同様に4級の単語をちりばめる。命令表現だから、神か王のような司令塔になって、命令で世界を発展させるストーリー。レッスンの目次が縦に並ぶ UI はマンネリなので裏に隠して、自動で進む感じに。丁寧な命令は別の神にすれば？」。

| 変えたところ | 中身 |
|---|---|
| 物語 | 学ぶ人＝生まれたての神さま。フクロウのブーホが教える。島の子には **tú**、女神マリーナには **usted**、旅の一行には **ustedes**、お祭りの村のみんなには **vosotros**。相手が場面にいるので「だれに言うか」で形を選ぶ必然がある |
| 目次を隠す | ホーム＝島の景色。次の「神託」は島の人の頼みごととして出る。目次は「📖 創世記」の中だけ。クリア後に自動スタート（「✋ あとで」で止まる） |
| レッスンの形 | 場面＋ボード（表・問題）＋セリフ＋ボタン。表は次の表まで残し、問題のときは消す（思い出す練習） |
| 中心の操作 | **⚡ cast**：困りごと → 命令を選ぶ → 正しければ叩きつけ文字・光の柱。**🔨 forge**：hablas の s をタップで消す。**👥 tapwho**：場面の人をタップ |
| ごほうび | XP と神格、コンボ、ボス＝島をおそう災い、60秒ラッシュ、**奇跡の祈り（ガチャ）で住人カード**（お金なし。予測できないごほうびの学習効果は出典が割れている G24 G25） |

- 理由は「🤔 なぜ？」に（usted の命令は接続法から来たので a・e が反対、-oy の4つは o を取れない、くっつけると ´ など）。ve（ir／ver）と sé（ser／saber）は同じつづり → 文の中で見分ける
- チェックは単語帳にない語・forge の cut/add・tapwho の人が場面にいるか・ブーホが3回つづけて話さないか。命令の形は es-words.js の F に足した

## ユーザーの指摘と対応
- **復習で引っかかった所は、その神託をもう一度受けさせる**（2026-11-01「人間は一度読んだだけで全部は覚えられない。復習で引っかかった箇所のレッスンをもう一度」）→ **🩹 おさらい神託**（原則23〔出典 L9 L25〕）。復習・ボス・ラッシュ・西検チャレンジでまちがえた問題を神託ごとに `S.weak` に残し、その神託の要点だけを回り直して最後に**まちがえた問題そのものにリベンジ**（正解で消える）。ホームでは次の神託より先におさらい（「あとで」も可）。
- **4級の命令の問題が解けるところまで**（「このアプリ全体をやれば4級の命令の問題が解けるレベルまで育てる気合で」）→ 試験の形の穴をうめる神託を3つ足した：L11「浜の市場」（yo の形がクセものでも usted の命令は yo の形から）、L12「島の約束」（e の前のつづりの書きかえ）、L13「神々の宴」（代名詞2つ、禁止では前に、再帰の禁止）。🎓 **西検チャレンジ**。画面の「第○の神託」は並び順で数える（`L.ord`）。id は足した順のまま（保存とのずれを防ぐ）
- **範囲のまちがい**（2026-11-04「たまに『ここは3級でやるよ』とあるけど、4級に命令って書いてある」）→ 公式で確認（原則24）。「3級で習う」を消し、第14の神託「みんなで行こう」で **nosotros の「〜しよう」**（hablemos）と **vosotros の「〜するな」**（no habléis）を足した
- **形の作り方のルールは1つの形に1つだけ**（2026-11-04「tú は s を取る／3人称と同じ、usted は a と e を入れかえる／yo の形から、と複数のルールがある。単純に覚えるものなので、いちばんシンプルなものだけに」）→ tú＝**tú の形から s を取る**、usted＝**yo の形の o を取って -ar は e、-er・-ir は a**（不規則な tengo → tenga もこれ1つ）。「a と e を入れかえる」は使わない。あとは usted の命令から足し算：ustedes ＋n、「〜するな」＋s、「〜しよう」＋mos
- **🗺 命令の地図**（2026-11-10「動詞の変化の説明に迷走があって、頭に入りづらい」）。原因：形を作る出発点がレッスンごとに変わるのに全体図がなく、あとから足した神託で usted の仲間がジグザグになっていた。→ 出発点3つ（tú の形・yo の形・原形）→ 枝の1枚の地図（`MQ.map`。作り方は型.md）。並び：L5 → L6 → L11 → L7（L11 は港ができる前なので「浜の市場」に）。例外の4つ（ven・ten・pon・sal）の「原形の2文字を取る」は覚え方で、出発点ではない（「今日の出発は原形」と書くと vosotros の出発点と混ざる）
- **🔨 鍛冶場**（2026-11-10）：地図を自分でたどって形を作る。1回6問。「comer を、tú に『〜するな』」→ 手1「出発点は？」→ 手2「何をする？」→ 手3（足し算）。1手ごとに上の語が変わる。まちがえたら地図のその枝を光らせ、別の動詞でもう1問。表は `manda/js/data/forge.js`（規則で作れない組み合わせは出さない）。**選ぶだけの問題は「どの形から出発するか」を問わない。出発点を毎回自分で選ばせる**
