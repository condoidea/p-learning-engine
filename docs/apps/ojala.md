# ¡OJALÁ!（ojala.html・スペイン語の接続法現在）で試したこと（2026-11-25）

> ¡OJALÁ!（接続法現在・西検4級）。独立アプリ。`ojala.html` ＋ `ojala/`（データは `window.OQ`）。私用（news.js の ITEMS には足さない）
> チェック：`node tests/check-ojala.js`（`--words` で単語帳にない語だけ）。通しテスト：`tests/e2e-ojala.js`（`ojalaE2E`・`ojalaBoss`・`ojalaRemedy`・`ojalaWork`）。動作確認：`ojala.html?sandbox`
> 共通の教訓は [語学アプリの型.md](../語学アプリの型.md)。作りは ¡MANDA!（[manda.md](manda.md)）を元にした。

依頼「スペイン語検定シリーズの最後。戦後の港町の手紙の代書屋（空気感だけ。名前・用語・キャラ・見た目はオリジナル）。que のあとが本当のこと（直説法＝🔵青）か頭の中のこと（接続法＝🔴赤）かを毎回問い、封蝋の色で押す。まちがえると誤解された返事。形のルールは1つ。形の練習を厚く。長い『なぜ』を書かない」。

| 決めたこと | 中身 |
|---|---|
| 物語 | 学ぶ人＝港町の代書屋の新米。手紙を運ぶ鳩のパロマが教える。依頼人（ルス・ニコ・アンセルモ・イネス・テオ）の手紙を書いて、町がにぎわう（`OQ.world`）。7つの依頼・4日・ボス3体（霧の配達人ニエブラ／石頭の検閲官セベロ／行きちがいの嵐） |
| 中心の操作 | **🔏 seal（封蝋）**：手紙の文 → まず封蝋の色（🔵 本当のこと／🔴 頭の中のこと）→ 次に形。**色をまちがえると、届いた先の誤解の返事**（`mis`）がボードに出る。返事が見える位置までボードを送り、パロマの吹き出しでは隠さない（目線の誘導：見せたいのは返事） |
| 形のルール | 1つだけ：**yo の形の o を反対の母音に（-ar → e、-er・-ir → a）＋人ごとの語尾**。tengo → tenga も同じ。例外は **-oy の4つ（vaya・sea・esté・dé）・haya・sepa**、つづりの書きかえ（-car・-gar・-zar）だけ。語幹母音変化（quiera・pueda・vuelva）は表で形を見せるだけで、新しい作り方は足さない（why に1回） |
| 形の練習 | **🖋 形の工房**（`ojala/js/data/verbs.js`・38語）：「この動詞を、この人の接続法に」→ 手1「o を何に？」（例外は形を選ぶ）→（つづり）→ 手2「人の形」。まちがえたら同じ動詞の別の人でもう1問。ホーム・地図・帳面から入れる |
| 使い分け | 依頼ごとに条件を1つ：願い（quiero que・espero que）→ ojalá → 気持ち（me alegro de que）→ 疑い・必要（no creo que・es necesario que）→ まだ・目的（cuando ＋ これから・para que）→ さがしている人（busco … que・no hay nadie que）→ 伝える／頼む（dile que viene／venga）。それぞれ青の対（sé que・creo que・cuando ＋ いつも・tengo un amigo que…）と並べる |
| 地図 | **封蝋の地図**：出発点3つ（yo の形・🔴 赤・🔵 青）→ 枝。1レッスンで光らせる札は2枚まで（3枚だと 375×550 で3枚目が吹き出しの下に隠れた） |
| 試験の形 | 問題 144 問（pick・form・mood・ng・ja・bug・build）。**mood**＝この文はどちらの色？。🎓 西検チャレンジは 20 問・分野6つ（`TOPICS`）。公式のサンプル（casa-esp.com）は複製・転載禁止なので、形式だけ合わせて文は自作 |

- 単語は共通の単語帳（shared/es-words.js）に「¡OJALÁ! で足した語と形」として足した（descansar・regresar・ojalá・harina・boda など。接続法の形は F で）。ひっかけの形（busces・llege・esten・empieze・volvas・comi）は pos 'bad'
- 解説の中の短いスペイン語（`sé que` など）と用語（接続法）は2行に割らない（`white-space: nowrap`）。割れると読みにくく、重なりチェックにも引っかかる
- ホームのボタンは7つ（読み返し・工房・ラッシュ・西検・切手・地図・帳面）を1段に（375px で1列 46px・文字 10.5px）

## 雰囲気（あとから作り直した）

最初は ¡MANDA! の見た目（ネオンの金と紫・ゲームの HUD・派手なスラム文字）を流用していて、「色調からしてイマイチ。¡MANDA! に引きずられすぎ」と言われた。くすんだセピアにする案も撤回し、**光が主役**の方向で作り直した。

| 決めたこと | 中身 |
|---|---|
| 変数に集める | 色・字・質感は `ojala/css/ojala.css` の冒頭の `:root` にまとめた（紙 `--paper`・インク `--ink`・封蝋 `--wax-red`／`--wax-blue`・真ちゅう `--brass`・空 `--sky1〜3`・光 `--glow`・海と岸壁・字 `--f-body`／`--f-latin`／`--f-es`）。丸ごと差し替えるときはここだけ直す。app.js が使う旧名（`--text`・`--muted`・`--panel`）も残した |
| 光と時刻 | 澄んだ自然光・逆光・ふちのにじみ・漂う光の粒。影には青や紫を混ぜる。依頼ごとに時刻を決めて（`HOUR`：L1 夕方・L2 夜明け・B1 霧・L3 昼・L4 朝・B2 役所・L5 夕方・L6 雨・L7 夜・B3 嵐、全部済んだら晴れ）、`body[data-hour]` で空の色を上書きする。物語が進むほど `--warm` で暖かくなる |
| 動きの決まり | 光は放射グラデーションと粒だけで出し、動かすのは `transform` と `opacity` だけ（`filter` や大きな `blur` は使わない。iPhone でも Android でも重くしない） |
| 紙とインク | カードは光を受けた白・生成りの紙、字は深い青のインク。答えの封蝋は事実＝深い青、心＝深い赤。決定のボタンは封筒の形で、右に封蝋 |
| 字 | 本文は明朝（Shippori Mincho B1）、見出しの欧文は Cormorant Garamond、スペイン語の文は EB Garamond。細めのセリフ体 |
| 見出しの言葉 | スラム文字・結果の見出しは静かなスペイン語（Carta enviada・Perfecto・Cielo despejado など）で、大文字やびっくりマークで叫ばない。「TAP!」「60 SEC RUSH」も「封を切る」「Sesenta segundos」に |
| 音 | `ojala/js/sound.js` で音色だけをこのアプリ用に（オルゴール・小さな鐘・紙の音）。鳴らすタイミング・回数・振動は共通のままで、ごほうびの豊かさは削らない |
| 文体 | パロマと依頼人のせりふは静かで少し切なく。はげましも穏やかに（「要点だけ、もう一度ゆっくり見ていこう。」） |
| まねしない | 空気感の手本にした作品の名前・用語・人物・衣装・構図は使わない |

- 字を Garamond に変えたら、行の高さが同じでも字の箱が大きくなり、工房の問い（`descansar` と `nosotros（私たち）`）が2行になると上下で重なった → `.forge2-ask` の行の高さを 1.6 → 1.9 に
- スクリーンショットは、ランクの字や選択肢が出てくる途中を写すことがある。消えて見えたら、少し待って撮り直してから判断する

## 物語（あとから作り直した）

「雰囲気は画面だけでなくストーリーも」。主人公が名前も変化もない「あなた」で、依頼が1文ずつ終わっていたので、芯と手紙を足した。文法の範囲と問題数（144問・drill）は変えていない。

| 決めたこと | 中身 |
|---|---|
| 芯 | 代書人は、もと役所の清書係。事実（🔵 青）の書類はまちがえずに書けるが、人の心（🔴 赤＝願い・気持ち・まだ来ない日）を手紙にするのははじめて。赤い封蝋を覚えることが、そのまま「心を書けるようになること」に重なる。空気感の手本にした作品の筋（気持ちが分からない元兵士など）には寄せず、清書係という別の出どころにした |
| 独白（`mono`） | 依頼の終わりに代書人「わたし」の1〜2行。L1「『帰ってくる』ではなく『帰ってきてほしい』。書類には、なかった書き方だ。」→ … → L7「赤い封蝋は、まだ起きていないことの色だと思っていた。いまは、人の心の色だと思う。」。吹き出しは左に赤い線 |
| 書きあがった手紙（`letter`） | 依頼の最後（drill のあと）に、その依頼で書いた文をつなげた1通（宛名・本文・署名）を便せんに出し、🔏 封をして送る。各行の下に小さく訳。文脈の中で形をもう一度見る（羅列より文脈の好みにも合う）。`recv:true` は届いた手紙（読むだけ） |
| 切なさ | アンセルモ「……返事は、来るかのう。」→ L7 でやっと届いた返事は1行だけ（`Llego el domingo.`）。ルスは結婚式の前に「マルコの船が、嵐で三日おくれたの。毎晩、港のあかりを数えてた。」。L6 のニコの手紙は自分の字で、消した跡がある |
| 語りの調子 | パロマは静かでやさしい相棒（「〜わ」「〜の」）。「まかせて！」「迷わなくていい」「OK」などのゲーム口調と、物語に割りこむ文法の前置き（「今日は -er と -ir の動詞」など）を減らした |

## 説明の手直し（中身の確認を受けて）

- L3 の why「nosotros・vosotros だけは原形の芯にもどる」は -ir の動詞では成り立たない（pedir → pidamos、dormir → durmamos）。-ar・-er は原形にもどる（podamos・pensemos）、-ir は e → i・o → u、に直した。データに -ir の語幹変化動詞の nosotros 形はなかった（工房・問題・単語帳とも、podamos・queramos・volvamos・empecemos は正しい）
- quiera・pueda・vuelva・piense は試験によく出るので、why だけでなく L3 に表（＋ nosotros は芯がもどる1行）と予想ではない ask（poder の nosotros）を足した。作り方のルールは1つのまま
- `es posible que`（〜かもしれない）を L4 の疑いの表・Tips・地図・問題（l4-21）に。dar は ´ が dé だけ（des・demos・den）を例外の表に1行、問題 l3-23（ひっかけ dés）
- `quizá`・`tal vez` は、西検4級の公式ページ（https://casa-esp.com/?page_id=1798 。www をつけると証明書エラー）で接続法現在が範囲に入っていることを確かめ（語ごとの名指しはない）、ojalá と同じ「文の頭の接続法」の基本として L4 に表と1行・注意書き（わりと確かだと思うときは直説法も使う。試験では接続法）・問題 l4-22・l4-23（ひっかけは直説法）を足した。地図の doubt にも

## 物語のつながり・説明の順番・文字化け・人物の絵文字（ユーザーの指摘を受けて）

> 「短くてもいいので、何故その流れになるのかが分かること。説明なしで始まってもわからない」
> 「動詞の変化の規則と、接続法を導きやすい表現の組み合わせについて唐突で、前提知識が無いと一足飛びになっている」

- **場面の地の文（scene）** を足した。ボードに2〜3行、だれのせりふでもない文。チェッカーは「読むだけ」の連続に数えない（物語の流れなので）
  - 序章（L1 の頭）：戦後三年の港町・字を書けない人が多い → わたしは役所の清書係だった → 代書屋のおばあさんが目を悪くして店をついだ → パロマ（おばあさんの代からの伝書バト）→ 店の決まり（事実は青・願いや気持ちは赤）
  - 依頼ごとに「なぜ今来たか」と前の依頼とのつながり：ルスは食堂の仕事のあと、船から三か月便りがない／ニコはルスに聞いて来た／ニコの母さんの返事「その字は、だれが書いたの？」でうわさが広がり、アンセルモは名簿で弟の名を見つけた／二日たっても返事がなく、イネスは小麦がひと月届かない（アンセルモに聞いて来た）／小麦が半分届き、ルスに返事／パン屋がいそがしくなり人さがし／ニコが働きはじめて一週間、テオが来る
  - 人は、はじめて話すときに場面に来る（actors は空。前は序章のあいだからルスが立っていた）
- **見る → 根拠 → 結論 → 名前**（L1）：同じ「マルコが帰る」を Sé que regresas／Espero que regreses で並べる → 語尾がちがう・**変わるのは que のあとの動詞だけ** → どちらが本当のこととして書いてあるか → 本当のことはいつもの形、頭の中のこと（願い）は形が変わる → 名前（直説法・接続法）と封蝋の色 → regreses はどっち？
- **形の作り方を1段ずつ**（L1）：① yo の形（hablo）② 最後の o をとる（問い）③ 反対の母音（-ar は e、-er・-ir は a。「a と e を入れかえる」と呼び方を説明）→ 工房 ④ 人ごとの語尾（いつもの -s・-mos・-is・-n）→ 表。L2 で「原形でなく yo の形から作るのは tengo → tenga の g が残るため」、L3 で例外を「yo の形が o で終わらない（voy・soy・doy・estoy・he・sé）から作り方が使えない」理由といっしょに
- **ことばは意味のまとまりごとに1行の理由と青の文をとなりに**：気持ちは Sé que vives（青）を表に並べ、「事実でも、心で受けとめて言うときは赤。ふしぎに思うところ」と言う。必要は Es verdad que abren（青）を表に。quizá・tal vez は「本当か分からない」、antes de que・para que・pedir que は「まだ起きていない」
- 「主語が同じなら que はいらない」を「願う人と、する人が同じなら」と言いかえ、別の人にしてほしいときの文を並べた。「芯」は使わず「原形の pod- にもどる」に
- **文字化け**：吹き出しは1文字ずつ出すが、文字を UTF-16 の単位で割っていたので 🔴・🔵（2単位の文字）が半分に割れて化けていた。Array.from で割るように直し、さらに本文の 🔴・🔵（{{red}}・{{blue}} とも書ける）は CSS で描く小さな封蝋（.wx）にした（機種で絵文字の見え方が変わらない）
- **人物の絵文字をやめた**：吹き出し・場面の札・封蝋の依頼・町の絵・ホームの依頼・ボスは名前だけ。かわりの絵は足していない。目立つ UI の絵文字（🔏・📮・💡・📎・🤔・❓・📋・📜）も外した
