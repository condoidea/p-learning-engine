# ¡PROTESTO! 森のどうぶつ裁判（protesto.html・スペイン語の比較）で試したこと（2026-10-23）

> ¡PROTESTO!（スペイン語の比較・西検4級）。独立アプリ。`protesto.html` ＋ `protesto/`
> チェック：`node tests/check-protesto.js`（`--words`）。通しテスト：`tests/e2e-protesto.js`。動作確認：`protesto.html?sandbox`

ユーザー（私用）「推理もの面白そう。逆転裁判みたいな裁判形式で。証言に合うものを選ぶ・ムジュンを指摘・アイテムを突きつける」「動物裁判がほのぼの」「捜査パートは凝らずにテンポ優先」「古びたヨーロッパの絵本みたいな画面」。比較は「AはBより〜」という**主張そのもの**なので、ムジュンが作りやすい。独立アプリ（`protesto/`）。キャラ・名前・セリフはオリジナル（「¡Protesto!」「¡Un momento!」「¡Contradicción!」は普通のスペイン語）。

| 変えたところ | 中身 |
|---|---|
| 流れ | 事件ごとに**捜査（インプット）→ 法廷（アウトプット）**。捜査では現場の3か所を調べ、グラフ → 予想の問い → 文 → ミミのノート（文法の名前）の順に習う。法廷では習った形でウソをくずす＝「教える前に問題を出さない」が物語の形で自然に守れる |
| 法廷の操作 | **尋問**（◀▶で証言を見て「¡Un momento!」でゆさぶる／「¡Protesto!」で証拠をつきつける）、**証拠のつきつけ**（1つの主張に）、**ムジュンする2つの証言をタップ**、**流れる主張を止める**、**通訳ロロの誤訳を直す**（menos を「より高い」と訳す等＝意味の理解を直接問う）、**順に並べる**、**決め手の一文をタイルで組み立てる**（まぎらわしいタイルつき） |
| 罰 | まちがえると「どんぐり」が減る（5つ）。0 で休廷 → 5つに戻して再開（やり直しにしない）。ミスの数で S/A/B |
| グラフ | 比べる事実はいつも**棒グラフ**で見せる（高さ・値段・速さ・年齢・数）。比較の文は「グラフを言葉にしたもの」になり、ウソはグラフとのずれで分かる |
| 色 | 比べる部分を [ ] で囲み、más・mejor・mayor＝朱、menos・peor・menor＝藍、tan・tanto＝緑、que・como・de＝黄土 |
| 訳 | 証言の訳はぼかしておき、タップで見える（まずスペイン語を読む）。設定で最初から見せられる |
| 練習 | **証言台ドリル**（60秒）：グラフと証言をその場で作り、「¡Es verdad!」か「¡Protesto!」。クリアした事件の文法だけ出る。ウソを見のがしたら、グラフどおりの文を見せる |
| 見た目 | 生成りの紙・インク・二重の罫線・❦。絵文字はメダルに入れて少しセピア。叩きつけ文字は赤い木版の札、判決は朱のスタンプ |

- 台本は6話を Sonnet のサブエージェントに1話ずつ並行で書かせた（データ形式は `protesto/js/data/cast.js` の先頭、見本は第1話）。単語帳にない語は各話の先頭コメントに書かせ、登録はまとめて自分で（230語ほど）
- 教材チェック `node tests/check-protesto.js`（単語帳・正解の番号・証拠を get してから使っているか・同じ人が3回続けて話す・1行30字）。`--words` で単語帳にない語の一覧。ブラウザの通しテスト `tests/e2e-protesto.js`（全事件を正解で進め、重なり・横スクロール・エラーを数える）。動作確認は `protesto.html?sandbox`（全話が開く）
- ドリルの正誤は node で数千問作って、グラフと一致するか機械で確かめた
- 単語メモ（`node tests/check-relativo.js --memo`）に protesto の列を足した

### ¡PROTESTO! を使ってみての指摘（2026-11-04）
- **文字が小さい** → 本文 16.5px、スペイン語の文 21px、訳・補足 14.5〜15px、選択肢 16px 以上に。小さい字（10〜12px）は名札・単位くらいにとどめる
- **会話の名札が枠から半分はみ出して読めない** → 枠は中身をスクロールする（overflow）ので、上にはみ出させた絶対配置の名札は切れる。名札は枠の中に置く
- **ノートの「más alto que」が1語ずつ改行** → 別の修正で入った `.cmp`（答えの比較の行・display:grid）と、比べる部分の色づけのクラス名がぶつかっていた。色づけは `.cpt` に改名。**クラス名は短い一般的な名前ほど衝突する**
- **選択肢の中の知らない語を調べられない**（ボタンを押すと答えになってしまう） → スペイン語の選択肢は「文＋右の端の『えらぶ』ボタン」の行に。文の語はタップで意味のバルーン（選ぶのはボタンだけ）。意味のある語は5級もふくめて全部調べられる（4級以上だけ点線）
- **出てきた単語を復習したい** → 🗂 単語の復習：事件・ドリルの画面に出た**4級以上の語**を自動で集め（ser・estar など5級の基本語は「さすがに要らない」とユーザー。例文は訳のある文を優先し、答えたあと「文の意味」も出す）、意味の4択で間隔反復（正解で 1・3・7・14・30 日後、まちがえたらその回の最後にもう一度）。**調べた語（🔍）を先に出す**。📇 で事件ごとの一覧と覚えぐあい（★）
- **一足飛びの見直し（原則22・¿QUIÉN FUE? と同じ観点）**：全6話を見る順に1本の文に書き出して読み、次を直した。①まだ出ていない数字で問う（第6話：パボン12歳・ウラカ3歳を ng にしか書いていない → 先にグラフ。巣の高さ 400 cm を、巣の写真より前に使っていた → ミミが「木を見てきた」と先に言う）②根拠とつながらない決め手（第3話：灰色の毛＝ロボ、とどこにも言っていない → ニコが言う）③同じ語の別の意味を説明なしに（第6話：riquísimo＝「とてもおいしい」と習った直後に「¡Soy riquísimo!」＝大金持ち → rico の2つの意味をミミが言う）④未習の用語（第5話 Tips の「最上級」→「いちばん」）⑤人物の話し方のぶれ（第4話：「ティトくん」なのに証言が「〜わ」）・時刻の食いちがい（8時に朝市／9時に買う）⑥呼び捨てで失礼になる名前（Cerdo → el señor Cerdo）⑦ことばのずれ（「高さが少ない」→「値段の高さが少ない」、棚の下の砂糖を en el estante → debajo del estante）
- **流れる主張（stop）が速すぎて読めない**（読み上げの音質がいまいちで、文字で読んでいた）→ 1行 4.2 秒の固定をやめ、**文の長さに合わせた時間**（7 秒以上、スペイン語＋訳の字数×0.11 秒）に。**⏸ 止めて読む／◀ ▶ で行を戻す・進める**を足し、語をタップして調べると自動で止まる。**流れる演出は残しても、読む人が時間を握れるように**
- **「ムジュンする2つ」に確信が持てない**（第2話）→ ①ムジュンが証言の外の数字（汽車は1分で 1000 m）に頼っていたのに、その数字が画面になかった → 直前にグラフとミミの一言で出す ②関係ない行が、前の証言（切符売り場にいた）とぶつかって見えた → ぶつからない文に ③まちがえたら「汽車なら何分？ルペは何分と言った？」のヒント。**ムジュンの2行以外は、どの行ともぶつからないこと**を見直す
- **組み立て（build）で alto／alta を落としたのに、ヒントがない**（第2話：usted が女性のルペさんだと気づけない）→ 問いに「ルペさんに『あなたは…』」とだれに言うかを書き、まちがえたら ng のヒント（usted＝ルペさん、女性、自分でも rápida と言っていた）をミミが言う。全6話の組み立てに ng を足した。**usted は性別が見えないので、形容詞の性を問うなら相手を問いに書く**

### ¡PROTESTO! の再点検（2026-11-10：説明・筋・ドパガキ）
- **筋の穴は「その証拠で、ほかの答えも通らないか」「その物は本当にそこを通れるか」で探す**：第3話は、年れいの証明書を捜査で先に渡していたので、最初の尋問で証明書を出すのが正しいのにミスになった → 証明書は法廷の途中で届く。第5話は 30 kg の本が幅 5 cm の窓から出たことになっていた → 本は棚の下にあった（砂糖のつぶの列が棚の下まで）。第6話は「夜は出かけない」と「ゆうべ見た」がムジュンにならない（巣は銀行の前）→ 習った形どうしがぶつかる文に（menos de cien と más de cien）。第1話は「棚より背が高い」の根拠がなかった → はしごは鍵つきの物置。**ムジュンは、習った形そのものでぶつける**
- **事実とちがう証言をした証人には、最後に理由を言わせる**（第2話のウマ駅長・第4話のティト）。言わないと「なぜウソを？」が残る
- 捜査パートの形を問う問いに、まちがえたときのヒント（ng）を全部つけた。答えは言わず、見る所を指す
- **形を自分で選ぶ穴埋め**（`PQ.drill.fill(form)`）：グラフ＋空所のある文＋2〜3択。数字と動物は毎回変わる（原則18）。más／menos、形容詞の性、tan／tanto、como／que／de、mayor／más grande、mejor／más bueno、冠詞、de／en、数の前の de。まちがえたら ✕／○ の2行＋訳＋「グラフで〜 → だから〜」。証言台ドリルに4割まぜる
- **🩹 おさらい（原則23）**：事件の中の形の問い・組み立て・通訳、ドリルのまちがいを話ごとに数える（`S.weak`）。表紙と事件の結果画面に出し、その話のノートを全部見直す → 穴埋めを3問正解で記録が消える。教材チェックに穴埋めの検査（各300問）を足した
