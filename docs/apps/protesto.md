# ¡PROTESTO! 森のどうぶつ裁判（protesto.html・スペイン語の比較）で試したこと（2026-10-23）

> ¡PROTESTO!（スペイン語の比較・西検4級）。独立アプリ。`protesto.html` ＋ `protesto/`
> チェック：`node tests/check-protesto.js`（`--words`）。通しテスト：`tests/e2e-protesto.js`。動作確認：`protesto.html?sandbox`
> 共通の教訓は [語学アプリの型.md](../語学アプリの型.md)。根拠の印は [根拠/README.md](../根拠/README.md)。

ユーザー（私用）「推理もの面白そう。逆転裁判みたいな裁判形式で。証言に合うものを選ぶ・ムジュンを指摘・アイテムを突きつける」「動物裁判がほのぼの」「捜査パートは凝らずにテンポ優先」「古びたヨーロッパの絵本みたいな画面」。比較は「AはBより〜」という**主張そのもの**なので、ムジュンが作りやすい。キャラ・名前・セリフはオリジナル。

| 変えたところ | 中身 |
|---|---|
| 流れ | 事件ごとに**捜査（インプット）→ 法廷（アウトプット）**。捜査はグラフ → 予想の問い → 文 → ミミのノート（文法の名前）の順に習う。法廷では習った形でウソをくずす＝「教える前に問題を出さない」が物語の形で自然に守れる |
| 法廷の操作 | **尋問**（「¡Un momento!」でゆさぶる／「¡Protesto!」で証拠をつきつける）、**ムジュンする2つの証言をタップ**、**流れる主張を止める**、**通訳ロロの誤訳を直す**、**順に並べる**、**決め手の一文をタイルで組み立てる** |
| 罰 | まちがえると「どんぐり」が減る（5つ）。0 で休廷 → 5つに戻して再開（やり直しにしない） |
| グラフ | 比べる事実はいつも**棒グラフ**。比較の文は「グラフを言葉にしたもの」になり、ウソはグラフとのずれで分かる |
| 色 | 比べる部分を [ ] で囲み、más・mejor・mayor＝朱、menos・peor・menor＝藍、tan・tanto＝緑、que・como・de＝黄土 |
| 練習 | **証言台ドリル**（60秒）：グラフと証言をその場で作り、「¡Es verdad!」か「¡Protesto!」。ウソを見のがしたら、グラフどおりの文を見せる |

- 教材チェックは単語帳・正解の番号・証拠を get してから使っているか・同じ人が3回続けて話す・1行30字。台本の分担は型.md。

## ユーザーの指摘と対応
### 使ってみての指摘（2026-11-04）
- **文字が小さい** → 型.md の「文字の大きさ」に直した。
- **会話の名札が枠からはみ出して読めない** → 名札は枠の中に置く（型.md）。
- **ノートの「más alto que」が1語ずつ改行** → 別の修正の `.cmp` と色づけのクラス名がぶつかっていた（色づけは `.cpt` に改名）。**クラス名は短い一般的な名前ほど衝突する**。
- **選択肢の中の知らない語を調べられない** → 選択肢を「文＋『えらぶ』ボタン」の行にし、語はタップでバルーン（型.md）。
- **出てきた単語を復習したい** → 🗂 単語の復習：4級以上の語を自動で集め（5級の基本語は「さすがに要らない」とユーザー）、意味の4択で間隔反復（間隔をあける L6 L8）。**調べた語を先に出す**。
- **一足飛びの見直し**（原則22）：全6話を見る順に書き出して読み、穴を直した（例：riquísimo＝「おいしい」と習った直後に「大金持ち」。見つけ方は型.md）。
- **流れる主張（stop）が速すぎて読めない**→ 1行の固定をやめて**文の長さに合わせた時間**に。**⏸ 止めて読む／◀ ▶ で行を戻す・進める**。語をタップして調べると自動で止まる。**流れる演出は残しても、読む人が時間を握れるように**。
- **「ムジュンする2つ」に確信が持てない**（第2話）→ ムジュンが証言の外の数字に頼っていたのに画面になかった → 直前にグラフで出す。**ムジュンの2行以外は、どの行ともぶつからないこと**。
- **組み立て（build）で alto／alta を落としたのに、ヒントがない**（第2話）→ 問いに「ルペさんに『あなたは…』」とだれに言うかを書き、全6話の組み立てに ng を足した。

### 再点検（2026-11-10：説明・筋・ドパガキ）
- **筋の穴は「その証拠で、ほかの答えも通らないか」「その物は本当にそこを通れるか」で探す**：第3話は年れいの証明書を捜査で先に渡していたので、最初の尋問で出すのが正しいのにミスになった → 証明書は法廷の途中で届く。第5話は 30 kg の本が幅 5 cm の窓から出たことになっていた → 本は棚の下。第6話はムジュンにならない → 習った形どうしがぶつかる文（menos de cien と más de cien）に。**ムジュンは、習った形そのものでぶつける**。
- **事実とちがう証言をした証人には、最後に理由を言わせる**（言わないと「なぜウソを？」が残る）。形を問う問いには、まちがえたときのヒント（ng）を全部つけた（答えは言わず、見る所を指す）。
- **形を自分で選ぶ穴埋め**（`PQ.drill.fill(form)`）：グラフ＋空所のある文＋2〜3択。数字と動物は毎回変わる（原則18）。まちがえたら ✕／○ の2行＋訳＋「グラフで〜 → だから〜」。証言台ドリルに4割まぜる。
- **🩹 おさらい**（原則23）：事件の中の形の問い・組み立て・通訳、ドリルのまちがいを話ごとに数える（`S.weak`）。その話のノートを全部見直す → 穴埋めを3問正解で記録が消える。
