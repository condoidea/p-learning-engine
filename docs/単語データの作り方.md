# 単語データの作り方（参考書連動版デッキ）

単語アプリ（`vocab.html`）に読み込む**デッキ（JSON ファイル）**を、参考書から作るための手順と決まり。
作業する AI・人は、この文書だけで作業できるように書いてある。アプリ全体の考え方は [単語アプリ設計.md](単語アプリ設計.md)。

---

## 0. 前提

- できあがった JSON は、利用者が自分の端末（iPhone／Android）に**読み込んで使う**。
- **このリポジトリは公開されている。** 参考書から作ったデータは commit しない。作業中のファイルは `vocab/decks/private/` に置く（`.gitignore` 済み）。
- 1冊（またはシリーズ）＝1デッキ。参考書の**課＝区間（section）**、単語ごとに**ページ（ref）**を持たせる。アプリでは「範囲：第3課〜第5課」のように絞って復習できる。

## 1. 作業の流れ

1. 参考書の単語のページ（写真・スキャン）から、**課・ページ・単語・品詞・性・意味**を取り出す。
2. **例文・予想の手がかり・覚え方は、オリジナルで作る**（参考書の例文や解説は写さない）。
3. JSON を書く。
4. チェックを走らせ、エラーを0にし、注意を見直す（→ 6）。動詞の活用表も確かめる（→ 5）。
5. ファイルを利用者に渡す（→ 7）。

### 参考書から取り出すもの／取り出さないもの

| 取り出す | 取り出さない（自分で作る） |
|---|---|
| 課の番号・題名、ページ | 例文・会話文 |
| 単語のつづり、品詞、名詞の性 | 解説・コラム・イラストの説明 |
| 意味（短く） | 覚え方・語源の説明（必要なら自分の言葉で） |

## 2. ファイルの形

見本：[vocab/decks/sample/sample-book.json](../vocab/decks/sample/sample-book.json)（8語。不規則動詞 traer・oír の書き方も入っている）

```json
{
  "id": "nuevo-espanol-1",
  "title": "スペイン語（○○連動）",
  "brand": "📗 NUEVO 1",
  "sub": "第1課〜第12課",
  "book": "参考書の名前",
  "lang": "es",
  "skin": "espana",
  "sections": [
    { "id": "L01", "name": "第1課 あいさつ", "ref": "p.10–15" }
  ],
  "words": [
    { "id": "nombre", "s": "L01", "ref": "p.12", "w": "nombre", "pos": "n", "g": "m", "ja": "名前",
      "ex": ["¿Cuál es tu {nombre}?", "君の名前は？"],
      "clue": { "t": "cog", "text": "英語の name・nominate と同じ祖先" },
      "memo": "任意：覚え方・使い方" }
  ]
}
```

### デッキ

| 項目 | 中身 |
|---|---|
| `id` | 英小文字・数字・ハイフン（例 `nuevo-espanol-1`）。**あとから変えない**（進み具合の保存先になる）。`spanish` は使えない |
| `title` / `brand` / `sub` | コース一覧とアプリに出る名前（brand は短く） |
| `book` | 参考書の名前。これがあると、カードに「📗 第3課・p.42」と出る |
| `lang` | `es`（いまはスペイン語だけ） |
| `skin` | `espana`（省略可） |
| `sections` | 課の一覧（参考書の順番どおり） |

### 区間（sections）

| 項目 | 中身 |
|---|---|
| `id` | 英数字（例 `L01`）。単語の `s` で使う |
| `name` | 「第1課 あいさつ」のように |
| `ref` | 課のページ範囲（任意） |
| `known` | `true` にすると、その課の単語は「👀 顔見知りチェック」（もう知っている語を素早く確かめる）から始まる。既習の課に使う（任意） |

### 単語（words）

| 項目 | 必須 | 中身 |
|---|---|---|
| `id` | ○ | 英小文字・数字・`_`・`-`。アクセント記号と ñ は外す（niño → `nino`、canción → `cancion`）。同じつづりで意味が別の語は `banco_1` のように。**あとから変えない** |
| `s` | ○ | 区間の id |
| `ref` | | ページ（例 `"p.42"`）。複数の課に出る語は、最初の課に1つだけ書き、`"p.12, p.40"` |
| `w` | ○ | つづり。**名詞は冠詞なし**、**動詞は原形**（再帰動詞は `-se`：`levantarse`）、表現はそのまま（`por favor`） |
| `pos` | ○ | `n` 名詞／`v` 動詞／`adj` 形容詞／`adv` 副詞／`phr` 表現（あいさつ・決まり文句・熟語） |
| `g` | 名詞 | `m` 男性／`f` 女性。冠詞（el / la）はアプリが自動でつける |
| `art` | | 冠詞が例外のとき：`"el"`（el agua, el hambre）、複数形だけの語は `"los"`／`"las"` |
| `ja` | ○ | 意味。短く、2〜3個までを `・` で（例 `"駅・季節"`） |
| `ex` | ○ | `["スペイン語の例文", "日本語訳"]`（→ 4） |
| `clue` | ○ | 予想の手がかり（→ 4） |
| `memo` | | 覚え方・使い方・ひっかけ・不規則の要点。1〜2文 |
| `cj` | 動詞 | 不規則動詞のくせ（→ 5） |

## 3. アプリでの使われ方（なぜこの形なのか）

- **出会い**：単語と発音 → 手がかり（`clue`）を見て意味を**予想**（採点しない）→ 意味・例文・覚え方 → 見分ける問題 → 図鑑へ。
- **野生戦**：意味を選ぶ・聞き取る・スペイン語を選ぶ・つづりを組み立てる・**例文の { } を穴埋め**。
- **活用**：動詞は `w`（原形）から、アプリが全時制の形を作る（直説法現在・点過去・線過去・現在完了・未来・過去未来・接続法現在・命令）。

だから、`clue` で答えがばれると予想が成り立たず、`ex` の { } がずれると穴埋めが壊れ、動詞のくせがまちがっていると活用の練習がまちがう。

## 4. 書き方のルール

### 例文（ex）

- **オリジナル**で作る。短く（10語くらいまで）、西検4級くらいの文法（直説法の基本の時制）で。
- その単語の**いちばん基本の意味**が伝わる場面にする。
- **`{ }` は1か所だけ**、その単語の所を囲む。名詞の複数形・形容詞の女性形・動詞の活用形でもよい（`Tengo dos {hermanos}.`、`La fruta es {barata}.`、`Me {levanto} a las siete.`）。冠詞は { } の外。
- 動詞の { } は、アプリが作れる活用形であること（チェックが確かめる）。
- 訳は自然な日本語。

### 予想の手がかり（clue）

学習者は、意味を見る**前に**これを見て予想する。**意味そのものを書かない**（チェックが警告する）。4種類から選ぶ。

| t | 使うとき | 例 |
|---|---|---|
| `cog` | 英語と同じ祖先で、形が似ている | `"英語の station と同じ祖先"`（estación）。英語の単語だけ書き、その意味は書かない |
| `trap` | 英語と似ているのに意味がちがう（偽りの友）。**`lure` に思わず選ぶ意味**を書く | `{ "t": "trap", "text": "英語の exit に似ているけど…？", "lure": "出口" }`（éxito＝成功） |
| `parts` | 部品に分けると意味が推測できる | `"cumple（満たす）＋ años（年）"`（cumpleaños）。最後の答えは書かない |
| `ctx` | 上のどれにも当たらない。絵文字＋場面 | `"🍽️ 午後2時。朝から何も食べていない…"`（hambre） |

- `ctx` では、アプリが例文（スペイン語）も一緒に見せる。場面から意味が想像できるように。
- 迷ったら `ctx`。`cog` は本当に同じ祖先の語だけ（似ているだけの語は使わない）。

### 覚え方（memo）

- あると助かるもの：まぎらわしい語との区別（「出口は salida」）、性の例外（「-a で終わるのに男性名詞」）、動詞の不規則の要点（「私は＝traigo」）、よく使う言い回し。
- 理由のわかるコツにする（「なぜ？」がわかると覚えやすい）。

## 5. 動詞のくせ（cj）

アプリは、規則動詞と、次の不規則動詞のくせを**すでに知っている**。これらは `cj` を書かなくてよい：

> ser, estar, ir, haber, tener, venir, hacer, poner, salir, decir, poder, querer, saber, dar, ver, conocer, empezar, pensar, despertar(se), cerrar, volver, recordar, acostar(se), jugar, dormir, pedir, sentir, escribir, abrir

それ以外の動詞は、まず**規則動詞として**活用される。チェックを `--verbs` つきで走らせると、作った活用表が出る。**1つでもまちがっていたら `cj` を書く。**

| 項目 | 中身 | 例 |
|---|---|---|
| `stem` | 語幹の母音が変わる：`"ie"`（e→ie）／`"ue"`（o→ue）／`"i"`（e→i）。強く読む所だけ（nosotros・vosotros は変わらない） | entender `{ "stem": "ie" }`、encontrar `{ "stem": "ue" }`、repetir `{ "stem": "i", "ir": "i" }` |
| `ir` | -ir 動詞の追加の変化：`"i"`（e→i）／`"u"`（o→u）。点過去の3人称と接続法の nosotros・vosotros に効く | preferir `{ "stem": "ie", "ir": "i" }`、morir `{ "stem": "ue", "ir": "u", "part": "muerto" }` |
| `yo` | 直説法現在の yo だけ不規則。接続法はこの形から作られる | traer `{ "yo": "traigo" }`、conducir `{ "yo": "conduzco" }`、coger `{ "yo": "cojo" }` |
| `pretS` | 点過去の強変化の語幹（語尾は e, iste, o, imos, isteis, ieron。j の後は eron） | traer `"traj"`、conducir `"conduj"`、andar `"anduv"` |
| `futS` | 未来・過去未来の語幹 | oír `"oir"`（原形の記号を外す） |
| `part` | 過去分詞 | romper `"roto"`、morir `"muerto"`、volver はアプリが知っている |
| `tu` | 命令 tú の不規則 | （ほとんど不要） |
| `noImp` | `true` で命令の練習をしない | 命令で使わない動詞 |
| `pres` `pret` `impf` `subj` | その時制の6つの形を全部書く（yo, tú, él, nosotros, vosotros, ellos の順）。上の項目で表せないとき | oír（見本ファイル）、leer の点過去 `["leí","leíste","leyó","leímos","leísteis","leyeron"]`、construir の現在・点過去・接続法 |

- 書いたら、もう一度 `--verbs` で表を見て確かめる（`cj` を書いた動詞は一覧に出ないので、確かめたいときは `cj` を一時的に外して見比べる）。
- 判断に迷う動詞は、`pres`・`pret`・`subj` を表ごと書くのがいちばん確実。

## 6. チェック

```bash
node tests/check-vocab-deck.js vocab/decks/private/nuevo-espanol-1.json --verbs
```

- **✖ エラー**：0にする（0でないとアプリが読み込まない）。
- **⚠ 注意**：1件ずつ見る。手がかりに意味が書いてある、例文の { } の形がおかしい、同じつづりが2つある、など。
- **🔁 規則動詞として活用する動詞**：表を見て、不規則なら `cj` を書く。

## 7. 渡し方・読み込み方

- ファイル名は `<デッキの id>.json`（課ごとに分けるなら `<id>-L01-L05.json` など）、文字コードは UTF-8。
- 利用者は、¡VAMOS! のホームの **「📚 デッキ」→「＋ 参考書のデッキを読み込む」→「📂 ファイルをえらぶ」** で読み込む（iCloud Drive・Google Drive などに置いたファイルを、iPhone でも Android でも選べる）。少しなら中身を貼りつけてもよい。数百語でも問題ない（600語で約110KB・読み込み1秒以内を確認済み）。
- **課ごとに分けて渡してよい。** 同じ `id` のデッキに読み込むと「足す」を選べる。区間は後ろに追加され、同じ単語の id は新しい内容に入れかわる。分けたファイルも、それぞれが完全な形（`id`・`title`・`brand`・その課の `sections` と `words`）にする。
- **直したデータは「全部入れかえる」で読み込み直す。** 進み具合は単語の `id` で引き継ぐので、**id は変えない**（id を変えると、別の単語として最初からになる）。

- [ ] 区間は参考書の課の順、単語に `ref`
- [ ] 名詞は冠詞なし＋`g`、動詞は原形
- [ ] 例文の { } は1か所
- [ ] 手がかりで意味がばれない
