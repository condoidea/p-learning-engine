# 語学アプリの型（次のスペイン語アプリを作るときの共通の教訓）

relativo・manda・protesto・quien・futuro の5本で得たこと。経緯は各項目末のファイル（`apps/`）。[原則.md](原則.md) と併せて読む。

## 範囲と作り方のルール
- **範囲は公式で確かめる。** casa-esp.com の級別の文法範囲とサンプル問題。記憶で「○級で習う」と書かない（接続法を「3級」と誤記した）。4級＝過去完了・未来・未来完了・過去未来・接続法現在・命令・受身、5級＝現在完了・過去分詞・現在分詞、3級＝接続法の現在完了・過去・過去完了・過去未来完了。気合は「アプリ全体をやれば4級のその分野が解ける」（原則24）（apps/manda.md・futuro.md）
- **形の作り方のルールは1つの形に1つ。** 別の覚え方は、正しくても書かない（why に1回だけ）。2つあると迷う（apps/manda.md・futuro.md）
- **出発点が変わる文法は、1枚の全体図（地図）を。** きまりを見つけた直後に書きこむ（その枝だけ光る）。1レッスンに多くて2回。未習の枝・補足の札は「？？？」で隠す。いつでも開ける。各レッスンの最初に「今日の出発は○○」を一言。**レッスン中は短い表示**（出発 → 親の枝＋いまの枝だけ。全体は 🗺 で）。あとから足すときは、文法の並びと物語の並びの両方に合う場所へ（apps/manda.md・futuro.md）

## 説明の書き方
- **見る順に書き、一足飛びにしない**（原則21・22）。全話を見る順に1本の文に書き出して通読する（サブエージェントの台本は、読む順に書き出すスクリプトで）。見つかった穴：まだ出ていない数字で問う／根拠とつながらない決め手／同じ語の別の意味を説明なしに／未習の用語／前に教えたきまりと食いちがって見える形（その場でつなぐ）（apps/protesto.md・quien.md・relativo.md）
- **未習の形を、選択肢や why に出さない。** 現場ボードの仮面は、その話までに習ったものだけ（apps/quien.md）
- **ダミーに「正しくなってしまう形」を入れない。** `Mañana llueve.` は正しい文なので未来形の問題のダミーにしない。規則どおりのまちがい（`poderé`）を使う。`Dijo que`＋未来形をまちがいにするなら why に理由（apps/futuro.md）
- **使い分けは原因 → 結果で。** その場で見えないもの（「表の○行目」）を参照しない。1か所だけちがう2文を両方並べる。手がかりを先に自分で選ばせる。「なぜ？」は単独で読める文章（「だから」で始めない）（apps/relativo.md）
- **usted は性別が見えない。** 形容詞の性を問うなら、相手を問いに書く（apps/protesto.md）

## 画面
- **文字の大きさ：** 本文 16.5px、スペイン語の文 21px、訳・補足 14.5〜15px、選択肢 16px 以上。10〜12px は名札・単位だけ。名札は枠の中に置く（overflow で切れる）。クラス名は短い一般的な名前ほど衝突する（apps/protesto.md）
- **選択肢の語も調べられる：** 「文＋右の端の『えらぶ』ボタン」の行にし、文の語はタップでバルーン。5級の語もふくめて全部（点線は4級以上だけ）（apps/protesto.md）
- **出た単語は復習：** 4級以上の語を自動で集め、意味の4択で間隔反復（1・3・7・14・30日、調べた語を先に）（apps/protesto.md・quien.md）
- **まちがえたら、自分の答えと正解をならべる**（✕ あなた／○ 正解。ちがう語だけ色）（apps/relativo.md）
- **目次を隠し、自動で進む：** ホームは世界の景色。次のレッスンは頼みごととして出て、クリア後に5秒のカウントで自動スタート（「あとで」で止まる）（apps/manda.md）
- **時間のある演出は、読む人が握れるように**（止める・戻す・進める）。60秒ドリルは、時間切れでも解いている1問は答えるまで終わらない（apps/protesto.md・quien.md）

## 復習と試験
- **🩹 おさらい（原則23）：** まちがえた問題をレッスン（話）ごとに記録 → その場で要点（Tips・表）→ 要点だけを回り直し → 最後にまちがえた問題そのものにリベンジ（正解で消える）→ ホームで次のレッスンより先に（「あとで」も選べる）。残したい説明は `**` で書く（apps/relativo.md・manda.md・protesto.md）
- **試験と同じ形の問題と模試：** 空所・入らないもの（ng）・正体・まちがい探し・意味。20問・分野ごと・答え合わせは最後・合格ライン70%・分野別の結果と弱い分野のおさらいボタン。選択肢は表示のたびに順をまぜる（apps/relativo.md・manda.md・quien.md）
- **物語の筋の穴は：** 「その証拠でほかの答えも通らないか」「その物は本当にそこを通れるか」で探す。ムジュンは習った形そのものでぶつけ、2行以外はどの行ともぶつけない。事実とちがう証言をした証人には、最後に理由を言わせる（apps/protesto.md）

## 単語帳とチェック
- **`shared/es-words.js`：** 例文の語は全部登録（ない語はチェックでエラー）。活用形は見出し語の活用形として足す。存在しない形は品詞 `bad`（ひっかけ用）。4級以上の語は点線バルーン（apps/manda.md・futuro.md）
- **単語メモ** `docs/vocab/スペイン語単語メモ.md` は `node tests/check-relativo.js --memo` で作り直す。新しいアプリは文を集める処理と列を足す。語選びは、復習なら「よく出した語」・4級の語、新しく足すなら表にない語
- **名前：** 教材チェック `tests/check-<アプリ>.js`（`--words` で単語帳にない語）、通しテスト `tests/e2e-<アプリ>.js`、動作確認は `<アプリ>.html?sandbox`。手順は [作業の手順.md](作業の手順.md)

## サブエージェントへの分担
- 台本は話ごと・前半後半ごとに**ファイルを分けて**並行で書かせる。同じ人物表・ステップの形・地図のデータ・見本の1話を渡す。最後に1人が統合（結合・つなぎ目の通読）（apps/protesto.md・quien.md・futuro.md）
- **単語帳は共有ファイルなので触らせない。** 「ない語の一覧」を書かせ、統合の人がまとめて登録する（apps/futuro.md）
- 最後に洗う：同じ名前の別人、不自然なスペイン語、文字列の中の生の改行（1つで全チェックが止まる）（apps/quien.md）
