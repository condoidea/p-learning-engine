# アプリのお知らせ（news/news.js・中央管理）

全アプリ共通の仕組み（もとは yuki の章の末尾にあった）。
- すべてのアプリの入口に `<script src="news/news.js?v=2"></script>` を入れておく（新しいアプリを作ったら、その入口にも1行）。お知らせの中身は news.js の `ITEMS` だけで管理し、各アプリは触らない
- 1件ごとに：お知らせ先（url）・出さないアプリ（exclude）・期限（until）。アプリごとに1回、お知らせ先をまだ開いていないときだけ。閉じるのは「閉じる」ボタンだけ
- アップデートのお知らせは `updated: '日時'` をつける：前に開いたことがあって、その日時のあとにまだ開いていない人だけに出す（一度も開いていない人には「新しいアプリ」のほうが出る）。例：モル教室のおさらい（2026-11-04、スペイン語の私用アプリには出さない）
- 「開いたか」は news.js が共通で記録（le.news.visited.<ファイル名>）
- **新しいアプリを必ずお知らせするわけではない**。私用のアプリ（例：¡QUE FUSIÓN! 関係詞）と娘用のアプリが混在しているので、`ITEMS` に足すのは広めたいアプリのときだけ（ユーザー指示 2026-10-21）
