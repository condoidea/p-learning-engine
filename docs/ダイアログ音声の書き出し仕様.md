# ダイアログ音声の書き出し仕様（TTS ツールへの依頼）

TTS ツール（別の場所にある）を担当するチャットへの依頼書。learning-engine の**ダイアログ・プレーヤー CHARLA**（`charla.html`。台本を見ながら音声を聞く学習アプリ。[apps/charla.md](apps/charla.md)）が読み込むデータの形を決める。

## プレーヤーでやりたいこと（この仕様が必要な理由）
- 再生中の**セリフ**を光らせる（単語単位は不要）
- セリフをタップすると、そのセリフの頭から再生し、そのセリフを AB 区間（くり返し）にする
- 台本を隠せる・速度を変える・2秒戻す・1本ループ

このうち上の2つは「**完成した mp3 の中で、各セリフが何ミリ秒から何ミリ秒までか**」が分からないとできない。いまの書き出し（`renders/vN.json`）にはこれがない。しかもセリフの間に `jitterMs` のばらつきが入るので、あとから計算で出すこともできない。だから**つなぐときに、実際に置いた位置を書き出してほしい**。

## 書き出すもの（ダイアログ1本につき1フォルダ）

```
<id>/
  dialog.json   … 下の形
  audio.mp3     … プレーヤーで使う完成版を1本だけ（v2・v3 のような候補は入れない）
```

- `<id>` は英数字とハイフンだけ（例：`20261118-134152-faf9`）。日本語やスペースは使わない
- 置き場所：learning-engine の **gitignore の対象外**のフォルダに置き、公開する（`_参考用/` は gitignore されているので、そこに置いても公開されない）。置き場所は `charla/dialogs/<id>/`（`charla/dialogs/list.js` に1行足す）
- `raw/` の wav や作業用の json は入れなくてよい

## dialog.json の形

```json
{
  "format": 1,
  "id": "20261118-134152-faf9",
  "title": "En el hotel",
  "scene": "Recepción de un hotel pequeño en Madrid, por la tarde. Ambiente tranquilo.",
  "accent": "es-ES",
  "createdAt": "2026-11-18T05:03:53.476Z",
  "audio": "audio.mp3",
  "durationMs": 72744,
  "speakers": [
    { "id": "A", "gender": "male",   "persona": "cliente educado, un poco cansado después del viaje" },
    { "id": "B", "gender": "female", "persona": "recepcionista amable y profesional" }
  ],
  "lines": [
    {
      "index": 0,
      "speaker": "A",
      "text": "Buenas tardes. Tengo una reserva a nombre de Torres, una habitación doble para dos noches. Si es posible, me gustaría una con vistas a la plaza.",
      "direction": "",
      "startMs": 400,
      "endMs": 13480
    },
    {
      "index": 1,
      "speaker": "B",
      "text": "Bienvenido, señor Torres. Un momento, que lo compruebo... Lo siento, las habitaciones con vistas están todas ocupadas esta noche.",
      "direction": "amable; al final, con pena",
      "startMs": 14180,
      "endMs": 28580
    }
  ]
}
```

（数字は形を示すための例。実際の値ではない）

### 各項目の約束
- **`format`**：この仕様の版。いまは `1`。形を変えたら上げる
- **`lines`**：台本の順に**すべてのセリフ**を入れる（`index` は 0 から連番）
- **`text`**：画面に出す文。**TTS への指示は取り除く**（`<short pause>` のようなタグ、`(amable)` のような演技指示）。取り除いたあとの余分な空白も詰める。スペイン語の文字（á ñ ¿ ¡ など）はそのまま UTF-8 で
- **`direction`**：演技指示（なければ空文字）。画面には小さく出すかもしれない
- **`startMs` / `endMs`**：**完成した audio.mp3 の先頭から**の、そのセリフの声の始まりと終わり（ミリ秒・整数）
  - 実際に置いた位置を書く。リードイン（`leadInMs`）・間・ばらつき（`jitterMs`）・速さの調整（`tempo` の factor）をすべて反映したあとの値
  - クリップの前後に無音があるなら、それを含めた範囲でよい。ただし**次のセリフの `startMs` を越えない**こと
  - 精度の目安は ±50ms。前後の余白はプレーヤー側で足す
- **`durationMs`**：audio.mp3 の長さ

### mp3 について
- いまの形式（24kHz・モノラル・128kbps）でよい。ファイルを小さくしたいなら 64kbps でもかまわない
- mp3 は先頭に少し余分な無音が入る（エンコーダーの遅延。ふつうは数十ms）。精度の目安の内側なので、`startMs` は mp3 にする前の時間軸のままでよい。遅延が 100ms を超えるような設定で書き出すなら、その分を足して書く

### 書き出すときの自己チェック
- `lines` の数が台本のセリフの数と同じ
- どのセリフも `startMs < endMs`、前のセリフの `endMs` ≦ 次のセリフの `startMs`
- 最後のセリフの `endMs` ≦ `durationMs`
- `text` に `<` `>` や先頭の `(…)` が残っていない

## 作らなくてよいもの
- **単語ごとの時刻**：プレーヤーはセリフ単位で光らせるだけなので要らない
- **単語の意味・訳・下線用のデータ**：台本（`text`）があれば learning-engine 側で作る
- **翻訳**：同じく learning-engine 側で作る（必要になったら）

## 前提
- セリフ単位の生成（`mode: "line"`）でつないだ音声を前提にしている。会話全体を1回で読ませる方式の音声は、セリフの位置が分からないので対象外。その方式も使いたいときは相談してほしい
