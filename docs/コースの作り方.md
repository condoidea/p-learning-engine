# コースの作り方

新しい科目（例：世界史、化学、スペイン語）をこのエンジンで作るための手順と、教材の書き方。
基本情報技術者試験コース（`courses/fe/`）が完全な見本なので、迷ったらそれを見る。

---

## 1. ファイルを用意する

```
courses/<コースID>/
  course.js        コース設定
  theme.css        見た目（空でもよい）
  data/            教材
<コースID>.html    入口（fe.html をコピーして、course.js のパスと title を変える）
```
最後に `courses/registry.js` へ1行足すと、タイトル画面に並ぶ。

## 2. コース設定（course.js）

| 項目 | 内容 | 必須 |
|---|---|---|
| `id` | コースID（フォルダ名と同じ） | ○ |
| `version` | ファイルを更新したら上げる（ブラウザのキャッシュ対策） | ○ |
| `title` / `appName` / `brand` | タブの題名・アプリ名・ロゴ（`['前半','後半']`） | ○ |
| `storageKey` | 学習データの保存名（他コースと重複しないこと） | ○ |
| `files` | 読み込む教材ファイル（順番どおりに読む） | ○ |
| `exams` | 試験の区分。`{id, name, max, pass}`。合格ラインがなければ `pass: null` | 推奨 |
| `predict` | 予測スコアの見出し・注記・当てずっぽうで取れる割合 `guessRate` | 任意 |
| `roadmap` | ロードマップ画面の見出し | 任意 |
| `focus` | 特訓モード（特定の区分 `cat` だけを解く）。不要なら書かない | 任意 |
| `mock` | 模試（区分 `exam` から `count` 問）。不要なら書かない | 任意 |
| `fieldRules` | 分野ごとの特別ルール。`{分野ID: {limitSec, fast, ok, xpBonus}}` | 任意 |
| `titles` | レベルごとの称号 `[[レベル, '称号'], …]` | 任意 |
| `welcome` | 初回起動のメッセージ | 任意 |
| `highlight(src, esc)` | 問題文中のコードの色分け | 任意 |
| `legacyKeys` | 引き継ぐ旧データの保存名 | 任意 |
| `css` | コース専用CSS（`['theme.css']`） | 任意 |
| `fonts` | 書体の読み込みURL（Google Fonts） | 任意 |
| `terms` | 画面の呼び名の差し替え。例：`{card:'古文書', dex:'古文書館', boss:'宿敵', roadmap:'年代記', unit:'LIBER', lesson:'§'}`（キー一覧は `engine/js/terms.js`） | 任意 |
| `themes` | 着せ替えテーマ `{id:{name, accent, accent2, cost, legendary}}`。先頭がはじめのテーマ | 任意 |
| `mascot` | ナビキャラ `{ico:'🦅', name:'鷹のハビ'}`（なければ既定のロボ） | 任意 |
| `scene` | 背景のプリセット。`{preset:'royal'}`＝金の粒子と天球儀（3D）、`{preset:'map'}`＝古地図（`data/map.js` の `LE.mapData` が必要。three.js は読み込まない）、`{preset:'geo'}`＝方眼ノートと回る単位円（数学向け）。なければ既定のサイバー | 任意 |
| `sound` | 効果音の音色 `'royal'`（やわらかい音・低い太鼓。なければ既定の電子音） | 任意 |
| `typewriter` | `true` で吹き出し・説明の文字を一文字ずつ表示。キーワード（**太字**）は跳ねてマーカーが引かれる。吹き出しタップで全表示 | 任意 |
| `autoGloss` | `true` で、`LE.glossary` の用語（2文字以上）が文章に出たら自動で「？」つきヘルプにする（1つの文で最大3つ・選択肢などボタンの中には付けない） | 任意 |
| `recapTap` | `true` でまとめのキーワードをぼかし、思い出してからタップ | 任意 |
| `math` | `true` で `$…$`（行内）と `$$…$$`（独立）を KaTeX で数式にする。問題文・選択肢・解説・図の中でも使える | 任意 |
| `libs` / `extCss` | 外部ライブラリの JS / CSS（例：KaTeX）。cdnjs など | 任意 |
| `katexMacros` | KaTeX のマクロ。例：`{'\S': '\textcolor{#ff5fa2}{\sin}'}` | 任意 |
| `unitNumeral` | `'roman'` でユニット番号をローマ数字（Ⅰ・Ⅱ…）に | 任意 |

## 3. 教材データ

読み込み順の目安：分野 → ロードマップ → 問題 → レッスン → 追加問題 → 復習カード

### 分野（試験の出題範囲）
```js
LE.cats = [{ id: 'T', name: 'テクノロジ系', exam: 'A', weight: 41, color: '#38e8ff' }];
LE.fields = [{ id: 'basic', cat: 'T', name: '基礎理論', icon: '∑', weight: 6, desc: '…' }];
```
`weight` は予測スコアの重み（本番での出題比率に合わせる）。

### ロードマップ・ボス
```js
LE.unit({ id: 'u1', name: 'コンピュータの言葉', icon: '01', color: '#38e8ff', desc: '…' });
LE.bosses = { u1: { name: 'バイナリ・ゴーレム', ico: '🗿' } };
```
ユニットは**前提知識の順**に並べる（後のユニットが前のユニットの知識を使う）。

### 本番形式の問題
```js
LE.add('basic', [
  { q: '問題文', o: ['正解', '誤答', '誤答', '誤答'], e: '解説' }   // o[0] が正解（a で変更可）
]);
LE.addTo('u1-1', 'basic', [ … ]);   // 問題を登録し、レッスン u1-1 の解放対象にも加える
```

### レッスン
```js
LE.defLesson('u1', {
  id: 'u1-1', title: 'コンピュータはなぜ0と1なの？', goal: '…できるようになる',
  year: '1273年',            // 任意：歴史などで、ロードマップ・カードに年代を表示
  q: ['basic-005'],          // このレッスンをクリアすると解放される問題
  steps: [ … ]               // 最後は必ず recap（まとめ）
});
```

| ステップ `t` | 用途 | 主な項目 |
|---|---|---|
| `say` | 説明（ナビキャラが話す） | `text`, `viz`（図のHTML） |
| `term` | 新しい用語の紹介（用語集にも登録される） | `word`, `yomi`, `short`, `ex`（たとえ） |
| `quiz` | 確認問題（間違えても再挑戦できる） | `q`, `o`, `a`, `why`（選択肢ごとの解説）, `hint` |
| `match` | 用語と意味をつなぐ | `pairs`（右側は重複不可） |
| `order` | 正しい順に並べる | `items`（正解順） |
| `num` | 数値を入力 | `answer`, `unit`, `hint`, `solve`（解き方） |
| `steps` | 例題を1手ずつ見せる | `q`, `steps` |
| `trace` | プログラムを1行ずつ実行 | `code`, `rows[{l, v, say}]` |
| `timeline` | できごとを古い順にタップして年表を作る | `items[{y, t, label}]`（`y` は数値、表示を変えたいときは `label`） |
| `decide` | 決断（RPG）：人物になって選ぶ → 結末 → 史実 | `role`, `ico`, `q`, `o[{t, r, hist}]`（`hist:true` はちょうど1つ） |
| `advise` | 提言：説得力のある根拠を選んでゲージを満たす | `to`, `ico`, `need`, `win`, `o[{t, ok, r}]` |
| `route` | 旅：地図の上で駒を目的地へ進める | `piece`, `stops[{p, t, hint}]`, `decoys`（地名IDは `LE.mapData.places`） |
| `fill` | 穴埋め図（家系図など）：光る空欄に札を入れる | `viz`（空欄は `{{0}}`…）, `a`, `extra`, `hints` |
| `like` | たとえ：歴史 ⇄ いまでいうと を1行ずつめくる | `rows[[a, b]]`, `note` |
| `show` | 見せて教える：コマ送りで、キャラの台詞と図（ペンで描かれる）が変わっていく。インプット用で採点しない | `frames[{say, viz}]` |
| `widget` | 動かせる図形（コースの `LE.widgets[名前]` が描く）。ミッションをクリアで次へ | `w`（名前）＋ウィジェットごとの設定 |
| `build` | 公式を組み立てる：TeX の札を正しい順にタップ | `ans`（札の並び）, `extra`（ダミー）, `pre` / `post`（式の前後） |
| `bits` / `gate` / `stack` | 2進数・論理回路・スタックの体験 | 各専用項目 |
| `recap` | まとめ（復習カードの「要点」にもそのまま使われる） | `points` |

どのステップにも `art:'名前'`（挿絵。`LE.art` に線画SVGを登録。ペンで描くように表示）と `place:'地名ID'`（古地図の背景がその場所へ移動）を付けられる。レッスンにも `place` を付けられる。

本文の書き分け：`**覚えること**`（マーカー）、`__覚え方のヒント__`（💡波線）、`((この教材での呼び方・約束))`（📎グレー）。学習者は何を覚えるべきか判断できないので、必ず書き分ける（数式 `$…$` はこれらで囲まない）。

本文の書式：`**太字**`、`` `等幅` ``、`[[用語]]`（タップで意味を表示）、改行は `\n`。
図（`viz`）は `.vz-row` `.bx`（色 `c1`〜`c5`）`.ar`（矢印）`.vz-tbl`（表）などの部品で組む。

### 復習カード（1レッスン＝1枚）
```js
LE.cardDefs['u1-1'] = {
  ana: 'たとえ話の一言（レッスンと同じたとえ）',
  vizFind: 'レッスン内の図に含まれる文字列',   // その図をカードにも載せる
  how: ['公式や手順'],
  extra: [{ t: '補足の見出し', b: 'レッスン外だが試験に出る知識（レッスンの知識を前提に説明）' }],
  traps: ['ひっかけ注意']
};
```
「要点」はレッスンの `recap` から自動で入るので書かない（レッスンとカードの文言がずれないため）。

## 4. 教材の書き方（品質のルール）

このエンジンの価値は**初学者がわかること**。以下を守る。

1. **1画面1アイデア**：`say` は3行程度まで。言いたいことが2つあれば2画面に分ける。
2. **具体 → 抽象**：まず身近なたとえ（「CPU＝料理人」）→ 図 → 用語・公式、の順。いきなり定義から入らない。
3. **用語は先に紹介**：初出の専門用語は `term` で紹介するか `[[用語]]` で意味を引けるようにする。
4. **説明のすぐ後に確認**：`say` が2〜3枚続いたら、やさしい `quiz` / `match` を挟む。
5. **誤答にも理由を**：`quiz` の `why` で「なぜその選択肢は違うか」を書く。間違えても学べるように。
6. **計算は「例題 → 自力」**：`steps` で手順を見せてから、数字を変えた `num` を解かせる。
7. **問題を解くのに必要な知識は必ずレッスンで教える**：カードの「補足」だけに書いた知識で解く問題を作らない。
8. **補足は明記**：レッスンで扱っていない知識は、カードの `extra` に「補足」として書く。
9. **最後は recap**：そのレッスンで覚えてほしいことを3〜4点に絞る。
10. **事実確認**：歴史の年号・化学の数値・語学の綴りなどは、信頼できる資料で必ず確認する。

## 5. 確認する

```bash
node tests/check-course.js <コースID>
```
問題・レッスン・カードの対応漏れや書式の誤りを検出する。
そのあと `<コースID>.html?e2e` をブラウザで開き、全レッスンを自動で通せることを確認する。

## 6. 科目に合わせた拡張（今後）

| やりたいこと | 方法 |
|---|---|
| 見た目を世界観に合わせる（古地図・周期表など） | `theme.css` で配色トークン・書体・背景を差し替える |
| 新しい体験ステップ（地図ピン・音声など。年表 `timeline` は実装済み） | エンジンの `lesson.js` にステップ種別を追加し、どのコースからも使えるようにする |
| 新しい問題形式（入力式・リスニングなど） | エンジンの `ui.js` に問題形式を追加する |

科目専用のつもりで作った部品も、他の科目で使えることが多い（地図ピンは地理・生物の図にも使える）。
基本は**エンジンに追加して共有**し、どうしてもそのコースだけのものはコース側に置く。

## 問題に図をつける（数式コース）

`LE.addTo` の問題に `fig` を付けると、問題文の下に図が出る。
`fig: '<svg>…</svg>'`（HTML をそのまま）か、`fig: ['rt', {a:'3'}]`（`LE.figs.rt({a:'3'})` を呼ぶ）のどちらでもよい。
