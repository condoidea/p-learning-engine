# BIT RUSH 学習設計（v2：レッスン中心への作り直し）

## 何が問題だったか
- v1 は「問題演習＋要点カード」。要点カードは**すでに分かっている人向けの要約**で、初学者が読んでも理解できない。
- 知らない知識をいきなり問題で問うのは、初学者にとっては「当てずっぽう」でしかない（学習にならない）。

## 拠り所にした学習科学
| 知見 | 内容 | アプリへの落とし込み |
|---|---|---|
| 分割の原則（Mayer） | 学習者のペースで小さく区切ると理解しやすい | 1画面＝1アイデア。数行読んだら「つづける」 |
| 事前訓練の原則（Mayer） | 主要な用語を先に知っていると理解しやすい | 「用語カード」ステップ＋本文中の用語タップで意味を表示 |
| 信号の原則（Mayer） | 構造や要点を強調すると理解しやすい | 太字・図解・最後の「まとめ」 |
| 会話体の原則（Mayer） | 堅い文より話し言葉のほうが学びやすい | ナビキャラ「ピコ」が話しかける口調 |
| 二重符号化／マルチメディア | 言葉＋図で理解が深まる | 各説明に図解（アニメーション付き） |
| 具体→抽象（concreteness fading） | 身近な具体例から入り、徐々に抽象化すると応用が効く | 「たとえば〇〇」→ 図 → 用語・公式、の順で説明 |
| 例題学習効果・フェーディング | 初学者は解き方の手本を見てから解くほうが伸びる | 「例題（手順を1つずつ表示）」→「手順の一部を自分で」→「自力で」 |
| 熟達化反転効果 | 慣れてきたら手厚いガイドはむしろ邪魔 | レッスン後は通常の問題演習（ガイドなし）へ移行 |
| 生成効果・テスト効果 | 自分で答えを出すと記憶に残る | 説明の直後にやさしい確認問題。間違えても理由を説明して再挑戦 |
| 体験学習（Brilliant 型） | 操作して確かめると腹落ちする | ビットを押して数を作る、論理回路のスイッチ、スタック操作、プログラムの1行ずつ実行 など |
| 習熟学習（Mastery） | 前提を身につけてから次へ | レッスンを終えた範囲の問題だけが復習・演習に出る |
| 間隔反復 | 忘れかけで思い出すと定着 | 既存の SRS（忘却曲線）はそのまま「学んだ後」に使う |

## 新しい学習の流れ
1. **ロードマップ**（11ユニット・約45レッスン）を前提順に並べる。0と1の話から始まり、最後は科目Bのプログラム読解。
2. **レッスン**（1本 5〜8分）
   - たとえ話・図解 → 用語 → 体験（操作）→ 確認クイズ → 例題 → 自分で解く → まとめ
3. レッスンクリアで、その範囲の**本番形式の問題が解放**され、**要点カード**（復習用のまとめ）が手に入る。
4. 解放された問題は**間隔反復**で復習。
5. 毎日のメニュー＝「次のレッスン1本」＋「復習」。

## v3：復習カードをロードマップと連動
- **1レッスン＝1枚**（55枚）。番号・名前・色・並び順はレッスンと同じ（例：📍 Lesson 6-3）。
- 表面：**思い出そう**（レッスンと同じたとえ・同じ図）／**要点**（レッスンのまとめと同じ文章を自動で使う）／**公式・手順**。
- 裏面：**＋α補足**（レッスン外だが試験に出る知識。レッスンの知識を前提に説明）／**ひっかけ注意**／**マスター度**。
- 問題画面には「📍 Lesson x-y」タグを表示。問題→レッスン→カードの対応は推測でなく**データで1対1**。
- 「問題を解くのに必要な知識は必ずレッスン本体で教える」ルールで全問題を点検し、不足していた3か所（MIPSの計算、ライセンス形態、2分探索の最大比較回数）をレッスンに追加。

## v3：学習効果に結びつくドパガキ強化
| 演出 | 学習上のねらい |
|---|---|
| **ユニットボス戦**（全レッスンクリアで出現、7割正解で撃破、初撃破はレア宝箱確定） | ユニットの範囲を**混ぜて**出題＝インターリービング。本番の「どの知識を使う問題か見抜く力」 |
| **カード進化**（ブロンズ→シルバー→ゴールド→ホロ） | 進化条件＝その範囲の問題の**記憶の定着度**。復習そのものがご褒美になる |
| 進化演出は**リザルト画面でまとめて** | 問題を解いている最中は集中を邪魔しない |
| **記憶メーター＋RESCUED!** | 忘れかけた記憶を思い出せた瞬間を可視化＝間隔反復の価値を体感 |
| **ZONE**（レッスンで一発正解5連続、XP×1.5） | 集中状態を強化。間違えても罰はなく解除されるだけ |
| ロードマップの**開放演出・CLEARスタンプ** | 進捗の実感＝続ける理由 |
| **合格予測の節目お祝い**（400/500/600点…） | 最終目標（合格）への距離を意識させる |
| スマホの**振動** | 正誤の手応え（サウンドOFFなら振動もOFF） |

## v4：ドパガキ仕様の再点検（2026-11-10）

「続けたくなる」と「効果が上がる」の両方で、エンジン（全コース共通）を点検した。

| 弱点 | 足したもの | 学習上のねらい |
|---|---|---|
| 問題でまちがえても、解説を読んで終わり。レッスンへ戻る道がなかった（原則23（docs/原則.md）が、エンジンにだけ入っていなかった） | **🩹 おさらい**：まちがえた問題をレッスンごとに記録（`S.miss`）。ホームでは次のレッスンより先に「🩹 おさらい」、結果画面でも「もう1セット」より先に出す。押すと、そのレッスンの復習カード（要点）→「⚔ まちがえた○問にリベンジ」。あとの回で正解できたら記録から消える（同じセットの中の再出題では消さない） | 誤答の修正。読むだけで終わらせず、要点を見直してから同じ問題を自分で解き直す |
| 結果画面が「もう1セット／ホームへ」だけで、次に来る理由がない | **📬 明日の予告**（明日までにとどく復習の数）を結果画面に | 間隔反復の価値を見せる＝また来る理由 |
| デイリークエストに、達成できないものが混ざる（レッスンを全部終えたのに「レッスンを1本」など） | その日に達成できるクエストだけを出す。**ぜんぶ達成で、次の宝箱がレア以上に確定** | 目標は届くものだけ。3つそろえる動機 |
| 倒したボスに再戦する理由がない。逆に、再戦のたびにエピック宝箱が確定していた | **ボスの復活**：倒してから 7日 → 14日 → 30日で復活し、ホームに出る。復活したボスを倒すとエピック以上（すぐの再戦では確定しない） | 間をあけた、範囲を混ぜた総復習（間隔反復×インターリービング） |
| 「記憶救出」のボーナスが一律＋6で、コンボ（最大＋20）より小さい | 記憶が薄れていたほど大きく（＋7〜＋20） | 忘れかけで思い出すのが、いちばん効く。そこに一番の報酬を置く |
| まちがえた瞬間に「💔 コンボで途切れた…」のトーストが出て、解説から目がそれる | トーストをやめた。再挑戦・おさらいで正解したら「リベンジ成功！」 | まちがえた瞬間にいちばん見せたいのは解説（目線の誘導の原則） |
| ノルマの数え方が、ホーム（問題＋レッスンのステップ）と結果画面・ヒートマップ（問題だけ）でずれていた | すべて「問題＋ステップ」に統一。ノルマに届いた日は、ホームに戻ったときに1回だけ「DAILY GOAL!」 | レッスン中心の日も達成として数える |
| 連続記録が続いているのに、今日の分がまだのとき、何も言わない | ホームのあいさつに「🔥 ○日連続中。あと○問で今日の分を確保」 | 小さな習慣（1日3問）を思い出させる |

- お祝い・知らせは、問題やレッスンの途中に増やさない。ホーム・結果画面でまとめて出す
- 通しテスト（`?e2e`）に、おさらいの流れ（記録 → ホームのボタン → リベンジで消える）を足した

## ドパガキ演出
- ロードマップのノードが光って次が開く、星3つ評価、ステップ毎の XP とコンボ、正解時のパーティクル＆効果音、レッスンクリア演出、カード獲得演出。
