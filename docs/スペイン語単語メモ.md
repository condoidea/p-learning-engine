# スペイン語 単語メモ（アプリ横断）

スペイン語のアプリで、問題・例文に織り込んだ単語の一覧。**次のアプリを作るときに「どれを復習として使うか」「どれと被らないように新しく足すか」を決めるためのメモ。**

- 元のデータは [shared/es-words.js](../shared/es-words.js)（共通の単語帳）。アプリはこれを読んで、難しめの語（4級・4級より上）にバルーンを出す
- この文書は `node tests/check-relativo.js --memo` で作り直す（手で直さない）。回数は、そのアプリの例文・問題に出てきた回数（活用形もまとめて数える）。「よく出した語」はアプリの合計
- 「¡VAMOS!」の列：単語アプリ（vocab.html）のスペイン語デッキにもある語は ✓
- 新しいアプリを作ったら：使う語を単語帳に足し（ない語はチェックでエラーになる）、このスクリプトにそのアプリの文を集める処理と列を足す
- 次のアプリの語選びのめやす：**復習として使うなら「よく出した語」や 4級の語から**（このアプリで見慣れている）。**新しく足すなら、この表にない語**を選ぶと被らない

## アプリ

| 印 | アプリ | 中身 |
|---|---|---|
| relativo | ¡QUE FUSIÓN!（relativo.html） | 関係詞（que・quien・前置詞＋冠詞＋que・donde・lo que・el que・cuyo）。西検4級 |
| manda | ¡MANDA!（manda.html） | 命令表現（tú・usted・vosotros・ustedes の命令、不規則な8つ、代名詞をくっつける、「〜するな」）。西検4級 |
| protesto | ¡PROTESTO!（protesto.html） | 比較（más・menos…que、tan…como、mejor・peor・mayor・menor、tanto…como、el más…de、-ísimo、más de＋数）。西検4級 |
