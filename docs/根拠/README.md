# 根拠（毎回読める短い版）

**根拠の優先順位**：①信頼できる出典（論文・メタ分析・公的機関・企業の一次報告）②依頼者の指摘＝経験則③AI の推測〔推論〕。食いちがったら出典を優先。番号は [出典一覧.md](出典一覧.md)（L＝学習理論、G＝ゲーム）。ほとんどが抄録レベルの確認で、大学生・実験室・購買研究が多い（成人のスマホ学習アプリそのものの検証ではない）。確かさ：強い＝メタ分析など複数／中＝条件・素材で差が大きい／弱い＝少数・議論中。報告にない主張は「出典あり」と書かない。詳細：調査-学習理論.md・調査-ゲーム.md／未確認：まだ確かめていないこと.md

## 使わない通説
学習スタイルに合わせる（L34）／短期記憶は7±2（約4。L35）／集中は◯分で切れる（L35）／再読・ハイライト（低い有用性。L1）。
