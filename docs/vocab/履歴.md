### v1（2026-10-09）
入口 `vocab.html`、データ `vocab/decks/spanish/deck.js`、コア `core.js`、画面 `ui.js`。新しいデッキは `deck.js` の形で作る（スキン・サウンドはデッキの `skin`／`sound`）。未実装のまま：ラッシュ、スキル（武器）、スキン・サウンドパックの解放。

### v2：キャラクター・距離感・活用（ユーザーの感想から）
- **出会いと定着の差が分かりづらい** → ランクに関係の名前（出会った／顔なじみ／仲間／相棒）。ゴールド以上を「定着」とよぶ。
- **キャラクター感・自キャラと単語キャラの距離感** → 単語から自動で描くゆるキャラ（品詞＝体の形、性＝色、コンディション＝表情）。ホームの**広場**と、問題の上の**距離のトラック**（**その日に近づけるのは「出会った」まで**。そこから先は日を空けて思い出すと近づく）。王冠の小物はゴールドとまぎらわしいので使わない（花にした）。
- **図鑑のランクの色が見分けにくい** → 番号札と帯をランクの色で塗る。しおれても枠の色はあせさせない。
- **野生戦が初日に試せない** → 再会は翌日からのまま（ユーザーの選択）。ホームに「次の野生まで あと○時間」。
- **動詞は活用込みで（4級は接続法まで）** → 🔁 活用ブロック：12ユニット（1ユニット＝1つのくせ）。**お手本の表 → 予想 → 説明（🤔なぜ？）→ 練習**。動詞×時制ごとにカード（`cj:動詞:時制`）。

### v3：活用と単語の統合
活用は別の科目ではなく、**同じ動詞キャラの別の姿（フォルム）**。覚えた時制の色のスカーフを巻く。動詞が顔なじみになると現在形を、前の時制が顔なじみになると次を**覚えたがる**（2回正解で新フォルム）。野生では活用した形で現れる。くせの族（-go 族・ie 族…）は広場で並んで立つ。

### v4：参考書連動版デッキ
別のデッキ（区間＝課、単語に `ref`）。データは**端末に読み込む**（公開リポジトリに入れない）。読み込み口は最初コース一覧に置いたが、¡VAMOS! との関係が分かりにくかったのでアプリの中（「📚 デッキ」）に移した。大きなデッキの図鑑は課ごとにたたみ、開いた課だけ描く（600語で 1.2秒 → 0.04秒）。作り方：[単語データの作り方.md](単語データの作り方.md)。

### v5：英単語版 WORD AVENUE
- **英英定義を学習に**。**「単語 → 英英の説明」は高校生には難しすぎるので出さない**。英英の問題は読む時間をとるため自動で次へ進まない。**Playfair の斜体は文章だと読みにくい**ので使わない。英語は冠詞・名詞の性を扱わない。同じ意味の語は他の語の選択肢に入れない。
- **端末のダークモードに合わせない**（iPhone で暗く表示されていた。`color-scheme: light`）。

### v6：野生戦がたまらない仕組み・身に付いた瞬間
**問題**：以前の仕組み（ランクごとの長持ち日数）では、単語が増えるほど野生戦が増え続ける。試算（初日30語・毎日5語・全部正解）で180日目に1日75体。「貯めても責めない」は救いにならない（真面目な人ほど自分を責める）。1日の上限も付けない。

**根拠（出典で見直し）**
- 最適な間隔は「いつまで覚えていたいか」とともに伸びる（L6、強い）。**以前の「間隔は伸ばしていくべき」は強すぎた**：拡張と等間隔の差はほぼない（L8）。あけること自体が大事。
- Cepeda 2008 の割合（1週間後 20〜40%、1年後 5〜10%）は検索要約のみで**未確認**（L7）。SM-2（×2.5）・FSRS・WaniKani の burned・Anki の load balancer は発想の元で、一次資料は未確認（FSRS は L11）。
- よって下の数値は**設計上の値**〔推論〕。

**しくみ**（`vocab/js/core.js`。数値は設計.md）：記憶の強さ s。**s が240日を超えたら卒業**＝卒業させないと山はたまり続ける。**次にしおれる日は、0.85〜1.25倍の範囲でいちばん空いている日**に置く（同じ日に覚えた30語も分かれる）。試算で最大の日が95体 → 35体。まとめて覚えた日の2〜3日後の山だけは避けられない → **🤝 なつかせる**（24時間以内にしおれる子に先に会う）。

**身に付いた瞬間**（ユーザー：もっと情緒を。身に付いた！を強制的に実感させたい）：捕まえた・取り戻した・卒業したとき、画面いっぱいの短い場面。毎回出すと多すぎるので、しおれかけを助けたときは1行だけ。

### v7：たまったときも重くしない「ひと区切り」
v6 でたまりにくくはなったが、何日か空いたあとに「しおれ 90枚」と4か所に数が出て、「野生に戻る前に助けよう」と急かしていた。真面目な人ほど重く感じる。
- **残りの総数を出さない。見せるのは「ひと区切り」（12体・約5分）だけ**。終わったら「今日はここまでで大丈夫」。続けたいときは「もうひと区切り ▶」（上限ではない）。
- ひと区切りに入っていないしおれた子は 🥀 を付けず、すやすや顔（お昼寝中）。1週間以上空いたら「おかえり！ まずは 6体だけ」。
- 急かす言葉（「助けよう」「戻る前に」）はやめた。時間の圧力・愛着の圧力は子ども向けアプリで確認された害（G53）。

### v8：⚠ 緊急事態ボス
学習の途中に割り込むと時間が狂うので、**ホームにだけ**現れる。**音は出さない**。その日のうちで、逃しても何も失わない。あなたの単語12語でできたボスを**90秒**で倒す（まちがえると −5秒）。見破り（B）は単語の並び的に作りにくいので入れない。**まちがい・時間切れでは記憶を下げない**。90秒は「時間の圧力」に近いので、何も失わない約束を守る〔推論〕。

### v9：ドパガキ仕様の再点検（2026-11-10）
v7 の約束（残りの総数を出さない・急かさない・連続記録で責めない）は変えない。
| 弱点 | 足したもの |
|---|---|
| まちがえると「意味を1行見て終わり」 | **🔁 にげた子に、もう一度**（その回の最後に1回）。正解後も想起を続ける L5 L9 |
| まちがえた直後の正解が、まちがえた分（×0.4）を帳消しにしていた | **覚え直し**：6時間以内の正解は強さを伸ばさない。Anki の relearning と同じ考え方〔推論〕 |
| 4択でまちがえても、選んだ選択肢が何だったか分からない | **とりちがえた相手をならべる**（`S.mix`）。次からその語の選択肢に優先して入れる（近い：L12 L13）〔推論〕 |
| 長い目で見た達成感がない | **🏅 あしあと**（「あと○語」は出さない。通算なので休んでも減らない。G33） |

### v10：活用のテンポ・手ごわい子・おやすみ前の3体（2026-11-11）
ユーザー「活用学習がちょっとテンポが悪い」「もう一工夫、単語を覚えるという観点で何かないか（活用とは別の話）」。

**活用のテンポ**：遅かった原因は、正解のたびの6行の表（1.5〜1.8秒待ち）・語尾の札が6枚・練習前の「練習 ▶」画面。直し：**正解は短い1行で 0.6 秒後に自動で次へ**（表はボタンで）、語幹にくせがない形は語尾の1タップ、見たユニットは練習前の画面を飛ばす。**正解のあとに毎回同じ情報を見せて待たせない。止まるのは、まちがえたときと節目だけ**（反応の目安 0.1秒・1秒・10秒 G64）。

**🌶 手ごわい子**（単語カードだけ）：通算3回まちがえた語に印。「自分のことばで、覚え方を1行」＋きっかけのチップ。自分のメモ（`S.notes`）はデッキのメモより先に出す。次はちがう問い方で。2回続けて正解で卒業。
- 理由：自分で作った手がかりは残りやすい（生成効果 L27。**自作の手がかりそのものの効果は未確認**）。
- **チップ「音が似ている日本語は？」はキーワード法にあたり、主要な総説の評価は「低い有用性」（L1 L29）。2026-11-11 に「この語で、自分のことを短い文にすると？」へ差し替えた（自分で文を作る＝生成 L27・産出 L29。このチップそのものの効果は未確認）**（他のチップに出典はない）。

**🌙 おやすみ前の3体 → ☀ ゆうべの3体**：その日まちがえた語などから最大3語を、問題なしで眺める。次の日の最初にホームで「☀ ゆうべの3体、おぼえてる？」（1タップ・「あとで」で消える）。見なかった日は何も起きない（催促しない）。
- **理由づけを直した**：前は「寝る前に見たものは残りやすい」→ 出典で支えられない。いまは**翌朝の確かめ＝間隔をあけた想起**（L6 L8）。**寝る前に見ることの効果は未確認**（睡眠と定着は再現性に議論 L31）。
- 見送った案：答えたあとに「知ってた／あやしい」を自分でつける（手数がふえる。流暢さの感覚は当てにならない L32）、語の仲間・英語の親戚でつなげる（デッキごとにデータが要る）。

### v11：🎯 思い出しビンゴ・💬 ふれあいイベント（2026-11-11）
ユーザー「単語を覚えるという観点で、今とは違うゲーム性を入れてもいいかな（今の構成を崩す？）」「集めた単語たちと仲良くなるようなイベントみたいな演出も」。いつもの流れには混ぜず、ホームのアラカルトに「🎈 あそび場」を足した。結果は今までと同じ記録に流す。
- **🎯 ビンゴ**：3×3 の盤に意味が9つ。4択より探す範囲が広く、当てずっぽうが効きにくい。**フリーのマスを自分で選べる**（自信のない子を外せる）。まちがえたらゆれて「✕ このマスは ○○／○ 正解のマスは ここ」。**時間制限・負けなし**（時間の圧力に近づけない〔推論〕）。盤が意味／語を交互に。
- **💬 ふれあいイベント**：広場の1体に「！」。**1日1つまで・その日のうちだけ・やらなくても何も起きない**。🎂 きねん日（歩みを責めずに成長として）・🤝 しょうかい（とりちがえた組を**仲良しの組として覚え直す**）・✏ おねがい（例文の穴埋め）。終えるたびに 💛、3つでかざり。イベントの問いも、ふだんの復習と同じに数える。
