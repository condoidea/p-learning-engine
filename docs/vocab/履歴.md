### v3：活用と単語の統合（2026-10-09）

活用は別の科目ではなく、**同じ動詞キャラの別の姿（フォルム）**。動詞の一生＝出会い（意味）→ フォルムが増えていく。

- **A フォルム**：動詞カードに時制の印（8つの点）。シートに時制の札（覚えた＝ランク色／💬覚えたがっている／まだ）。キャラは覚えた時制の色の**しましまスカーフ**を巻く（フォルムが増えるほど色が増える）。
- **B 覚えたがる**：動詞が顔なじみ（シルバー）になると現在形を、前の時制が顔なじみになると次の時制を「覚えたがる」。順番：現在 → 点過去 → 線過去・現在完了 → 未来・過去未来 → 接続法 → 命令。ホームのお知らせ・広場の💬・シートの札から入り、**そのくせのユニットを初めてなら「くせの教室」（お手本→なぜ）**、習ったことがあれば予想から。2回正解で新しいフォルム。おまかせ（しっかり）にも入る。
- **C 野生では活用した形で現れる**：フォルムを持つ動詞は、野生戦でときどき「comerá」の姿で現れる。① 元の動詞の意味は？（単語のカード）② 誰が・いつ？（その時制のカード）。
- **D くせの族**：-go 族🎸・-zco 族🦓・ie 族🌿・ue 族🌊・i 族🕯・特別な子🎭・-ar／-er／-ir 族。説明と「覚えたがる」画面に族と仲間（会った子は濃く）。現在形の予想は「この子は -go 族。yo は？」と族の決まりで。広場では同じ族が並んで立つ。
- 「🔁 活用」のユニット一覧は、アラカルト（自分で選ぶ教室）として残す。

### v6：野生戦がたまらない仕組み・身に付いた瞬間（2026-10-10）

**問題**：以前の仕組み（ランクごとの長持ち日数、正解が続いても2.6倍で頭打ち）では、単語が増えるほど野生戦が増え続ける。試算（初日30語・毎日5語・全部正解）で180日目に1日75体。「貯めても責めない」は救いにならない（真面目な学習者ほど自分を責める）。1日の上限も付けない（やる気のあるときはたくさんできてよい）。

**根拠**
- SM-2（Anki の元）：1日 → 6日 → 以降 ×2.5（ease factor の初期値）。
- FSRS：記憶の強さ（stability）の伸びは、思い出したときの思い出しにくさで変わる。忘れかけて思い出すほど大きく伸び、早すぎる復習は伸びが小さい。
- Cepeda ほか（2008）：最適な復習の間隔は、覚えておきたい期間が長いほど長くなる（1週間後なら20〜40%、1年後なら5〜10%）。間隔は伸ばしていくべき。
- WaniKani・Bunpro：4時間 → … → 4か月で「もう出ない」（burned）。卒業させないと、山はたまり続ける。
- Anki の load balancer：次の復習日を、少し前後の範囲で空いている日に置く。

**しくみ（vocab/js/core.js）**
- カードごとに記憶の強さ s（コンディションが半分になるまでの日数）。出会ったとき 1.2日（約12時間でしおれ始める）。
- しおれてから思い出せたら s ×2.5（遅いほど少し多め、最大×2.9）。しおれる前に会ったら（なつかせる）、その早さに応じて少なめ（例：8割の時点なら×2.2）。まちがえたら s を4割に。
- **s が240日を超えたら卒業**：もう野生に出ない（図鑑と広場には🎓で残る）。しおれるたびに思い出せば 0.5 → 1.3 → 3.2 → 7.9 → 19.9 → 49.6日の間隔で6回、約3か月で卒業。
- **次にしおれる日は 0.85〜1.25倍の中でいちばん空いている日**（2日以上先のとき）。同じ日に覚えた30語も、3回目からは3・4・5日後に10語ずつ分かれる。
- 試算：最大の日が95体 → 35体、270日目以降は卒業でほぼ0。まとめて覚えた日の2〜3日後の山だけは避けられない（最初の数回の復習は短い間隔が必要）→ **🤝 なつかせる**（24時間以内にしおれる子に先に会う）で、自分で山を崩せる。おまかせでも、野生が少ない日は自動で入る。
- 古い記録は、以前の長持ち日数から s に移す。

**身に付いた瞬間（ユーザー：もっと情緒を。身に付いた！を強制的に実感させたい）**
- 出会いで捕まえたとき・野生から取り戻したとき・卒業したとき、画面いっぱいの短い場面：単語キャラが遠くから自キャラのとなりへ（取り戻したときは色が戻る）→ ハート（💛／💙／🎓）→ 言葉がゆっくり浮かぶ → ひとこと → 「次に会うのは約○日後（前は約○日）」。少し待ってから「タップでつづける」。
- しおれかけを助けたとき（野生ではない）は、答えのあとに「🌱 長持ち：約1.2日 → 約2.7日」。場面を毎回出すと多すぎるので、取り戻したとき・卒業のときだけ。
- 顔見知りチェック（知っている語の確認）は、テンポを優先してこれまでどおり軽い演出。

### v7：たまったときも重くしない「ひと区切り」（2026-10-11）

v6 でたまりにくくはなったが、何日か空いたあとなどにたまってしまうと、ホーム・タイル・図鑑・結果の4か所に「しおれ 90枚」と数が出て、「野生に戻る前に助けよう」と急かしていた。真面目な人ほど重く感じる。

- **残りの総数を出さない。見せるのは「ひと区切り」（12体・約5分。英英など読む問題もあるので1体25秒くらいで見積もる。スペイン語・英語とも）だけ**：野生戦のタイルは「ひと区切り 12体（約5分）」。図鑑のタイルも枚数だけ。「覚えたがっている」も「ほかに○体」を出さない。
- **ひと区切り終わったら「✔ ひと区切り、おわり。今日はここまでで大丈夫。」**。続けたいときは「もうひと区切り ▶」（上限ではない。何度でも続けられる）。
- **順番**：覚えたばかり・忘れかけの子が先。記憶の強い子（長持ち2週間以上）は少し待っても忘れにくいので後ろ。
- **お昼寝中**：ひと区切りに入っていない、しおれた子は 🥀🍂 を付けず、色もそのままの すやすや顔（広場）・💤（図鑑）。シートでは「記憶が強い子なので、少し待っても大丈夫。そのうち野生戦で会える」。
- **久しぶり（1週間以上）**：「👋 おかえり！ みんな待ってたよ。まずは 6体だけ、会いに行こう」。最初のひと区切りは半分の6体。
- 急かす言葉（「助けよう」「戻る前に」）はやめた。

### v8：⚠ 緊急事態ボス（2026-10-11）

ゲーム的な要素の強化。学習の途中に割り込むと時間が狂うので、**ホームにだけ**現れる。

- **出方**：3〜4日に1回（単語が10語以上そろった翌日から）。ホームの上に赤い警報の帯。**音は出さない**（予期しない大きな音はまずい）。帯がときどき小刻みに揺れるだけ（動きを減らす設定なら揺れない）。
- **期限**：その日のうち。何度でも挑める。翌日には静かに去る（逃しても何も失わない）。
- **中身（C＋A）**：ボスの体は あなたの単語12語でできている（もうすぐしおれる子・しおれた子・弱い子の順に選ぶ＝大きな「なつかせる」）。**90秒**。正解するとその語のパーツが砕けて、単語キャラを助け出す。3連続でクリティカル（＋3秒）。まちがえると反撃（−5秒、その語はあとでもう一度）。問い方は速い4択だけ（意味・英語/スペイン語・聞き取り・英英→単語）。見破り（B）は、単語の並び的に作りにくいので入れない。
- **記憶への影響**：正解はふだんの復習と同じに数える（早めなら伸びは小さい＝正直）。勝ったら正解した語に長持ち＋15%のおまけ（卒業の手前まで）。まちがい・時間切れでは記憶を下げない。
- 勝つと「🏆 撃破！」と助け出した単語の一覧、ボス図鑑（`S.bossWins`）に記録。ホームの帯は緑の「倒した！」に。

### v9：ドパガキ仕様の再点検（2026-11-10）

「続けたくなる」と「効果が上がる」の両方で点検した。v7 の約束（残りの総数を出さない・急かさない・連続記録で責めない）は変えない。

**見つけた弱点と、足したもの**

| 弱点 | 足したもの |
|---|---|
