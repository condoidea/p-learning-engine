## 根拠メモ（2026-11-11 出典で見直し。番号は [出典一覧](../根拠/出典一覧.md)）
- **間隔**：間隔をあけた想起は保持が良い（L6 L8）。**広げ方（拡張）にこだわる必要は薄い**（等間隔と差がほぼない L8）。Cepeda 2008 の割合（1週間後 20〜40%、1年後 5〜10%）は検索要約のみで未確認（L7）。「忘れかけを狙うほど伸びる」（FSRS の発想）は本調査で確かめていない〔未確認〕。
- **🔁 もう一度・正解するまで＋日をあけて戻す**：正解後も想起を続け、回をまたいで繰り返すと長期保持が大きい（L5 L9。大学生の実験室）。
- **🌶 手ごわい子**：「自分で作った手がかり」は生成効果の仲間（L27：自分で出すと残る。自作の手がかりそのものの効果は未確認）。**きっかけのチップ「音が似ている日本語は？」はキーワード法にあたる。主要な総説の評価は「低い有用性」（L1 L29）。このチップは2026-11-11 に「この語で、自分のことを短い文にすると？」へ差し替えた（自分で文を作る＝生成 L27・産出 L29。このチップそのものの効果は未確認）**（コードは別の人が直す）。他のチップ（どの英語に似ている？／どんな場面で使う？）に出典はない〔推論〕。
- **🌙 おやすみ前の3体 → ☀ ゆうべの3体**：効く理由は「翌朝の確かめ＝間隔をあけた想起」（L6 L8）。**寝る前に見ることの効果は未確認**。睡眠と記憶の定着は再現性に議論がある（L31）。仕組みは残す。
- **ボスの「混ぜて出題」**：識別型の問題には混ぜるのが有利だが、**単語では混ぜるよりブロックが良い**（L12）。ボスの価値は「混ぜる」より「間をあけた想起」（L8）で説明する。出会い（新語3〜5語）は混ぜない（原則27）。
- **✨ きらきらの子・ときどきレア（予測できないごほうび）**：学習への効果は出典が割れている（有利 G24／影響なし G25）。お金がからむ抽選は問題ギャンブルとの関連が報告されている（相関のみ。G19 G20）ので使わない。お金なし・量は確実・見せ方に少し変化、にとどめる。
- **急かさない**：時間の圧力・愛着の圧力（「かわいそう」）は 3〜5歳向けアプリで確認された害（G53）。90秒のボスやビンゴの時間制限は「負けなし・何も失わない」を保つ。しおれる表現でも急かす言葉は使わない（v7）〔推論〕。
- **連続記録で責めない**：1日抜けても習慣形成への影響は小さい（G33）。
- **自己申告にしない**：流暢さの感覚で学習を判断してしまう（L32）。自己評価の指導は「エビデンス最小」（L24）。自己申告に頼らず正解したかどうかで自動判定する理由になる〔推論〕。

## 出発点

- いきなりテストだと答えられなくて困る。でも、ただ見るだけでは退屈。
- **Anki のようにはしない。** Anki の退屈・つらさの原因と、こちらの方針：

| Anki | なぜつらいか | こちらの方針 |
|---|---|---|
| 最初からカードを裏返してテスト | 知らないものを問われる（原則1に反する）〔経験則〕 | **出会い → すぐ使う → 思い出す**の小さなループ |
| 「もう一度／難しい／普通／簡単」を自己申告 | 面倒で、甘くなる（出典：L24 L32） | 正解したかどうかで**自動判定** |
| 期限切れカードが積み上がる | 開くたびに借金を見せられる〔経験則〕 | 復習を借金にせず**再登場**として混ぜる |
| カードの形がずっと同じ | 脳が慣れて素通りする〔推論〕 | **問い方を段階的に変える** |
| 単語が孤立している | 意味がつながらない | 語源・対比・文脈で**つなげる** |

> Anki は「カードの山を崩す作業」、こちらは「単語を育てて図鑑を埋めるゲーム」。

## 進化ラダー（1語ごとの段階）

段階が上がるごとに問い方が変わる。

1. **出会い**：例文やシーンの中で出会う。覚え方のヒント（語源・音・イメージ）付き。採点しない。
2. **予想**：見る前に予想させ（例：pre＝前＋dict＝言う → 意味は？）、答えると説明が出る。採点しない（成人の単語では、当て推量→すぐ訂正が読むだけに勝った L26）。
3. **見分ける**：見たばかりの数語から選ぶ。答えられる難しさ。
4. **組み立てる**：つづりをタイルで組み立てる／定義から用語を当てる（`build` の応用）。
5. **使う**：例文の穴埋め、まぎらわしい語との使い分け、仲間分け。

- 1回に扱うのは **3〜5語**。その中で 1→3 まで一気に上げる（すぐ答えられて気持ちいい／自分で思い出しているので見るだけにならない）。
- 4・5 は次の日以降の**再登場**で出す（間隔反復を「復習」と感じさせない）。
- 原則2：タップするだけで解ける問題は作らない。

## カードの成長：武器と敵

### 強いカードは「武器」、弱い単語は「敵」

「強い＝よく覚えている」をそのまま攻撃力にすると、強いカードばかり使って弱い単語が放置される。そこで役割を分ける。

- **敵は、まだ定着していない単語**（出会ったばかり・しおれかけ）。
- **倒すには、その単語の問題に正解する。** 攻撃＝答えること。
- **育てたカードは、敵を倒すのを助けるスキル**：
  - 🥉 ブロンズ：制限時間 +3秒
  - 🥈 シルバー：選択肢を1つ消す
  - 🥇 ゴールド：最初の1文字を見せる
  - ✨ ホロ：1回だけミスを帳消し
- **倒した敵は自分のカードになる**（捕獲）。ブロンズから始まる。

| 単語の状態 | ゲームでの姿 |
|---|---|
| まだ習っていない | 出てこない（原則1：出会う前に戦わせない） |
| 出会ったばかり・しおれかけ | 敵（野生） |
| 正解して捕まえた | 自分のカード（ブロンズ） |
| 時間を空けても答えられた | 進化（シルバー → ゴールド → ホロ） |

### 経験値のルール

- **間を空けて思い出せたときに、たくさん経験値が入る。** 同じ日に何回答えてもほとんど入らない（連打で育てる「作業」を防ぐ。間隔をあける効果は L6 L8）。
- 間隔反復がそのままゲームのルールになる。「寝かせたカードが育つ」感覚。

### レベルとコンディションを分ける

- **レベル**（ブロンズ〜ホロ）：最高到達。**下がらない**（達成感を守る）。
- **コンディション**：いまの定着度。時間で下がり、カードがしおれる。下がりきると「野生に戻りかけ」として敵側に出る。
- ホロでも放っておくと敵として現れる → 強い単語のメンテナンスも自然に回る。取り返すと「おかえり」。

## 進め方：流れを固定しない

使える時間も気分もその時々で違う。**一連のプロセスは固定しない。** 負担感をなくす。

### ブロック（それぞれ単独で始められる）

| ブロック | 中身 | 目安 |
|---|---|---|
| 🌱 出会い | 新しい単語 3語（予想 → 説明 → 見分ける → 捕獲） | 約2分 |
| ⚔ 野生戦 | しおれかけ・未捕獲の単語と戦う | 約2分 |
| 👑 ボス | 区間・テスト範囲を混ぜて出題（条件を満たしたときだけ） | 約3分 |
| ⚡ ラッシュ | 捕獲済みの単語だけで時間制限の連打 | 1分 |
| 📖 図鑑 | 眺める・しおれたカードを1枚ずつ救出 | 自由 |

### 選び方

- **アラカルト**：ブロックを直接選ぶ。
- **おまかせ（時間）**：1分（ラッシュ or 救出1枚）／5分（野生戦＋出会い）／10分（出会い＋野生戦＋ボス）。その日の状態を見て中身を変える。
- **気分**：🧠 しっかり（新語・つづり・使い分け）／😌 ゆるく（知っている語の見分け・ラッシュ）。

### 負担感を減らす約束

- **いつやめても損をしない。** 途中で閉じても、答えた分の経験値と捕獲は記録する。
- **ボスは強制しない。** ホームに「挑戦できます」のバッジを出すだけ。ロードマップの奥に隠さない（学習アプリではボスがロードマップからしか行けず、アクセスが悪かった反省）。
- **連続記録で責めない。** 途切れても「おかえり」。
- **ノルマを出さない。** 「残り○語」ではなく「今日は○語育った」。

### ボスが出るきっかけ

| きっかけ | 中身 |
|---|---|
| 1区間（例：20語）を全部捕獲 | その区間をまとめて出題（間をあけた想起。混ぜる効果は単語では出典で支持されない L12） |
| 小テストの前日（日付と範囲を登録） | テスト範囲の総まとめ（Database 向け） |
| 週1回 | その週に出会った単語を混ぜて出題 |

ボス戦では育てたカードのスキルが活躍する。

### ホーム画面のイメージ

```
┌──────────────────────────┐
│ 図鑑 63%    今日 +12 EXP  │
│ 👑 ボス挑戦可（101〜200） │  ← 出ているときだけ
│                           │
│ おまかせ                  │
│ [ 1分 ] [ 5分 ] [ 10分 ]  │
│  気分：🧠しっかり / 😌ゆるく│
│                           │
│ アラカルト                │
│ 🌱出会い  ⚔野生戦  ⚡ラッシュ│
│ 📖図鑑（しおれ 4枚）       │
└──────────────────────────┘
```

範囲指定（「101〜200 だけ」）は設定の中。普段は表に出さない。

### その他のご褒美

- しおれるカードを「助けに行く」（借金より救出のほうが動機になる〔経験則〕）。「かわいそう」の圧力にはしない（G53）。
- ときどきレアカード・クリティカル演出（予測できない報酬）。学習への効果は出典が割れている（G24 G25）。読む画面では控えめ（原則9）。

## 見た目・音のバリエーション

同じ音・演出だとマンネリ化する。バリエーションを多めにつける。うまくいったものは学習アプリ（`engine/`）にも戻す。

### 3つの層

1. **デッキごとの世界観**：スペイン語＝ギター風のはじく音・コンボで手拍子、陽ざし・タイル柄・暖色／情報基礎＝8bit、ターミナル・ドット／Database＝娘の好みに合わせる。
2. **ブロックごとの雰囲気**：出会い＝静か（読む画面なので控えめ）／野生戦＝打撃音・ヒットの揺れ／ボス＝重低音・全画面／ラッシュ＝コンボでテンポと音程が上がる／図鑑＝きらめき・めくる手ざわり。
3. **予測できない変化**：撃破・捕獲・進化の演出を数種類からランダム／朝夜・季節で色合い／育てた数でサウンドパック・スキンを解放。

### 変えてはいけないもの

- ボタンの位置・画面の構成（毎回探すことになる）
- 文字の読みやすさ（大きさ・コントラスト）
- 意味のある色（正解・不正解、カードのランク）

> 変えるのは「色・音・演出」、変えないのは「操作・読みやすさ・意味」。

### 作り方

- **サウンドパック**：音色・音階・フィルター・コンボ音をデータで定義。今の `audio.js` の `ROYAL` 分岐をパックの1つに置き換えるイメージ。
- **スキン**：色・フォント・背景を CSS 変数のまとまりで定義。
- **演出**：撃破・捕獲などを種類ごとに登録し、そこから選ぶ。

### 単語と用語集で見せ方を変える

学習アプリの「基本情報」と「ハプスブルク」が違うように、外国語の単語と用語集は見せ方を変える。

- **外国語の単語**：音（発音）・つづり・性や活用・例文の中での使い方が中心。
- **用語集**：分解して「なぜ？」（略語の展開、漢字の意味）・用語どうしの関係図・定義のまちがい探し・状況の中で使う用語を選ぶ（`decide` の応用）。

## リポジトリ構成とデータ

**同じリポジトリで、フォルダを分ける。** 効果音・触覚・演出などの共通部品を共有でき、改良を学習アプリにも戻せるため。ただし、今のエンジンの中心（`core.js`・`ui.js`・`lesson.js`）には乗せない（考え方が違うので両方が複雑になる）。

```
engine/            今の学習アプリ
  js/audio.js      ← 単語アプリからも読み込む（サウンドパック化して共有）
  js/fx2d.js       ← 同上
vocab/             単語アプリ
  js/core.js       カードの成長・しおれ・経験値
  js/ui.js         ホーム（おまかせ／アラカルト）・各ブロック
  decks/spanish/   スペイン語（公開OK）
  decks/joho/      情報基礎（公開OK）
  decks/database/  ← .gitignore で除外（公開しない）
vocab.html         入口
```

### 端末：特定の機種に依存しない

- 使う人：ユーザー本人は **iPhone（Safari）**、娘は **Android（Chrome）**。学習アプリ（三角比など）も単語アプリ（Database）も、どちらの機種でも使う。
- **機種ごとの対策は、標準の動きに上乗せする形だけにする。** iPhone 専用・Android 専用の機能に頼らない。
- 振動は共通の `audio.js`（標準の Vibration API／iPhone は触覚スイッチで代用）。発音は標準の音声合成（どちらにもある）で、学ぶ言語の声を自動で選ぶ。声がない端末でも学習は進められるようにする。

### 題材ごとのデータ

| 題材 | データの集め方 |
|---|---|
| スペイン語 | 自作（下記）。公開OK |
| 情報基礎 | 教材に合わせる。なければ IPA のシラバスの用語から。公開OK |

### Database の扱い（⚠ リポジトリは公開）

- **本から取り出すのは**：見出し語番号・単語・品詞・意味（短く）だけ。番号は学校の小テスト範囲と合わせるのに必要。
- **本から取り出さないのは**：例文・解説・語源コラム。例文などはオリジナルで作る。
- 家庭内での私的な利用にとどめる。**公開リポジトリには入れない**（`decks/database/` を `.gitignore` で除外）。娘の Android（Chrome）へはファイル読み込みで取り込み、端末の中に保存する。
- 「今週の小テスト範囲（番号○〜○）」を選んで回せるモードを作る。前日にはボスが出る。

## 最初の題材：スペイン語（西検4級）

- ユーザーは**西検（スペイン語技能検定）5級を保持**、**4級を目指す**。
- 5級レベルの語は「顔見知り」。いきなり出会いからやり直すと退屈なので、**最初に素早く捕獲できる場（顔見知りチェック）**を用意する。答えられたらブロンズで図鑑に入る（既に学んだ語なので原則1に反しない）。答えられなかった語だけ、出会いからやる。
- 4級で新しく必要な語は、出会い → 予想 → 見分ける から。
- スペイン語ならではの部品：
  - **発音**：iPhone の音声合成（`speechSynthesis`、es-ES）で読み上げる。
  - **名詞の性**：男性・女性を色で固定する（色は意味で固定）。冠詞（el / la）とセットで覚える。
  - **予想のヒント**：英語と似た語（同語源語）を手がかりにする（例：información ← information）。似ているのに意味が違う語（偽りの友）は、ひっかけ・使い分けで出す。
  - **動詞の活用**：西検では活用が重要。単語のカードとは別のブロック（活用）として後で検討する。

### 試作の範囲（まずここまで）

出会い → 予想 → 見分ける → 捕獲 → 図鑑。バトルは後回しにして、**カードが育つ手ざわり**を先に iPhone で確かめる。
