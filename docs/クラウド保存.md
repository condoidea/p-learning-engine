# クラウド保存（Supabase）

学習の記録は今までどおり**端末（localStorage）に保存**し、ログインした端末だけ、同じ中身を**クラウドにも置く**。

- 目的：端末をなくした・消えたときの備え／端末をまたいで続きから学ぶ
- 使う人：自分と娘（1人1アカウント）
- ログインしていない端末・設定前は、今までとまったく同じ動き（端末だけ）

## しくみ
- `shared/cloud.js` を全アプリの入口の `<head>` の最初で読み込む。アプリ側のコードは変えていない
- localStorage のキー1つ＝クラウドの1行（`kv` テーブル）。中身は文字列のまま置く
  - 同期しないキー：`cloud.*`（ログイン情報など）・`le.news.*`（お知らせの既読）・`e2e` や `sandbox` を含むもの（テスト・お試し）
  - `?e2e` `?sandbox` で開いたページでは同期しない
- いつ同期するか
  - ページを開いたとき：クラウドの変化を取りこむ → この端末の変化を上げる
  - 学習中：変化があれば15秒に1回まで上げる
  - ほかのアプリに切りかえた・閉じたとき：上げる
  - 20秒以上たってから戻ってきたとき：取りこむ
- アプリがすでに読んだ記録が、ほかの端末の記録で入れかわったら、ページを読み直す（画面の中の記録で上書きしないように）
- 両方で変わっていたら（オフラインで2台を使ったときなど）、**あとで変えたほう**を残す。負けたほうは `kv_history` に残る
- `kv_history` には、1時間に1回まで前の版が自動で残る（30日で消える）。`cloud.html` の「前の記録に戻す」で戻せる

## 準備（1回だけ）
1. https://supabase.com でアカウントを作る（GitHub でログインできる）
2. **New project**：名前は何でもよい。Database Password は控えておく（このアプリでは使わない）。Region は **Northeast Asia (Tokyo)**。プランは Free
3. 左の **SQL Editor** → New query → [cloud-setup.sql](cloud-setup.sql) の中身を貼って **Run**
4. **Authentication → Sign In / Providers**：「Allow new users to sign up」を**オフ**（知らない人がアカウントを作れないように。大事）
5. **Authentication → Users → Add user → Create new user**：自分と娘の2人分。メールアドレスとパスワードを入れ、「Auto Confirm User」にチェック
   - メールアドレスは実在しなくても動く（確認メールを送らないため）。パスワードは端末で1回入れるだけ
6. **Project Settings → API Keys**（または Data API）で **Project URL** と **anon（public）key**（新しい画面では Publishable key）を控える
7. `shared/cloud.js` の上のほうの `SB_URL` と `SB_ANON` に入れて push（anon key は公開してよい鍵。中身は「自分の行だけ読み書きできる」設定で守られる）

## 端末ごと
1. コース選択の一番下「☁ クラウド保存」→ ログイン
2. 「この端末をつなぐ」
   - 片方にしかない記録は、もう片方にも入る
   - 同じアプリの記録が両方にあって中身がちがうときだけ、どちらを残すか聞かれる（残さなかったほうも履歴に残る）
   - **1台目**は今いちばん記録がそろっている端末でつなぐ。2台目からは「クラウドの記録を残す」が基本

## 気をつけること
- **1週間だれも使わないと、Supabase の無料プロジェクトは一時停止する**。停止中は同期できないだけで、端末の保存はそのまま続く。ダッシュボードで Restore すれば戻る
- 1つのブラウザには1人分。同じ端末・同じブラウザを2人で使う場合は、どちらか一方だけログインする
- 「プライベートブラウズ」ではログイン情報が残らない
- 単語デッキ（参考書のデータ）もクラウドに置かれる。自分のアカウントからしか読めない
- テスト用に設定を書きかえずに試すときは、`cloud.html` の「この端末だけで試す」に URL と key を入れる（localStorage `cloud.conf`）

## 困ったとき
- `cloud.html` に「最後の同期に失敗しました」と出る：通信・プロジェクトの一時停止・ログイン切れを確認
- 記録がおかしくなった：`cloud.html` の「前の記録に戻す」でキーを選んで戻す。もっと前が必要なら Supabase の Table Editor で `kv_history` を見る
