# 原則（毎回読む短い版）

番号は指摘を得た順（25〜は出典から）。きっかけ・例は [原則-くわしく.md](原則-くわしく.md)。理由づけ・新しい仕組みは [根拠/README.md](根拠/README.md)。
**印**：〔出典 L5〕＝論文・報告あり（[出典一覧](根拠/出典一覧.md)）／〔経験則〕＝依頼者の指摘（出典では未確認）／〔経験則・近い出典 L○〕＝近い研究があるだけ／〔推論〕＝AI の推測。優先は 出典＞経験則＞推論。

## 順番と分かりやすさ
1. **知識を入れる前に、採点する問題を出さない。** まず覚える（短く・楽しく）→ すぐ思い出す → 定着。「答え → すぐ説明」の予想はよい〔経験則・近い出典 L16 L26〕
2. **「タップするだけで解ける」問題は NG。** その知識を使わないと解けない操作にする〔経験則・近い出典 L2 L27〕
3. **受け身の「次へ」「次へ」にしない。** 自分で押す→結果。説明は「問い（予想）→ 答えると説明」〔経験則・近い出典 L26 L32〕
22. **飛ばして置いていくほうが、長くてだるいよりまずい。** 書いたら全レッスンを頭から読み、未習の言葉・一段飛ばしを洗う。長くなるなら分ける〔経験則〕
21. **説明は見る順に：見る → 根拠 → 結論 → 名前。** 結論や未習の言葉を先に出さない。図のキャプションでも答えを先に見せない〔経験則〕
15. **説明を一足飛びにしない。** 1段の省略・書き方の約束・前提の関係は使う前に教える。長い所は「🤔 なぜ？」(`more`) で開く〔経験則・近い出典 L16 L21〕
19. **理由は「A だから B、B だから C」と途中を省略しない。** 言葉だけで分かりにくい所は図もそえる〔経験則・近い出典 L20〕
16. **良い tips ほど理由（`why`）もそえる。** 問題で使うコツはレッスンでも教える〔経験則〕

## 目線と動き
20. **操作中は目線が操作の場所にある。** 書き換わる指示は、指示そのものの動き（`Y.chg`）で引く。別の場所への知らせ（トースト）は NG。見せたいものを1つに決め、動きはそこだけ。次に触る物の目印は動かない光で〔経験則・近い出典 L18 L20〕
4. **図形のアニメーションは説明に沿って、適度に。** 文と図を連動〔出典 L19 L20 L22〕
17. **言葉の説明より、前に動かした図をもう一度。** 前のウィジェットを新ミッションで再登場〔経験則〕

## 覚える・思い出す
14. **思い出させるときは手がかりを見せる。** 「問い（見える）＋答え（ぼかす）」。全部ぼかさない〔経験則・近い出典 L1 L2〕
5. **前に教えたことがまた出たら、同じ説明を復習として繰り返す。** 1〜2回で十分〔経験則・近い出典 L8〕
23. **一度読んだだけでは覚えきれない前提。** まちがえた問題をレッスンごとに記録 → その場で Tips・表を開ける／要点だけの「おさらい」＋リベンジ（正解で記録から消える）／ホームで次より先に出す〔出典 L9 L25〕
18. **計算問題は「解き方の型」＋「数字が変わる演習」で厚く。** レッスンは軽いまま、`tip` と `drill`。まちがえたら1手ずつ〔出典 L16 L24〕
25. **正解したあとも思い出す練習を続ける。** その回は正解するまで、さらに日をあけて戻す〔出典 L5 L9〕
26. **間隔は「あける」ことが大事。広げ方（拡張）にこだわらない。** 覚えておきたい期間に合わせて伸ばす〔出典 L6 L8〕
27. **見分け（どれを使うか）は混ぜて練習。単語の新規学習は混ぜない。** 〔出典 L12 L13 L14〕
28. **受容（意味を選ぶ）と産出（語を出す）は別の力。** 狙う力に合わせて両方使う〔出典 L29〕
29. **学ぶ人の「分かった気」や画面上の正答率を、学習の成果とみなさない。** 〔出典 L15 L32〕
30. **慣れた人には説明を省ける。** 初学者は完成例から、慣れたら自力へ〔出典 L16 L17〕

## 見た目・伝え方
7. **図がないと解けない画面は作らない。** 記号の問題には図〔経験則・近い出典 L20〕
8. **何をすれば合格か、いつも見えるように。** ミッションは具体的に、進み具合（●●○）も〔経験則・近い出典 G12 G13〕
9. **飾りが学習の邪魔をしたら本末転倒。** 文字の画面は背景を暗く、色の太線や光は描かない〔出典 L18 G50〕
10. 操作の「ここちよさ」：指に遅れない・吸いつきは少し弾む・数字は足し算が合うように〔出典 G64（0.1秒）。他は経験則〕
11. **画面のポイントが一目で分かるように。** 文字は一文字ずつ流し、キーワードは跳ねてマーカー（`typewriter`）〔経験則・近い出典 L19〕
12. **迷いそうな言葉にはこまめにヘルプ。** 本文に出たら自動で「？」（`autoGloss`）〔経験則〕
13. **覚えること／覚え方／呼び方を見た目で分ける。** `**…**`＝覚えること、`__…__`＝覚え方（💡）、`((…))`＝便宜上の呼び方（📎）。最初のレッスンで教える〔経験則・近い出典 L19〕

## ごほうび・続ける仕組み（出典から）
31. **ごほうびは物の予告より「できた」を伝える言葉と演出。** 演出は成功に連動した適度な量（なしも極端も下がる）。予測できないごほうびは出典が割れている〔出典 G63 G42 G47、割れ：G24 G25〕
32. **反応は 0.1 秒（即時）・1 秒（流れが切れない）・10 秒（注意の限界）が目安。** 演出の待ちは1秒以内〔出典 G64〕
33. **進み具合を見せる。最初から少し進んだ状態で始める。** 実際の進みに裏づけて〔近い出典 G12 G13。弱い〕
34. **連続記録は短い1回で延び、抜けても戻りやすく。責めない。** 達成者は減りうる〔出典 G27 G32 G33。G27 は企業報告〕
35. **終わりをはっきり見せる。自動で次へ流さない。** 気持ちよく終える〔近い出典 G38 G44。弱い〕
36. **物語・キャラクターは学ぶ内容と結びつける。** 無関係な絵は理解を下げうる〔出典 G50。物語の効果自体は弱い G7〕
37. **自分で作った・選んだものは、完成させてこそ愛着になる。** 〔近い出典 G15 G16。弱い〕
38. **目新しさは薄れる。** 慣れたあとも続く中身に重心〔出典 G11。弱い〕

## 使わない通説・害が出る手
39. **使わない通説：** 学習スタイル／7±2／集中は◯分／再読・ハイライト〔出典 L34 L35 L1〕
40. **害が出る手は使わない：** 損失の恐怖で縛る・時間の圧力・愛着の圧力（「かわいそう」）・やめにくい画面・順位の煽り・有料の確率抽選〔出典 G53 G54 G19 G20 G26〕

## 範囲
6. **教材の範囲・分量は元の資料に合わせる。** 盛りすぎない。ただし元の資料を見ないと分からない書き方はしない〔経験則〕
24. **「このアプリ全体をやれば、その試験のその分野が解けるレベルまで育てる」気合で範囲を決める。** 過去問の形を洗い出して足し、試験と同じ形の問題と模試を置く。**範囲は公式の出題範囲で確かめる。記憶で「○級で習う」と書かない**〔経験則〕

**点検**：完成前に全レッスンを通して、①説明より先に問題が出ていないか ②受け身の「次へ」が続いていないか ③図がないと解けない画面がないか ④資料より盛りすぎていないか ⑤太字が「覚えること」だけか、を見る。指摘箇所だけでなく全体を直す。太字の点検は くわしく に。
