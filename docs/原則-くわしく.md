# 原則（くわしく）

短い版は [原則.md](原則.md)。この文書は、各原則のきっかけ（ユーザーの指摘）・例・**根拠の印**。
**印**：〔出典 L○/G○〕＝論文・報告あり（[根拠/出典一覧.md](根拠/出典一覧.md)。L＝学習理論、G＝ゲーム）／〔経験則〕＝依頼者（教材編集・塾講師の経験）の指摘で出典では未確認／〔経験則・近い出典〕＝近い研究があるだけ／〔推論〕＝AI の推測／〔出典と食いちがい〕。**食いちがったら出典を優先**。出典の多くは抄録レベルで、大学生・実験室が多い（[根拠/README.md](根拠/README.md)）。

**2026-11-11 出典により修正**：
- 原則1：前は「知識を入れる前に問題を出さない」→「**採点する**問題を出さない。答え→すぐ説明の予想はよい」（成人の単語で、当て推量→すぐ訂正が読むだけに勝った L26。導入の事前質問の一般論は弱い L24）。
- 単語アプリ：「間隔は伸ばしていくべき」→「あけることが大事。広げ方の優位はほぼない」（L8）。ボスの「混ぜる＝インターリービング」→ 間をあけた想起（単語ではブロックが良い L12）。
