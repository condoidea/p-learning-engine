# 原則（くわしく）

短い版は [原則.md](原則.md)。この文書は、各原則のきっかけ（ユーザーの指摘）と例つきの全文。

## 学習設計ノウハウ（ユーザーと検討・獲得したもの）

コースを作る・直すときに、まずここを読む。
基本情報（BIT RUSH）→ ハプスブルク年代記 → 三角比（サンカク・ラッシュ）の制作で、ユーザーとのやり取りから得た原則・部品・試したアイデアをまとめたもの。

**点検のしかた**：完成前に全レッスンを通して、①説明より先に問題が出ていないか ②受け身の「次へ」が続いていないか ③図がないと解けない画面がないか ④資料より盛りすぎていないか ⑤太字が「覚えること」だけになっているか（話の強調・計算問題の数値・エピソードの細部は太字にしない）、を見る。指摘された箇所だけでなく全体を直す。

**太字の点検のしかた**：レッスンの「まとめ」と用語カードに出てこない太字を機械的に洗い出し（その太字は覚えることではない可能性が高い）、1つずつ「覚える／ヒント／呼び方／ただの強調」に振り分ける。計算問題の問題文の太字は「問題のデータ」なので外す。
