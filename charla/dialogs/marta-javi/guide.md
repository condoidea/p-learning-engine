### シリーズ1との文法の組み合わせの違い

| | シリーズ1 | シリーズ2 |
|---|---|---|
| 過去形 | 点過去と線過去（一回の出来事と背景） | **習慣の線過去**（昔は〜したものだ）と現在の対比／点過去と過去完了で出来事を組み立てる |
| 間接話法 | 未来→過去未来（「〜するだろう」と言った） | **過去完了・si（〜かどうか）・que＋接続法**（「〜したと言った」「〜かと聞いた」「〜するよう頼んだ」） |
| 接続法 | 名詞節（quiero que…） | **形容詞節**（que sepa…）と**副詞節**（para que / hasta que / en cuanto / aunque）、**疑い・感情**（no creo que / dudo que / me da miedo que） |
| 命令形 | tú の命令＋代名詞 | **usted の命令**＋代名詞（Siéntese / Pruébela / se lo limpio） |
| 代名詞 | 二重目的語（se lo / me la） | **間接目的語をとる動詞**（me encanta / te duele / le sienta fatal）と**無意志の se**（se me olvidó / se te han caído） |
| 完了 | 現在完了・過去完了 | **現在完了と点過去の使い分け**（este mes ⇔ el año pasado）、hace〜que / desde hace / llevar＋現在分詞 |

### 文法ノート

**習慣の線過去（昔は〜したものだ）と現在の対比**

| 本文の例 | 働き |
|---|---|
| Veníamos aquí todos los veranos / nos hacía chocolate / nos dejaba jugar | 繰り返していたこと（todos los veranos, siempre などと一緒に使う） |
| tú siempre te comías mis churros / comías muy despacio | 昔の習慣・癖 |
| el reloj nunca funcionaba / siempre marcaba las cinco y diez | 昔の状態 |
| Cuando le preguntábamos la hora, el abuelo siempre decía… | 「〜するといつも…した」 |
| **Solía** esconder nuestros regalos | soler（線過去）＋不定詞＝よく〜したものだ |
| ⇔ **Una vez tardé** tres días en encontrar mi bicicleta | 一回だけの出来事は点過去 |
| ⇔ Trabajaba… Ya no. **Lo dejé** hace un mes | 線過去（以前の状態）と点過去（辞めた時点）の対比 |

**間接目的語をとる動詞（gustar型）**：「人」は間接目的語（me / te / le / nos / les）になる

| 本文の例 | 直訳に近い意味 |
|---|---|
| A mí **me encantaban** los churros | チュロスが私を大いに喜ばせていた |
| a ti siempre **te dolía** la barriga | お腹があなたに痛みを与えていた |
| a papá y a mamá no **les interesa** nada | 両親には何も興味を引かない |
| el café **le sienta fatal** | コーヒーは彼の体に合わない |
| Eso **me preocupa** / A ti todo **te preocupa** | それが私を心配させる |
| Al abuelo **le gustaban** los misterios | 祖父には謎が好ましかった |
| a mí **me parece** una idea genial | 私にはすごいアイデアに思える |
| a mí **me duele** todo | 私はあちこちが痛む |

「a mí / a ti / al abuelo」は強調や、誰のことかをはっきりさせるために付ける。

**無意志の se（うっかり〜してしまった）**：se ＋ 間接目的語（その被害を受ける人）＋ 動詞（物に合わせて活用）

| 本文の例 | 意味 | 分解 |
|---|---|---|
| **Se me olvidaron** las llaves | 鍵を忘れてしまった | 主語は las llaves（複数）なので olvidaron |
| **se te van a caer** | （鍵を）落としそうだよ | |
| **¡Se te han caído!** | 落としちゃった！ | |
| no **se han roto** | 壊れなかった（物が主語） | |
| A mí **se me han olvidado** las gafas | メガネを忘れてきた | |
| Hoy **se te olvida** todo | 今日は何でも忘れるね | 主語は todo（単数） |

**代名詞**：dá**melas**（las llaves）／**¿La** leemos?・Lée**la** tú（la carta）／Bája**lo**（el reloj）／sujéta**me** la silla／Dá**melo**・no **lo** rompas（el sobre）／la receta **la** sabía el abuelo（目的語を文頭に出して代名詞で繰り返す）／Nunca **se la** enseñó a nadie

### 文法ノート

**点過去と過去完了で出来事を組み立てる**

| 本文の例 | 時間の関係 |
|---|---|
| La que **había preparado** para la inauguración | 「なくなった」より前に作っておいた |
| al abrir la nevera, **me di cuenta de** que no estaba | al ＋ 不定詞＝〜したとき |
| Cuando **me fui**, la tarta **estaba** allí | 点過去（出来事）と線過去（その時の状態） |
| **Te lo había dicho.** | 「今確認できた」より前にもう言っていた |
| Pensaba que eso ya se me **había pasado** | 「思っていた」より前に治っていた（はずだった） |
| **Hacía** veinte años que no me **pasaba** | 過去のある時点で「〜年間…していなかった」 |

**間接話法（過去に言われたことを伝える）**

| もとの言葉 | 伝えると |
|---|---|
| «Me acosté a las diez» | Me dijo que **se había acostado** a las diez（点過去→過去完了） |
| «No oí nada» | …y que no **había oído** nada |
| «¿Bajó usted al café?» | ¿Le preguntaste **si había bajado** al café?（はい／いいえで答える質問は si） |
| «No. A las diez ya estaba en la cama» | Me dijo que no, que a las diez ya **estaba** en la cama（線過去はそのまま） |
| «Javi se levantaba por las noches» | Mamá me contó que **te levantabas**…（線過去はそのまま） |
| «Haga usted otra, por favor» | Le pedimos que **haga** otra（頼みごとは que ＋ 接続法） |

**代名詞**

| 本文の例 | 分解 |
|---|---|
| ¿Y no **me lo** dijiste? / **Te lo** dije el martes / **Te lo** había dicho | me/te ＋ lo（そのこと） |
| **Se lo** pregunté | se（=le, a doña Pilar）＋ lo |

### 文法ノート

**現在完了と点過去の使い分け（スペインでの使い方）**

| 現在完了（今日・今週・今月・今までの経験） | 点過去（昨日・去年など終わった時間） |
|---|---|
| No **he dormido** nada en toda la noche | **Ayer visité** el Café El Reloj |
| **Este mes habéis trabajado** juntos… | **El año pasado** solo **nos vimos** en Navidad |
| **este mes nos hemos visto** todos los días | ayer lo **vi** por primera vez |
| **nunca he probado** una tarta tan buena（経験） | me **sirvieron** el agua caliente |
| ¿**Has movido alguna vez** esa mesa?（経験） | |
| **ya habéis encontrado** el tesoro | |
| **todavía no se ha ido** | |

ポイント：今日・今週・今月のように「まだ終わっていない時間」の中のことや、これまでの経験は現在完了。昨日・去年のように「終わった時間」のことは点過去。

**期間の表現**

| 本文の例 | 意味 |
|---|---|
| **Hace** cuarenta años **que** lo conozco | 知り合って40年になる |
| **Lleva** cuarenta años **viniendo** | 40年間通い続けている |
| Doña Pilar viene **desde hace** sesenta | 60年前から来ている |
| **Hace** un mes, vosotros dos casi no os hablabais | 1か月前（hace ＋ 期間＝〜前） |

**ほかの時制のまとめ**

| 時制 | 本文の例 |
|---|---|
| 線過去（以前の状態・習慣） | casi no os **hablabais** / Marta **vivía** en Madrid / Javi nunca **salía** / nunca nos **dejaba** tocarla |
| 過去未来（過去から見た未来） | el abuelo sabía que esto **pasaría** |
| 未来 | **Volveré** / **aprenderemos** |
| 接続法 | antes de que **se vaya** |

**代名詞**：Lée**lo**／**lo** conozco／**la** vamos a mover・toca**rla**（la mesa）／Levánta**la**（la baldosa）／Ábre**la**（la caja）／Lée**mela**（la carta）／**El dinero me lo** he gastado（目的語を文頭に出して繰り返す）／hacer**la**（la tarta）／prepára**lo**（el café）

**gustar型と無意志の se の復習**：**Le ha gustado**／A mí **me tiemblan** las manos

## 付録1：シリーズの伏線と回収

| 伏線（初出） | 回収 |
|---|---|
| 第1話：時計はいつも5時10分。「ここはいつでもコーヒーの時間」 | 第5話：「時計は直さない。ここはいつでも5時10分」 |
| 第1話：マルタは子どものころハビのチュロスを食べていた | 第3話：ハビが「姉さんが食べたんじゃないの？」と疑う |
| 第1話：二人ともコーヒーマシンが使えない | 第4話：評論家が「まだマシンの使い方も分からない」と書く／第5話：最後もまだ使えない |
| 第2話：ピラールさんが宝のありかを知っている | 第5話：宝はピラールさんの指定席の下にあった |
| 第2話：「おじいちゃんが電話してくるまで教えない」 | 第5話：P.D.「ついにピラールに電話した」 |
| 第3話：ハビが設置した防犯カメラ | 第5話：「夜中の3時にまで、カメラの中で」 |
| 第4話：「Pareces un policía」 | 第4話の後半で、ハビがそのまま言い返す |
| 第4話：「明日の新聞を読みなさい」 | 第5話：記事に最後の手がかり |
