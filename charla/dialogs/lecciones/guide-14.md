## 会話1　Las vacaciones en Barcelona（バルセロナの休暇）

**あらすじ**：休暇明けのマドリード。カルメンは久しぶりにマコトに会う。マコトはバルセロナ旅行から帰ったばかり。一方カルメンは、休暇中ずっと叔父の本屋で働いていた。

**聞き取りポイント**
- マコトはいつ、何でバルセロナから帰ってきたか
- バルセロナに何日いたか。何を見たか
- お土産に何を買ったか
- カルメンは休暇に何をしたか。なぜか

### 本文

| # | 話者 | Español | 日本語 |
|---|---|---|---|
| 1 | C | ¡Makoto! ¡Cuánto tiempo sin verte! | マコト！久しぶりね！ |
| 2 | M | ¡Hola, Carmen! Me alegro de verte. | やあ、カルメン！会えてうれしいよ。 |
| 3 ★ | C | ¿Cómo te fueron las vacaciones? | 休暇はどうだった？ |
| 4 ★ | M | Muy bien. Anoche vine de Barcelona en el AVE. | すごくよかったよ。昨日の夜、AVE（スペインの高速鉄道）でバルセロナから帰ってきたんだ。 |
| 5 ★ | C | ¿Cuántos días estuviste en Barcelona? | バルセロナには何日いたの？ |
| 6 | M | Estuve seis días. Visité la Sagrada Familia, el Parque Güell y otras construcciones de Gaudí. ¡Me impresionaron mucho! | 6日間いたよ。サグラダ・ファミリアとグエル公園と、ほかのガウディの建物を見たんだ。すごく感動したよ！ |
| 7 ★ | C | Muy bien. ¿Compraste algún recuerdo de Barcelona? | いいわね。バルセロナで何かお土産は買った？ |
| 8 ★ | M | Sí, compré un libro de la colección de las obras de Picasso. Y tú, ¿qué hiciste? | うん、ピカソの作品集を1冊買ったよ。君は何をしてたの？ |
| 9 | C | Yo trabajé mucho en la librería de mi tío. | 叔父の本屋でたくさん働いてたの。 |
| 10 | M | ¿Trabajaste? | 働いてたの？ |
| 11 | C | Sí, para ganar dinero. Porque algún día quiero viajar por Perú. | うん、お金を稼ぐためにね。いつかペルーを旅行したいから。 |

### 元のテキストから直したところ
- アクセントと記号（¿ ? ¡ !）を補った（Cuánto, Cómo, Cuántos, Visité, Güell, Gaudí, algún, compré, colección, tú, qué, trabajé, librería, tío, Perú など）
- Cunato → **Cuánto**、Hora → **Hola**（打ち間違い）
- 4番の **M** の後ろに「:」がなかったので補った
- el Parque Güell**,** y otras → el Parque Güell y otras（y の前にはコンマを付けない）
- **Güell** の ü：u の上の2つの点で「グエ」と読む（付けないと「ゲル」になる）

### 文法ノート

**不規則な点過去**

| 本文の例 | 不定詞 | 活用（yo / tú / él） |
|---|---|---|
| Anoche **vine** de Barcelona | venir | vine / viniste / vino |
| ¿Cuántos días **estuviste**? / **Estuve** seis días | estar | estuve / estuviste / estuvo |
| ¿qué **hiciste**? | hacer | hice / hiciste / **hizo**（c → z） |
| ¿Cómo te **fueron** las vacaciones? | ir | fui / fuiste / fue（複数は fueron） |

不規則な点過去は、yo と él の語尾にアクセント記号が付かない（vine, estuve, hice）。規則動詞は付く（visité, compré, trabajé）。

**規則的な点過去（比べる）**：**Visité** la Sagrada Familia／**compré** un libro／**trabajé** mucho／¿**Trabajaste**?／¿**Compraste**…?／**Me impresionaron** mucho

**alguno（いくつかの、何かの）**

| 本文の例 | 意味 | |
|---|---|---|
| ¿Compraste **algún** recuerdo? | 何かお土産を買った？ | 男性単数名詞の前で alguno → **algún** |
| **algún** día quiero viajar | いつか旅行したい | algún día ＝ いつか |

**gustar型の動詞**：¿Cómo **te fueron** las vacaciones?（休暇は君にとってどうだった？）／**Me impresionaron** mucho（それらは私を感動させた）。主語は las vacaciones / las construcciones なので3人称複数。

### 慣用表現

| 表現 | 意味 |
|---|---|
| ¡Cuánto tiempo sin verte! | 久しぶり！ |
| Me alegro de verte. | 会えてうれしい |
| ¿Cómo te fue / fueron…? | …はどうだった？ |
| algún día | いつか |
| para ganar dinero | お金を稼ぐために |

## 会話2　La nevera vacía（空っぽの冷蔵庫）

**聞き取りポイント**
- 昨日、ソフィアが電話したとき、なぜダニエルは出なかったのか
- ダニエルは旅行で何をしたか
- お土産はあったか。なかったのはなぜか

### 文法ノート

**不規則な点過去（会話1の続き）**

| 本文の例 | 不定詞 | 活用（yo / tú / él） |
|---|---|---|
| No **supe** nada de ti | saber | supe / supiste / supo |
| **Quise** llamarte / **Quise** comprarte algo | querer | quise / quisiste / quiso |
| no **pude** / No **pude** ir | poder | pude / pudiste / pudo |
| **Estuve** en un pueblo | estar | estuve / estuviste / estuvo |
| ¿**Hiciste** algo interesante? | hacer | hice / hiciste / hizo |
| **anduve** mucho por la montaña | andar | anduve / anduviste / anduvo |
| **Fue** estupendo | ser | fui / fuiste / fue（ir と同じ形） |
| ¿me **trajiste**…? / no te **traje** nada | traer | traje / trajiste / trajo（3人称複数は trajeron） |

語幹の母音でグループにして覚えるとよい。
- **-u-**：saber → **sup**-／poder → **pud**-／estar → **estuv**-／andar → **anduv**-／tener → **tuv**-
- **-i-**：querer → **quis**-／hacer → **hic**-／venir → **vin**-
- **-j-**：traer → **traj**-／decir → **dij**-

語尾はどれも共通：-e / -iste / -o / -imos / -isteis / -ieron（-j- の動詞だけ3人称複数が **-eron**：trajeron, dijeron）

**点過去にすると意味が変わる動詞**（4級でよく問われる）

| 本文の例 | 点過去での意味 | 現在形の意味 |
|---|---|---|
| **Quise** llamarte, pero… | 〜しようとした（実際にやってみた） | quiero＝〜したい |
| **no pude** | （やってみたが）できなかった | no puedo＝できない |
| **No supe** nada de ti | 何の知らせもなかった、知らなかった（＝情報が入ってこなかった） | sé＝知っている |

- **Quise…, pero no pude**（〜しようとしたが、できなかった）はセットでよく使う
- no quise ＋ 不定詞 は「〜するのを拒んだ」（例：No quiso venir＝来ようとしなかった）
- supe ＋ que… は「〜を知った、わかった」（例：Ayer supe que estabas aquí＝昨日きみがここにいると知った）
- **saber de＋人**：〜の消息を知る。No supe nada **de ti**＝君の消息は何もなかった

**規則的な点過去（比べる）**：te **llamé**／nadie **contestó**／no **encontré** nada／**me los comí** todos

**不定語と否定語**（このレッスンの中心）

| 肯定（何か・誰か） | 否定（何も・誰も） | 本文の例 |
|---|---|---|
| **algo**（何か） | **nada**（何も…ない） | ¿Hiciste **algo** interesante? ⇔ no te traje **nada** |
| **alguien**（誰か） | **nadie**（誰も…ない） | **nadie** contestó |
| **alguno**（何か一つ、どれか） | **ninguno**（一つも…ない） | ¿me trajiste **algún** recuerdo? ⇔ **Ninguno.** |
| | | Quise comprarte **algo** ⇔ no encontré **nada** bonito |
| también（…も） | **tampoco**（…も…ない） | en la nevera **tampoco** hay nada |

- alguno / ninguno は名詞の性・数に合わせる。男性単数名詞の前では -o が落ちる：**algún** recuerdo／**ningún** recuerdo
- ninguno は単独でも使える：¿Ni un yogur? — **Ninguno.**（ヨーグルトは1個もない）
- **tampoco**：お土産も「何もない」、冷蔵庫に「も」何もない、という流れ

**二重否定**：否定語が動詞の後ろに来るときは、動詞の前に **no** を付ける

| 本文の例 | 語順 |
|---|---|
| **no** te traje **nada** | no ＋ 動詞 ＋ nada |
| **Nadie** contestó | 否定語が動詞の前に来るときは no を付けない |
| en la nevera **tampoco** hay **nada** | tampoco が動詞の前にあるので no は付けない |

✕ Nadie no contestó　○ Nadie contestó ＝ No contestó nadie

**再帰動詞＋代名詞**：**Me los** comí todos（los ＝ los yogures）。comerse は「全部食べてしまう」というニュアンス

## 付録：単語リストの使用状況（会話2）

話題がころころ変わらないように、「旅行から帰った→お土産も冷蔵庫も何もない」の流れに合う語だけを入れました。

| 単語 | 意味 | 本文中の表現 |
|---|---|---|
| nevera | 冷蔵庫 | en la **nevera** tampoco hay nada |
| contestar | 答える（電話に出る） | nadie **contestó** |
| nadie | 誰も…ない | **nadie** contestó |
| ninguno, -na | 1人／1つの…も…ない | **Ninguno.** |
| vuelta | 回転、一周 | ¿damos una **vuelta**…? |
| pelear | 戦う | （見送り） |
| pirata | 海賊 | （見送り） |
| éxito | 成功 | （見送り。tener éxito＝成功する、の形でよく出る） |
| cirujano, -na | 外科医 | （見送り） |

※ nadie は「何も…ない」ではなく「**誰も**…ない」です。「何も…ない」は nada。
※ vuelta の「基幹」は「**帰還**」の打ち間違いかもしれません。vuelta には「帰り」の意味もあります（a la vuelta＝帰りに）。
