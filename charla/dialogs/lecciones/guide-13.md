## 会話1　El viaje a Monterrey（モンテレイ出張）

**あらすじ**：メキシコ市の会社。モンテレイ出張から戻った田中さんに、上司のガルシアさんが出張の様子を聞く。田中さんは取引先の銀行のロドリゲスさんと会ってきた。

**聞き取りポイント**
- 田中さんはいつ戻ったか。なぜ遅くなったか
- ロドリゲスさんは空港で何をしてくれたか
- ABC銀行はいつ創立されたか
- ロドリゲスさんの経歴（銀行で何年働いているか、メキシコ市に何年いたか、いつ支店長になったか）

### 本文

| # | 話者 | Español | 日本語 |
|---|---|---|---|
| 1 ★ | G | ¿Cuándo volvió de Monterrey? | モンテレイからはいつ戻ったんですか？ |
| 2 ★ | T | Anoche, a eso de las diez. El avión salió una hora atrasado del aeropuerto de Monterrey y llegué muy tarde. | 昨夜の10時ごろです。モンテレイの空港で飛行機が1時間遅れて出発したので、着いたのがとても遅くなりました。 |
| 3 | G | Lo siento. ¿Cómo le fue la reunión con el señor Rodríguez? | それは大変でしたね。ロドリゲスさんとの打ち合わせはどうでしたか？ |
| 4 | T | ¡Muy bien! El señor Rodríguez me recibió en el aeropuerto y me llevó a la oficina del Banco ABC. | とてもうまくいきました！ロドリゲスさんが空港に迎えに来てくれて、ABC銀行のオフィスに連れて行ってくれました。 |
| 5 | G | Lo felicito. ¿Cuándo se fundó el Banco ABC? | よかったですね。ABC銀行はいつ創立されたんですか？ |
| 6 ★ | T | Se fundó en mil novecientos veinte. | 1920年に創立されました。 |
| 7 ★ | G | ¿Trabaja el señor Rodríguez en el banco desde hace muchos años? | ロドリゲスさんは何年も前からその銀行で働いているんですか？ |
| 8 ★ | T | Sí. Hace catorce años que trabaja en el banco. Vivió tres años en la Ciudad de México para trabajar en la oficina principal del banco, y hace dos años lo nombraron gerente de la sucursal de Monterrey. | はい。銀行で働いて14年になります。本店で働くために3年間メキシコ市に住んで、2年前にモンテレイ支店の支店長に任命されました。 |

### 元のテキストから直したところ
- アクセントと記号（¿ ? ¡ !）を補った（volvió, salió, llegué, reunión, Rodríguez, señor, años など）
- My → **Muy**（2か所）、Rodoriguez → **Rodríguez**（打ち間違い）
- 4番の田中さんのセリフの話者が **M** になっていたので **T** に直した
- 4番の文末の「?」は質問ではないので「.」にした
- Si. hace → Sí. **H**ace（文の頭なので大文字）
- ciudad de Mexico → **Ciudad de México**（地名なので大文字）
- salió una hora **atrasado** はメキシコでよく使う言い方なのでそのままにした。スペインでは salió con una hora de **retraso** が普通（会話2で使用）

### 文法ノート

**点過去**：過去の一回の出来事

| 本文の例 | 不定詞 | 人称 | |
|---|---|---|---|
| ¿Cuándo **volvió**? | volver | usted | |
| El avión **salió** | salir | 3人称単数 | |
| **llegué** muy tarde | llegar | yo | g → gu（つづりの変化） |
| me **recibió** / me **llevó** | recibir / llevar | 3人称単数 | |
| ¿Cómo le **fue**…? | ir | 3人称単数 | 不規則（ser と同じ形） |
| **Vivió** tres años | vivir | 3人称単数 | 期間が区切られていれば点過去 |
| lo **nombraron** | nombrar | 3人称複数 | |

usted の活用は3人称単数と同じ形：¿Cuándo volvió **usted**?＝¿Cuándo volvió **él**?

**期間の言い方**（4級の頻出）

| 形 | 意味 | 本文の例 |
|---|---|---|
| **hace** ＋ 期間 ＋ **que** ＋ 現在形 | 〜して（期間）になる | **Hace catorce años que** trabaja en el banco |
| 現在形 ＋ **desde hace** ＋ 期間 | （期間）前から〜している | ¿Trabaja… **desde hace** muchos años? |
| 点過去 ＋ **hace** ＋ 期間 | （期間）前に〜した | **hace dos años** lo nombraron gerente |

上の2つは同じ意味：Hace catorce años que trabaja ＝ Trabaja desde hace catorce años。「今も続いている」ので動詞は**現在形**。

**受け身の se**：se ＋ 3人称の動詞で「〜される」

| 本文の例 | 意味 |
|---|---|
| ¿Cuándo **se fundó** el Banco ABC? | ABC銀行はいつ創立されたか |
| **Se fundó** en mil novecientos veinte | 1920年に創立された |

**主語を言わない3人称複数**：「（誰かが）〜した」。する人をはっきり言わないときに使う。**lo nombraron** gerente ＝（会社が）彼を支店長に任命した

**年号の読み方**：1920 ＝ **mil novecientos veinte**（「千・九百・二十」と読む。英語のように2けたずつ区切らない）

### 慣用表現

| 表現 | 意味 |
|---|---|
| a eso de las diez | 10時ごろ |
| Lo siento. | それは残念、お気の毒に |
| ¿Cómo le fue…? | …はどうでしたか（usted に） |
| Lo felicito. | おめでとうございます、よかったですね（usted に。tú なら Te felicito） |

### 4級の境目にある語彙

| 単語 | 意味 |
|---|---|
| atrasado/a | 遅れた |
| reunión | 会議、打ち合わせ |
| fundar | 創立する |
| nombrar | 任命する |
| gerente | 支店長、支配人 |
| sucursal | 支店 |
| oficina principal | 本店、本社 |

## 会話2　La boda en Sevilla（セビーリャの結婚式）

**あらすじ**：月曜の朝、マドリードの会社。姉の結婚式でセビーリャに行っていたアナが、同僚のケンジに週末の話をする。最後に、アナはケンジにお土産を渡す。

**聞き取りポイント**
- アナはいつ戻ったか。なぜ遅くなったか
- 結婚式はいつ、どこであったか。その教会はいつ建てられたか
- パーティーは何時まで続いたか
- お土産は何で、中に何が入っていたか。それはなぜか

### 本文

| # | 話者 | Español | 日本語 |
|---|---|---|---|
| 1 ★ | K | Hola, Ana. ¿Cuándo volviste de Sevilla? | やあアナ。セビーリャからいつ戻ったの？ |
| 2 ★ | A | Anoche, a eso de las once. El tren salió con una hora de retraso y llegué muy tarde a casa. | 昨日の夜の11時ごろ。電車が1時間遅れで出発して、家に着いたのがすごく遅くなっちゃった。 |
| 3 | K | ¡Qué pena! ¿Y qué tal la boda de tu hermana? | それは残念。で、お姉さんの結婚式はどうだった？ |
| 4 ★ | A | ¡Muy bonita! Se casaron anteayer en una iglesia muy antigua del centro. | すごくすてきだった！おとといの土曜日、街の中心にあるとても古い教会で式を挙げたの。 |
| 5 | K | ¿Ah, sí? ¿Cuándo se construyó? | へえ、そうなんだ。いつ建てられたの？ |
| 6 ★ | A | Se construyó en el siglo quince. Mis abuelos también se casaron allí, en mil novecientos cuarenta, justo después de la guerra. | 15世紀に建てられたの。祖父母もそこで結婚したのよ。1940年、戦争が終わってすぐに。 |
| 7 ★ | K | ¡Qué bonito! ¿Y la fiesta? ¿Cuánto duró? | すてきだね！で、パーティーは？どのくらい続いたの？ |
| 8 | A | Duró hasta las cuatro de la mañana. Anteanoche casi no dormí. | 朝の4時まで。おとといの夜はほとんど寝てないの。 |
| 9 | K | Por eso pediste permiso para no venir el viernes, ¿no? | だから金曜日に休みをもらったんだよね？ |
| 10 | A | Sí. El jefe me dio permiso enseguida. Ah, mira, te compré un regalo en Sevilla. | そう。部長がすぐに許可してくれたの。あ、そうだ、セビーリャでお土産を買ってきたのよ。 |
| 11 | K | ¡Un monedero! Muchas gracias. Justo el mes pasado perdí el mío. Oye, ¿y esta moneda? | 小銭入れだ！ありがとう。ちょうど先月なくしたところなんだ。あれ、このコインは？ |
| 12 ★ | A | Es para la suerte. En España, un monedero nunca se regala vacío. | 縁起物よ。スペインでは、財布は空っぽのままでは絶対に贈らないの。 |

※ 月曜日の会話なので、anteayer（おととい）＝土曜日、anteanoche（おとといの夜）＝土曜日の夜、anoche（昨夜）＝日曜日の夜。

### 文法ノート

**点過去（会話1と同じ形）**

| 本文の例 | 不定詞 | 人称 | |
|---|---|---|---|
| ¿Cuándo **volviste**? | volver | tú | 会話1の volvió（usted）と比べる |
| El tren **salió** | salir | 3人称単数 | |
| **llegué** muy tarde | llegar | yo | g → gu |
| Se **casaron** | casarse | 3人称複数 | 再帰動詞の点過去 |
| ¿Cuánto **duró**? / **Duró** hasta… | durar | 3人称単数 | |
| **pediste** permiso | pedir | tú | |
| te **compré** un regalo | comprar | yo | |
| **perdí** el mío | perder | yo | |

**不規則な点過去**

| 本文の例 | 不定詞 | 意味 |
|---|---|---|
| casi no **dormí** | dormir | 眠る（3人称は durmió と o → u になる） |
| me **dio** permiso | dar | 与える（アクセント記号なし：di, diste, dio） |

**受け身の se（会話1と同じ形）**

| 本文の例 | 意味 |
|---|---|
| ¿Cuándo **se construyó**? / **Se construyó** en el siglo quince | いつ建てられたか／15世紀に建てられた |
| un monedero nunca **se regala** vacío | 財布は空のままでは贈られない（現在形の受け身の se） |

会話1の **se fundó** と同じ形。se casaron（結婚した）は再帰動詞なので、受け身ではない。

**時を表す語**

| 語 | 意味 |
|---|---|
| anoche | 昨夜 |
| anteanoche | おとといの夜 |
| anteayer | おととい |
| el mes pasado | 先月 |

**年号と世紀**：mil novecientos cuarenta（1940年）／el siglo quince（15世紀。書くときは siglo XV とローマ数字）

**所有代名詞**：perdí **el mío**（＝ mi monedero）。名詞を繰り返さずに「私のもの」と言う。

### 慣用表現

| 表現 | 意味 |
|---|---|
| a eso de las once | 11時ごろ |
| con una hora de retraso | 1時間遅れで |
| ¡Qué pena! | それは残念 |
| ¿Qué tal…? | …はどうだった？ |
| justo después de… | …のすぐ後に |
| pedir permiso | 許可を求める、休みをもらう |
| enseguida | すぐに |
| Es para la suerte. | 縁起物だよ |

### 4級の境目にある語彙

| 単語 | 意味 |
|---|---|
| boda | 結婚式 |
| iglesia | 教会 |
| construir | 建てる |
| siglo | 世紀 |
| retraso | 遅れ |

## 付録：単語リストの使用状況（会話2）

使用頻度と試験での重要度が高い語を優先して入れ、残りは見送りました。

| 単語 | 意味 | 本文中の表現 |
|---|---|---|
| anteayer | おととい | Se casaron **anteayer** |
| anteanoche | おとといの夜 | **Anteanoche** casi no dormí |
| casarse | 結婚する | **Se casaron** anteayer / Mis abuelos también **se casaron** allí |
| permiso | 許可 | pediste **permiso** / me dio **permiso** |
| durar | 続く | ¿Cuánto **duró**? / **Duró** hasta las cuatro |
| guerra | 戦争 | justo después de la **guerra** |
| monedero | 小銭入れ | ¡Un **monedero**! |
| moneda | 通貨（硬貨） | ¿y esta **moneda**? |
| estallar | 勃発する | （見送り。la guerra estalló en… の形で歴史の文によく出るので、覚えておくとよい） |
| descubrimiento | 発見 | （見送り） |
| publicación | 出版 | （見送り） |
| trono | 王位 | （見送り） |
| circulación | 流通 | （見送り） |

※ moneda は単語リストでは「通貨」ですが、ここでは「硬貨、コイン」の意味で使っています。どちらの意味もあります。
