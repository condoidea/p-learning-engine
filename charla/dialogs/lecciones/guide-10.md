## 会話1　El regalo de cumpleaños（誕生日のプレゼント）

**あらすじ**：5月24日は日本にいる妹の誕生日。マコトは郵便でプレゼントを送るつもりで、友だちのカルメンに相談する。二人はデパートに財布を買いに行く。

**聞き取りポイント**
- 妹の誕生日はいつか。マコトはどうやってプレゼントを送るか
- カルメンは何を勧めたか。荷物はいつまでに送ればいいか
- マコトは誰のために、何色の財布を選んだか
- マコトの誕生日はいつか。なぜ「1年近く待たなければならない」のか

### 本文

| # | 話者 | Español | 日本語 |
|---|---|---|---|
| 1 ★ | M | ¡El veinticuatro de mayo es el cumpleaños de mi hermana! Voy a enviarle por correo un regalo. ¿Qué le compro? | 5月24日は妹の誕生日なんだ！郵便でプレゼントを送るつもりなんだけど、何を買ってあげようかな？ |
| 2 ★ | C | ¿Por qué no le compras una cartera? | 財布を買ってあげたら？ |
| 3 ＋ | M | ¡Buena idea! Oye, ¿me enseñas a enviar un paquete a Japón? No sé cómo se hace. | いいね！ねえ、日本への小包の送り方を教えてくれる？やり方がわからないんだ。 |
| 4 ＋★ | C | Claro. Mañana te acompaño a Correos. Si lo envías esta semana, se lo entregan a tu hermana antes del veinticuatro. | もちろん。明日、郵便局に一緒に行ってあげる。今週中に送れば、24日より前に妹さんに届くわよ。 |
| | | （デパートで） | |
| 5 | M | ¿Qué tal esta cartera azul? | この青い財布はどう？ |
| 6 | C | Sí, es graciosa. | うん、かわいいわね。 |
| 7 ★ | M | Voy a comprársela. Y también quiero esa cartera negra para mí. | これを妹に買うよ。それと、そっちの黒い財布も自分用に欲しいな。 |
| 8 ★ | C | ¿Cuándo es tu cumpleaños? Voy a regalártela el día de tu cumpleaños. | あなたの誕生日はいつ？誕生日の日に、それをプレゼントしてあげる。 |
| 9 | M | Gracias, no lo voy a olvidar. Pero tengo que esperar casi un año. ¡Mi cumpleaños es el veinte de abril! | ありがとう、忘れないよ。でも1年近く待たなきゃいけないな。僕の誕生日は4月20日なんだ！ |

### 元のテキストから直したところ
- アクセントと記号（¿ ? ¡ !）を補った（cumpleaños, qué, Sí, comprársela, regalártela, también, mí, año など）
- 1番の後の **Carmen** の後ろに「:」がなかったので補った
- 日付の数字は文字にした（24 → veinticuatro、20 → veinte）。TTSが読み間違えにくい
- **(En el Corte Inglés)** は台本では場面の区切り（間）にした。El Corte Inglés はスペインの有名なデパート

### 追加したセリフ（3・4番）について
- 1番の「郵便で送る」を受けて、送り方を教えてもらう流れにした
- 単語リストの **enseñar**（教える）と **entregar**（渡す、届ける）を使った
- **se lo entregan**（le → se の形）を入れて、このレッスンの文法をもう一度練習できるようにした
- 覚えておきたい語：**Correos**（スペインの郵便局。大文字で書く）、**paquete**（小包）、**acompañar**（一緒に行く）

### 文法ノート

**目的語の代名詞**

| | 間接目的語（〜に） | 直接目的語（〜を） |
|---|---|---|
| 私 | me | me |
| 君 | te | te |
| 彼・彼女・あなた | **le** | **lo / la** |
| 私たち | nos | nos |
| 彼ら・あなたたち | **les** | **los / las** |

**間接目的語 le（彼女に）**：「誰に」を代名詞にした形

| 本文の例 | 意味 |
|---|---|
| Voy a enviar**le** un regalo | 彼女（妹）にプレゼントを送るつもりだ |
| ¿Qué **le** compro? | 彼女に何を買おう？ |
| ¿Por qué no **le** compras una cartera? | 彼女に財布を買ったら？ |

**代名詞が2つ並ぶとき**：「〜に（間接）」が先、「〜を（直接）」が後

| 本文の例 | 分解 | 意味 |
|---|---|---|
| Voy a regalár**tela** | te（君に）＋ la（＝ la cartera） | 君にそれをプレゼントする |
| Voy a comprár**sela** | se（＝ le、妹に）＋ la（＝ la cartera） | 妹にそれを買う |
| **se lo** entregan | se（＝ le、妹に）＋ lo（＝ el paquete） | 妹にそれを届ける |

**le / les → se**：le・les の後ろに lo / la / los / las が続くときは、**se** に変わる。
✕ le la compro → ○ **se la** compro

**不定詞と代名詞**：不定詞の後ろにつなげる（または活用した動詞の前に置く）。2つつなげたときはアクセント記号が付く

| 本文の形 | 別の言い方 |
|---|---|
| Voy a compr**á**rsela | **Se la** voy a comprar |
| Voy a regal**á**rtela | **Te la** voy a regalar |
| Voy a enviarle | **Le** voy a enviar |

**中性の lo**：no **lo** voy a olvidar（lo ＝ カルメンがプレゼントすると言ったこと）

**日付**：el **veinticuatro de mayo**（5月24日）／el **veinte de abril**（4月20日）。日にちは数字（1日だけ primero も使う）、定冠詞 el を付ける

### 慣用表現

| 表現 | 意味 |
|---|---|
| ¿Por qué no ＋ tú の活用？ | 〜したら？（提案） |
| ¡Buena idea! | いいね、いい考えだ |
| ¿Me enseñas a ＋ 不定詞？ | 〜の仕方を教えてくれる？ |
| No sé cómo se hace. | やり方がわからない |
| ¿Qué tal…? | …はどう？ |
| para mí | 自分用に |

| 単語 | 意味 |
|---|---|
| cartera | 財布 |
| gracioso/a | かわいい、おもしろい |
| enviar | 送る |
| paquete | 小包 |
| Correos | 郵便局（スペイン） |
| acompañar | 一緒に行く |

## 会話2　La temporada de lluvias（梅雨）

**あらすじ**：6月、東京。スペイン人の留学生ラウラが、友だちのリクの家に遊びに来ている。外は毎日雨。リクが映画を見ようと誘うが、ラウラは怖い映画が苦手で……。

**聞き取りポイント**
- 梅雨はどのくらい続くか
- リクは何を提案したか。ラウラはなぜ断ったか
- ラウラは何を借りたか（2つ）。なぜ今夜は本が必要なのか
- 傘はいつ返すか。本はどうなりそうか

### 本文

| # | 話者 | Español | 日本語 |
|---|---|---|---|
| 1 | L | ¡Qué lluvia! Llueve todos los días. | すごい雨！毎日降ってるわね。 |
| 2 ★ | R | Es normal. Estamos en la temporada de lluvias. Dura más o menos un mes. | 普通だよ。今は梅雨だから。だいたい1か月続くんだ。 |
| 3 | L | ¡Un mes! Bueno, ¿y qué hacemos hoy? | 1か月も！それで、今日は何する？ |
| 4 ★ | R | Te propongo una cosa: vemos una película aquí. Tengo una de suspense muy buena. | 提案があるんだ。ここで映画を見ようよ。すごくいいサスペンス映画があるんだ。 |
| 5 | L | Uf, las películas de suspense me dan miedo. Prefiero leer. Oye, ¿qué es ese libro? | うーん、サスペンス映画は怖いのよね。本を読むほうがいいな。ねえ、その本は何？ |
| 6 ★ | R | Es una novela de suspense también, pero no da tanto miedo. ¿Te la presto? | それもサスペンス小説だけど、そんなに怖くないよ。貸そうか？ |
| 7 | L | Sí, por favor. Así esta noche tengo algo que hacer. Delante de mi casa hay obras y no puedo dormir con el ruido. | うん、お願い。これで今夜はすることができたわ。家の前で工事をしてて、うるさくて眠れないの。 |
| 8 | R | ¿Ya te vas? Pero está lloviendo mucho. ¿No tienes paraguas? | もう帰るの？でも雨がすごいよ。傘は持ってないの？ |
| 9 ★ | L | No, se me olvidó en casa. ¿Me dejas uno? | ううん、家に忘れてきちゃった。1本貸してくれる？ |
| 10 ★ | R | Claro, te lo dejo. Pero es mi favorito. Mañana me lo devuelves, ¿vale? | もちろん、貸してあげる。でもお気に入りなんだ。明日返してね。 |
| 11 | L | Sí, mañana te lo devuelvo. Y si el libro me da mucho miedo, ¡también te lo devuelvo mañana! | うん、明日返すわ。（笑いながら）それで、もし本がすごく怖かったら、本も明日返すからね！ |

### 文法ノート

**活用した動詞の前に代名詞2つ**：会話1は不定詞の後ろにつなげる形、会話2は動詞の前に置く形

| 本文の例 | 分解 | 意味 |
|---|---|---|
| ¿**Te la** presto? | te（君に）＋ la（＝ la novela） | 君にそれを貸そうか？ |
| **te lo** dejo | te（君に）＋ lo（＝ el paraguas） | 君にそれを貸す |
| **me lo** devuelves | me（僕に）＋ lo（＝ el paraguas） | 僕にそれを返す |
| **te lo** devuelvo | te（君に）＋ lo（＝ el paraguas / el libro） | 君にそれを返す |

順番は会話1と同じで、「〜に」が先、「〜を」が後。

**間接目的語をとる動詞（〜を怖がらせる）**

| 本文の例 | 意味 |
|---|---|
| las películas de suspense **me dan** miedo | サスペンス映画は私を怖がらせる（主語は películas なので dan） |
| no **da** tanto miedo | そんなに怖くない |
| si el libro **me da** mucho miedo | もし本がすごく怖かったら |

**prestar と dejar**：どちらも「貸す」。スペインでは日常会話で **dejar** をよく使う。¿Me dejas uno?＝¿Me prestas uno?

**proponer**：Te **propongo** una cosa（提案がある）。yo の形が -go になる（poner と同じ）

**現在形で提案・依頼**：**vemos** una película aquí（ここで映画を見よう）／Mañana **me lo devuelves**, ¿vale?（明日返してね）。現在形で軽く誘ったり頼んだりできる

**天気**：**Llueve** todos los días（毎日雨が降る）／**está lloviendo** mucho（今、ひどく降っている）

**レッスン12・13の復習**：¿Ya **te vas**?（再帰動詞）／**Dura** más o menos un mes（durar）／**se me olvidó**（うっかり忘れた）

### 慣用表現

| 表現 | 意味 |
|---|---|
| ¡Qué lluvia! | すごい雨！ |
| más o menos | だいたい |
| Te propongo una cosa. | 提案があるんだけど |
| dar miedo | 怖がらせる |
| tener algo que hacer | することがある |
| ¿Ya te vas? | もう帰るの？ |
| ¿…, ¿vale? | …ね、いい？（スペインの口語） |

### 4級の境目にある語彙

| 単語 | 意味 |
|---|---|
| novela | 小説 |
| ruido | 騒音 |
| paraguas | 傘（単数も複数も同じ形） |
| devolver | 返す（o → ue） |
| miedo | 恐怖 |
