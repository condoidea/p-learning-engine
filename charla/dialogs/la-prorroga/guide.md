### 3話の仕掛け
シーズン最終戦のロスタイム（93分）に決まった**「背中でのゴール」**。この1点について、**選手・監督・審判**の3人が、それぞれの立場から語ります。

1話ごとに少しずつ真相が明らかになり、第3話で最後の秘密が明かされます。

### 文法・表現の見どころ

| 項目 | 本文の例 | ポイント |
|---|---|---|
| 過去完了 | Ese gol lo **había practicado** toda la semana | 「ゴールした」より前に練習していた（と言い張っている） |
| 習慣の線過去 | **jugábamos** en la plaza / **Echaba** de menos… **Llamaba**… **lloraba** / mi abuela siempre me **decía** / **Venía** a verme cada semana | 子どものころ・怪我をしていたころの繰り返し |
| 点過去 | **rompimos** tres ventanas / el cura **se hizo** portero / **Me operaron** / **Hubo** días en que… | 一回の出来事。Me operaron（主語を言わない3人称複数）＝手術を受けた |
| 過去の推量 | **Debió de** ser duro | deber de ＋ 不定詞（点過去）＝〜だったに違いない |
| 現在完了と経験 | **Lo he visto** unas quinientas veces / **he oído** cosas | 今までの回数・経験 |
| 丁寧な願望 | ¿Qué te **gustaría** conseguir? / **Me gustaría** jugar con la selección | gustar の過去未来＝〜したい（控えめ） |
| 接続法 | **cuando me retire** / **para que** los niños no **tengan** que… | 未来の cuando、目的の para que |
| 無意志の se | **se nos acaba** el tiempo | 時間が（私たちから）なくなっていく。番組の決まり文句 |
| 目的語を前に出す | **Ese gol lo** había practicado | 話題を先に言って、代名詞で受け直す |
| usted の命令（複数） | ¡No **se lo pierdan**! | リスナー全員への呼びかけ（ustedes）。番組の締めの決まり文句 |
| 代名詞 | no me **lo** creo / **te lo** agradecerá / fichar**te** / **lo** escucharé | |

## 第2話　El entrenador（監督）

**あらすじ**：監督歴40年のベテラン、ラミロが登場。司会者に「usted で話そう」と言う昔気質の人。あのゴールの瞬間、監督はいったい何をしていたのか。そして番組の中で、重大発表が…？

**聞き取りポイント**
- ゴールの瞬間、ラミロは何をしていたか
- ラミロの選手時代の「記録」と、練習方法の特徴
- 番組での「重大発表」と、その本当のところ

### 文法・表現の見どころ

| 項目 | 本文の例 | ポイント |
|---|---|---|
| usted の会話 | ¿Cómo **vivió** aquel último partido? / ¿Qué **opina usted**? / **Mire** / **llámeme** / **Pregúnteselo** a él | 動詞は3人称の形。命令形の後ろに代名詞がつく（llámeme、pregúnteselo） |
| tutear | ¿Y **nos tuteamos**? | 「tú で話しましょうか」。スペインでよく聞くやりとり |
| aunque ＋ 直説法 | aunque todavía no lo **sabe** nadie | 事実を言うときは直説法（「〜ではあるけれど」）。aunque ＋ 接続法（たとえ〜でも）と比べてみよう |
| 点過去と線過去 | **estaba** de espaldas, **discutiendo**… **oí** un ruido, **me di** la vuelta y **vi**… | 背景（線過去＋現在分詞）に出来事（点過去）が割り込む |
| 過去進行形 | Le **estaba diciendo** que… | 〜しているところだった |
| 間接話法 | Dani nos dijo que ese gol lo **había practicado**… / nos contó que usted **iba** a verlo | 過去完了・線過去で伝える |
| que ＋ 接続法（頼みごと） | le pido dos cosas: que no **se olvide**… y que **se ate**… | pedir の内容は接続法 |
| querer que ＋ 接続法 | Mi mujer quiere que **pasemos**… que la **lleve**… que **aprenda**… | 主語が変わると接続法 |
| cuando ＋ 接続法 | **Cuando termine**, me retiro | 未来のこと |
| llevar ＋ 期間 ＋ 現在分詞 | **Llevo veinte años anunciando** que me retiro / lleva cuarenta años en los banquillos | 〜し続けて〜年になる |
| quedarse con〜 | me lo **quedo** hasta el lunes / **me quedé con** el de Dani | 〜を自分のものにする、預かる |
| 代名詞 | **me lo** quedo（el móvil）／**las** tenía todas apuntadas（las tarjetas）／**Las** he visto（las imágenes）／**Lo** apuntaremos | |

### 文法・表現の見どころ

| 項目 | 本文の例 | ポイント |
|---|---|---|
| 点過去で状況を説明する | me **coloqué** / El balón **rebotó**, **salió**… y me **dio** a mí / **fue** directamente… | 出来事を一つずつ順に並べる |
| 線過去（その時の状態） | Dani, que **estaba** agachado, atándose la bota / **Estábamos** comiendo | 出来事の背景 |
| 過去完了 | sus compañeros le **habían cantado** canciones | 「泣いて帰ってきた」より前のこと |
| tener que の線過去 | Yo **tenía que** parar el juego, y no lo paré | 〜すべきだった（のにしなかった） |
| siempre que ＋ 接続法 | **siempre que pueda**, claro | 「〜できるときはいつでも」「できる限り」 |
| hacer de〜 | tu madre **hizo de** VAR | 〜の役をする |
| 線過去（過去の可能・不可能） | nadie me **podía** avisar / **tenían** muchos jugadores delante | その時の状況 |
| es posible que ＋ 接続法 | Es posible que me **llamen**… y que me **sancionen** | 可能性 |
| preferir que ＋ 接続法 | prefiero que no | que の後の動詞（leas）が省略されている |
| ojalá ＋ 接続法 | ojalá no se **acuerde** nunca | 願望 |
| que ＋ 接続法 | **Que conste** que… | 「言っておくが」（決まり文句） |
| 無意志の se | ya **se le ha olvidado** | おばあちゃんは（うっかり）もう忘れた |
| arrepentirse de ＋ haber ＋ 過去分詞 | ¿Te arrepientes de **haber venido**? | 「来たこと」を後悔する（完了不定詞） |
| 目的語を前に出す | **el pan lo** traes tú | パンは、あなたが持ってきて |
| tú の否定命令 | **no lo dejes** / **no te preocupes** | |
| 代名詞 | **te lo** prometo／**lo** intento／**me** avisa／ver**lo**／**lo** diste por bueno／**me** coge el teléfono／leer**te** | |
